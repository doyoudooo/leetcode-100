给定一个大小为 `n` 的数组 `nums` ，返回其中的多数元素。多数元素是指在数组中出现次数 **大于** `⌊ n/2 ⌋` 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

**示例 1：**

```
输入：nums = [3,2,3]
输出：3
```

**示例 2：**

```
输入：nums = [2,2,1,1,1,2,2]
输出：2
```

**提示：**

*   `n == nums.length`
*   `1 <= n <= 5 * 10^4`
*   `-10^9 <= nums[i] <= 10^9`

**进阶：** 尝试设计时间复杂度为 O(n)、空间复杂度为 O(1) 的算法解决此问题。

## 解决方法

### 1. 问题理解

**目标：** 找到数组中出现次数超过 `⌊ n/2 ⌋` 的元素（多数元素）。
**保证：** 数组非空，且多数元素总是存在。
**输入：** 整数数组 `nums`。
**输出：** 多数元素。
**进阶要求：** 时间 O(N)，空间 O(1)。

### 2. 思路分析

#### 方法一：哈希表计数 (O(N) 时间, O(N) 空间)

1.  遍历数组，使用哈希表记录每个元素出现的次数。
2.  遍历哈希表，找到值（出现次数）大于 `n / 2` 的那个键（元素）。

- **时间复杂度：** O(N)，遍历数组和哈希表。
- **空间复杂度：** O(N)，最坏情况下，存储接近 N/2 个不同的元素。**不满足进阶要求。**

#### 方法二：排序 (O(N log N) 时间, O(log N) 或 O(N) 空间)

1.  对数组 `nums` 进行排序。
2.  由于多数元素出现次数超过 `n / 2`，排序后，数组中间位置 `nums[n // 2]` 的元素一定是多数元素。
3.  返回 `nums[n // 2]`。

- **时间复杂度：** O(N log N)，主要取决于排序算法。
- **空间复杂度：** O(log N) 或 O(N)，取决于排序算法使用的空间（例如，快速排序平均 O(log N)，归并排序 O(N)）。**不满足进阶要求。**

#### 方法三：Boyer-Moore 投票算法 (O(N) 时间, O(1) 空间) - 满足进阶要求

**核心思想：**
- 维护一个候选多数元素 `candidate` 和一个计数器 `count`。
- 遍历数组 `nums`：
    - 如果 `count` 为 0，将当前元素 `num` 设为新的 `candidate`，并将 `count` 设为 1。
    - 如果 `count` 不为 0：
        - 如果当前元素 `num` 等于 `candidate`，则 `count` 加 1。
        - 如果当前元素 `num` 不等于 `candidate`，则 `count` 减 1。
- 遍历结束后，`candidate` 中存储的就是多数元素。

**为什么这个方法有效？**
- 多数元素的数量超过 `n / 2`。
- 当我们遍历数组时，每次遇到一个多数元素，`count` 增加；遇到一个非多数元素，`count` 减少。
- 由于多数元素的数量比所有其他元素的总和还要多至少 1 个，即使所有非多数元素都用来抵消多数元素，`count` 最终也一定会是正数，并且 `candidate` 会是那个多数元素。
- 想象一下，多数元素是“好人”，非多数元素是“坏人”。一个好人遇到一个坏人就同归于尽 (`count` 减 1)。因为好人比坏人多，最后活下来的肯定是好人。

**算法流程：**
1.  初始化 `candidate = None`, `count = 0`。
2.  遍历数组 `nums` 中的每个元素 `num`。
3.  如果 `count == 0`，设置 `candidate = num`。
4.  如果 `num == candidate`，`count += 1`。
5.  如果 `num != candidate`，`count -= 1`。
6.  遍历结束后，返回 `candidate`。

**注意：** 这个算法依赖于题目保证多数元素一定存在。如果可能不存在，还需要在最后再遍历一次数组，验证 `candidate` 的出现次数是否真的大于 `n / 2`。但在本题中，这一步可以省略。

### 3. 代码实现 (Python)

#### 方法一：哈希表计数

```python
from typing import List
import collections

class Solution:
    def majorityElement_hash(self, nums: List[int]) -> int:
        counts = collections.Counter(nums)
        n = len(nums)
        for num, count in counts.items():
            if count > n // 2:
                return num
        # 根据题意，总会找到，这里可以不写 return -1 或 raise Error
```

#### 方法二：排序

```python
from typing import List

class Solution:
    def majorityElement_sort(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        return nums[n // 2]
```

#### 方法三：Boyer-Moore 投票算法 - 推荐

```python
from typing import List

class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        """
        Boyer-Moore 投票算法
        时间 O(N), 空间 O(1)
        """
        candidate = None
        count = 0
        for num in nums:
            if count == 0:
                candidate = num
            
            if num == candidate:
                count += 1
            else:
                count -= 1
                
        # 因为题目保证多数元素一定存在，所以最后 candidate 一定是答案
        return candidate

# 示例调用
# sol = Solution()
# print(sol.majorityElement([3, 2, 3]))             # 3
# print(sol.majorityElement([2, 2, 1, 1, 1, 2, 2])) # 2
```

### 4. 复杂度分析

- **方法一 (哈希表)：** 时间 O(N)，空间 O(N)。
- **方法二 (排序)：** 时间 O(N log N)，空间 O(log N) 或 O(N)。
- **方法三 (Boyer-Moore)：** 时间 O(N)，空间 O(1)。

**结论：** Boyer-Moore 投票算法是满足所有约束的最优解。
