整数数组的一个 **排列**  是指将其所有成员以序列或线性顺序排列。

*   例如，`arr = [1,2,3]` ，以下这些都可以视作 `arr` 的排列：`[1,2,3]`、`[1,3,2]`、`[3,1,2]`、`[2,3,1]` 。

整数数组的 **下一个排列** 是指其整数的下一个字典序更大的排列。更正式地，如果数组的所有排列根据其字典顺序从小到大排列在一个容器中，那么数组的 **下一个排列** 就是在这个有序容器中排在它后面的那个排列。如果不存在下一个更大的排列，那么这个数组必须重排为字典序最小的排列（即，其元素按升序排列）。

*   例如，`arr = [1,2,3]` 的下一个排列是 `[1,3,2]` 。
*   类似地，`arr = [2,3,1]` 的下一个排列是 `[3,1,2]` 。
*   而 `arr = [3,2,1]` 的下一个排列是 `[1,2,3]` ，因为 `[3,2,1]` 不存在一个字典序更大的排列。

给你一个整数数组 `nums` ，找出 `nums` 的下一个排列。

必须 **[原地](http://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95)** 修改，只允许使用额外常数空间。

**示例 1：**

```
输入：nums = [1,2,3]
输出：[1,3,2]
```

**示例 2：**

```
输入：nums = [3,2,1]
输出：[1,2,3]
```

**示例 3：**

```
输入：nums = [1,1,5]
输出：[1,5,1]
```

**提示：**

*   `1 <= nums.length <= 100`
*   `0 <= nums[i] <= 100`

## 解决方法

### 1. 问题理解

**目标：** 找到给定整数数组 `nums` 的下一个字典序更大的排列。
**特殊情况：** 如果数组已经是字典序最大的排列（即完全降序），则将其重排为字典序最小的排列（升序）。
**约束：** 必须原地修改数组，空间复杂度 O(1)。
**输入：** 整数数组 `nums`。
**输出：** 无（原地修改 `nums`）。

### 2. 思路分析 (标准算法)

要找到下一个字典序更大的排列，我们希望：
1.  尽可能保持高位（左侧）的数字不变。
2.  找到一个尽可能靠右的位置进行修改，使得修改后的数字变大，且增大的幅度尽可能小。

**算法步骤：**

1.  **从右向左查找第一个“升序”对 (寻找“较小数”)：**
    - 从倒数第二个元素开始 (`i = n - 2`) 向左遍历。
    - 找到第一个满足 `nums[i] < nums[i+1]` 的索引 `i`。
    - 这个 `nums[i]` 就是我们需要增大一点以获得下一个排列的“枢轴”或“较小数”。它右边的子数组 `nums[i+1...n-1]` 必然是降序的（因为我们是从右往左找到第一个升序对）。
    - **例子:** `[1, 2, 7, 4, 3, 1]`，从右往左看，`1 < 3`, `3 < 4`, `4 < 7`, `7 > 2`。第一个升序对是 `(2, 7)`，所以 `i = 1`，`nums[i] = 2`。

2.  **处理完全降序的情况：**
    - 如果在步骤 1 中没有找到这样的 `i`（即 `i` 遍历到了 -1），说明整个数组是完全降序的，已经是最大的排列。
    - 此时，直接将整个数组反转，得到最小的排列（升序）。然后结束。
    - **例子:** `[3, 2, 1]`，找不到 `nums[i] < nums[i+1]`，反转得到 `[1, 2, 3]`。

3.  **从右向左查找第一个大于 `nums[i]` 的数 (寻找“较大数”)：**
    - 如果找到了 `i`，那么在 `i` 右边的降序子数组 `nums[i+1...n-1]` 中，从右向左 (`j = n - 1`) 查找。
    - 找到第一个满足 `nums[j] > nums[i]` 的索引 `j`。
    - 这个 `nums[j]` 是 `i` 右边比 `nums[i]` 大的数中最小的那个（因为 `nums[i+1...n-1]` 是降序的）。
    - **例子:** `[1, 2, 7, 4, 3, 1]`, `i = 1`, `nums[i] = 2`。从右往左找 `j`：`nums[5]=1 <= 2`；`nums[4]=3 > 2`。找到 `j = 4`，`nums[j] = 3`。

4.  **交换“较小数”和“较大数”：**
    - 交换 `nums[i]` 和 `nums[j]`。
    - 这一步保证了新的排列比原来的排列大。
    - **例子:** 交换 `nums[1]` 和 `nums[4]`。`nums` 变为 `[1, 3, 7, 4, 2, 1]`。

5.  **反转 `i` 右边的子数组：**
    - 将索引 `i+1` 到 `n-1` 的子数组反转。
    - 因为原来的 `nums[i+1...n-1]` 是降序的，交换后 `nums[i+1...n-1]` 仍然是降序的（只是其中一个元素变小了）。将其反转可以得到该部分的最小排列（升序）。
    - 结合第 4 步，这保证了我们得到的是 *刚好* 大于原排列的下一个排列。
    - **例子:** 反转 `nums[i+1...n-1]` 即 `nums[2...5]`，也就是反转 `[7, 4, 2, 1]`。
    - `nums` 最终变为 `[1, 3, 1, 2, 4, 7]`。

**辅助函数：** 需要一个原地反转数组指定区间的函数 `reverse(nums, start, end)`。

### 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def reverse(self, nums: List[int], start: int, end: int) -> None:
        """原地反转数组 nums 的 [start, end] 区间"""
        while start < end:
            nums[start], nums[end] = nums[end], nums[start]
            start += 1
            end -= 1

    def nextPermutation(self, nums: List[int]) -> None:
        """
        寻找下一个排列
        Do not return anything, modify nums in-place instead.
        """
        n = len(nums)
        if n <= 1:
            return

        # 1. 从右向左查找第一个升序对 (i, i+1)
        i = n - 2
        while i >= 0 and nums[i] >= nums[i+1]:
            i -= 1

        # 2. 如果找到了 i (即 i >= 0)
        if i >= 0:
            # 3. 从右向左查找第一个大于 nums[i] 的数 nums[j]
            j = n - 1
            while j > i and nums[j] <= nums[i]:
                j -= 1
            # 4. 交换 nums[i] 和 nums[j]
            nums[i], nums[j] = nums[j], nums[i]

        # 5. 反转 i 右边的子数组 (nums[i+1:])
        # 如果 i = -1 (完全降序)，则反转整个数组
        self.reverse(nums, i + 1, n - 1)
```

### 4. 复杂度分析

- **时间复杂度：** O(N)。
    - 最坏情况下，需要两次遍历数组（一次找 `i`，一次找 `j`），以及一次反转（最多反转 N 个元素）。总共是 O(N) + O(N) + O(N) = O(N)。
- **空间复杂度：** O(1)。原地修改，只使用了常数个额外变量。

### 5. 如何在面试中讲解

1.  **问题理解**：
    - "目标是找到给定数组的下一个字典序排列。"
    - "如果是最大排列（降序），则返回最小排列（升序）。"
    - "要求原地修改，O(1) 空间。"
2.  **核心思路**：
    - "要找下一个更大的排列，我们希望尽可能少地改变高位（左侧）。"
    - "关键是从右往左找到第一个可以增大的位置 `i`（即 `nums[i] < nums[i+1]`）。"
    - "然后，将 `nums[i]` 与其右侧刚好大于它的最小元素 `nums[j]` 交换。"
    - "最后，将 `i` 右侧的子数组反转，使其变为升序，从而得到紧邻的下一个排列。"
3.  **算法步骤详解**：
    - **Step 1: 找“较小数” `nums[i]`:** 从右往左，`i = n-2` down to 0，找 `nums[i] < nums[i+1]`。
    - **Step 2: 处理降序:** 如果找不到 `i` (`i < 0`)，说明是最大排列，反转整个数组，结束。
    - **Step 3: 找“较大数” `nums[j]`:** 从右往左，`j = n-1` down to `i+1`，找 `nums[j] > nums[i]`。
    - **Step 4: 交换:** Swap `nums[i]` and `nums[j]`。
    - **Step 5: 反转后缀:** Reverse `nums[i+1:]`。
4.  **代码演示**：
    - "展示包含 `reverse` 辅助函数的完整代码。"
5.  **复杂度**：
    - "时间 O(N)，因为最多涉及三次线性扫描（找 i, 找 j, 反转）。"
    - "空间 O(1)，原地操作。"
6.  **例子 walkthrough**：
    - "用 `nums = [1, 2, 7, 4, 3, 1]` 走一遍流程："
        - 找 `i`: `i=1` (`nums[1]=2 < nums[2]=7`)。
        - 找 `j`: `j=4` (`nums[4]=3 > nums[1]=2`)。
        - 交换 `nums[1]` 和 `nums[4]`: `[1, 3, 7, 4, 2, 1]`。
        - 反转 `nums[2:]` (`[7, 4, 2, 1]` -> `[1, 2, 4, 7]`): `[1, 3, 1, 2, 4, 7]`。
    - "用 `nums = [3, 2, 1]` 走一遍流程："
        - 找 `i`: 找不到，`i=-1`。
        - 反转整个数组: `[1, 2, 3]`。
