给定一个包含 `n + 1` 个整数的数组 `nums` ，其数字都在 `[1, n]` 范围内（包括 `1` 和 `n`），可知至少存在一个重复的整数。

假设 `nums` 只有 **一个重复的整数** ，返回 **这个重复的数** 。

你设计的解决方案必须 **不修改** 数组 `nums` 且只用常量级 `O(1)` 的额外空间。

**示例 1：**

```
输入：nums = [1,3,4,2,2]
输出：2
```

**示例 2：**

```
输入：nums = [3,1,3,4,2]
输出：3
```

**提示：**

*   `1 <= n <= 10^5`
*   `nums.length == n + 1`
*   `1 <= nums[i] <= n`
*   `nums` 中 **只有一个整数** 出现 **两次或多次** ，其余整数均只出现 **一次**

**进阶：**

*   如何证明 `nums` 中至少存在一个重复的数字？ (鸽巢原理)
*   你可以设计一个线性时间复杂度 `O(n)` 的解决方案吗？ (快慢指针)

## 解决方法

### 1. 问题理解

**目标：** 在一个包含 `n + 1` 个整数的数组 `nums` 中找到唯一的重复数。
**数组特性：**
- 长度为 `n + 1`。
- 所有数字都在 `[1, n]` 范围内。
- 只有一个数字重复（可能重复多次），其他数字都只出现一次。
**约束：**
1.  不能修改原数组 `nums`。
2.  空间复杂度 O(1)。
**输入：** 整数数组 `nums`。
**输出：** 重复的那个整数。

**鸽巢原理证明重复数存在：**
数组中有 `n + 1` 个数字（鸽子），这些数字的取值范围是 `[1, n]`，共 `n` 个可能的值（鸽巢）。根据鸽巢原理，至少有一个值（鸽巢）被至少两个数字（鸽子）选中，因此至少存在一个重复数。

### 2. 思路分析

#### 方法一：哈希集合/频率数组 (违反空间约束)

1.  使用哈希集合记录遍历过的数字。如果当前数字已在集合中，则找到重复数。
2.  或者使用大小为 `n+1` 的频率数组记录每个数字出现的次数。

- **时间复杂度：** O(N)。
- **空间复杂度：** O(N)。**违反 O(1) 空间约束。**

#### 方法二：排序 (违反修改约束)

1.  对数组 `nums` 进行排序。
2.  遍历排序后的数组，如果 `nums[i] == nums[i-1]`，则 `nums[i]` 是重复数。

- **时间复杂度：** O(N log N)。
- **空间复杂度：** O(log N) 或 O(N) (取决于排序算法)。
- **缺点：** **违反了不能修改数组的约束。**

#### 方法三：二分查找 (基于值域) - 满足约束

**核心思想：**
- 我们不对数组索引进行二分，而是对 **数字的值域 `[1, n]`** 进行二分。
- 对于值域 `[1, n]` 中的一个猜测值 `mid`，我们遍历整个 `nums` 数组，统计其中小于等于 `mid` 的元素个数 `count`。
- **根据鸽巢原理：**
    - 如果没有重复数（或者重复数大于 `mid`），那么 `nums` 中小于等于 `mid` 的元素个数应该恰好等于 `mid` (或者更少，但这里因为总数是 n+1，所以不会更少)。
    - 如果 `count > mid`，说明在 `[1, mid]` 这个值域区间内，元素的数量超过了区间的长度，因此重复数一定落在 `[1, mid]` 区间内。
    - 如果 `count <= mid`，说明在 `[1, mid]` 这个值域区间内没有足够的元素来产生重复，因此重复数一定落在 `[mid + 1, n]` 区间内。

**算法流程：**
1.  初始化查找区间 `left = 1`, `right = n`。
2.  循环条件：`left < right`。
3.  计算中间值 `mid = left + (right - left) // 2`。
4.  遍历 `nums`，计算 `count = sum(1 for num in nums if num <= mid)`。
5.  判断：
    - 如果 `count > mid`，说明重复数在 `[left, mid]` 区间，更新 `right = mid`。
    - 如果 `count <= mid`，说明重复数在 `[mid + 1, right]` 区间，更新 `left = mid + 1`。
6.  循环结束时 (`left == right`)，`left` (或 `right`) 就是重复的数。

- **时间复杂度：** O(N log N)。外层二分查找 log N 次，内层每次遍历数组统计 count 需要 O(N)。
- **空间复杂度：** O(1)。满足约束。

#### 方法四：快慢指针 (Floyd 判圈算法) - 满足约束 & O(N) 时间

**核心思想：**
- 将数组 `nums` 视为一个 **函数映射** 或 **链表**。每个索引 `i` 指向 `nums[i]`。即 `i -> nums[i]`。
- 因为数组长度为 `n + 1`，索引范围 `0` 到 `n`。而数字范围是 `[1, n]`。
- 考虑从索引 0 开始的序列：`0 -> nums[0] -> nums[nums[0]] -> nums[nums[nums[0]]] -> ...`
- 由于数字范围有限且存在重复数字，这个序列最终必然会进入一个 **环**。
- **关键：** 重复的数字 `dup` 意味着至少有两个不同的索引 `i` 和 `j` 指向同一个值 `dup` (`nums[i] = nums[j] = dup`)。这正是形成环的入口点。我们的目标就是找到这个环的入口点。

**Floyd 判圈算法 (Tortoise and Hare)：**
1.  **阶段一：找到环中相遇点**
    - 初始化两个指针，`slow` 和 `fast`，都从索引 0 开始。
    - `slow` 每次走一步：`slow = nums[slow]`。
    - `fast` 每次走两步：`fast = nums[nums[fast]]`。
    - 持续移动直到 `slow == fast`。此时它们在环内的某个点相遇。
2.  **阶段二：找到环的入口点**
    - 将 `slow` 指针重置回起点 0 (`slow = 0`)。
    - `fast` 指针保持在相遇点。
    - 两个指针都每次走一步：`slow = nums[slow]`, `fast = nums[fast]`。
    - 当 `slow == fast` 时，它们相遇的点就是环的入口点，也就是重复的数字。

**为什么阶段二能找到入口点？**
- 设起点到环入口的距离为 `a`，环入口到相遇点的距离为 `b`，相遇点到环入口的距离为 `c` (环长为 `b+c`)。
- 慢指针走了 `a + b` 步。
- 快指针走了 `a + b + k*(b+c)` 步 (k >= 1，绕了 k 圈)。
- 快指针走的路程是慢指针的两倍：`2 * (a + b) = a + b + k*(b+c)`。
- 化简得 `a + b = k*(b+c)`。
- 进一步得到 `a = k*(b+c) - b = (k-1)*(b+c) + c`。
- 这个公式的含义是：从起点走 `a` 步到达入口点，等于从相遇点走 `c` 步（回到入口点）再加上 `k-1` 圈。
- 因此，一个指针从起点出发，另一个指针从相遇点出发，都每次走一步，它们一定会在环的入口点相遇。

- **时间复杂度：** O(N)。两个阶段指针移动的总步数是线性的。
- **空间复杂度：** O(1)。满足约束。

### 3. 代码实现 (Python)

#### 方法三：二分查找

```python
from typing import List

class Solution:
    def findDuplicate_binary_search(self, nums: List[int]) -> int:
        """
        二分查找 (基于值域 [1, n])
        时间 O(N log N), 空间 O(1)
        """
        n = len(nums) - 1
        left, right = 1, n
        ans = -1
        
        while left <= right: # 使用闭区间查找
            mid = left + (right - left) // 2
            count = 0
            for num in nums:
                if num <= mid:
                    count += 1
            
            if count > mid:
                # 重复数在 [left, mid] 区间
                ans = mid # mid 可能是答案
                right = mid - 1
            else:
                # 重复数在 [mid + 1, right] 区间
                left = mid + 1
                
        return ans # 或者返回 left，因为循环结束时 left 指向第一个 count > mid 的位置

    # 另一种二分写法 (左闭右开区间)
    def findDuplicate_binary_search_v2(self, nums: List[int]) -> int:
        n = len(nums) - 1
        left, right = 1, n + 1 # [1, n+1)
        while left < right:
            mid = left + (right - left) // 2
            count = sum(1 for x in nums if x <= mid)
            if count > mid:
                right = mid # 答案在 [left, mid)
            else:
                left = mid + 1 # 答案在 [mid+1, right)
        return left
```

#### 方法四：快慢指针 - 推荐

```python
from typing import List

class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        """
        快慢指针 (Floyd 判圈算法)
        时间 O(N), 空间 O(1)
        """
        # 阶段一：找到相遇点
        slow = 0
        fast = 0
        # 先走一步，避免初始 slow == fast
        slow = nums[slow]
        fast = nums[nums[fast]]
        while slow != fast:
            slow = nums[slow]
            fast = nums[nums[fast]]
            
        # 阶段二：找到入口点
        slow = 0
        while slow != fast:
            slow = nums[slow]
            fast = nums[fast]
            
        return slow # 或 fast
```

### 4. 复杂度分析

- **方法一 (哈希表)：** 时间 O(N)，空间 O(N)。(不满足)
- **方法二 (排序)：** 时间 O(N log N)，空间 O(log N) 或 O(N)。(不满足)
- **方法三 (二分查找)：** 时间 O(N log N)，空间 O(1)。(满足)
- **方法四 (快慢指针)：** 时间 O(N)，空间 O(1)。(满足，且最优)

    - "**思路 (类比链表判环):** 将数组看作 `i -> nums[i]` 的映射。由于数字范围和重复数的存在，从 0 出发必然形成环，重复数就是环的入口。"
    - "**Floyd 算法:**
        - "阶段一：快慢指针（1步 vs 2步）找到环内相遇点。"
        - "阶段二：一个指针回起点，一个在相遇点，都走 1 步，再次相遇点即为入口（重复数）。"
    - "**原理:** 简单解释 `a = (k-1)*cycle_len + c` 的推导或几何意义。"
    - "**复杂度:** 时间 O(N)，空间 O(1)。满足约束且最优。"
5.  **代码演示**：
