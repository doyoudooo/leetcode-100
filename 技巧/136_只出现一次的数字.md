给你一个 **非空** 整数数组 `nums` ，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

**示例 1 ：**

```
输入：nums = [2,2,1]
输出：1
```

**示例 2 ：**

```
输入：nums = [4,1,2,1,2]
输出：4
```

**示例 3 ：**

```
输入：nums = [1]
输出：1
```

**提示：**

*   `1 <= nums.length <= 3 * 10^4`
*   `-3 * 10^4 <= nums[i] <= 3 * 10^4`
*   除了某个元素只出现一次以外，其余每个元素均出现两次。

## 解决方法

### 1. 问题理解

**目标：** 在一个非空整数数组中，找到唯一一个只出现一次的元素，其他所有元素都恰好出现两次。
**约束：**
1.  线性时间复杂度 O(N)。
2.  常量额外空间 O(1)。
**输入：** 整数数组 `nums`。
**输出：** 只出现一次的那个整数。

### 2. 思路分析

#### 方法一：哈希表 (不满足空间约束)

1.  遍历数组，使用哈希表记录每个数字出现的次数。
2.  再次遍历哈希表，找到出现次数为 1 的那个数字。

- **时间复杂度：** O(N)，两次遍历。
- **空间复杂度：** O(N)，最坏情况下，一半的元素是不同的，需要存储 N/2 个键值对。**不满足 O(1) 空间约束。**

#### 方法二：位运算 (异或 XOR) - 满足约束

**核心思想：** 利用异或运算的性质。
1.  `a ^ 0 = a` (任何数与 0 异或等于其本身)
2.  `a ^ a = 0` (任何数与自身异或等于 0)
3.  `a ^ b ^ a = (a ^ a) ^ b = 0 ^ b = b` (异或运算满足交换律和结合律)

**应用到本题：**
数组中除了一个元素只出现一次，其他都出现两次。将数组中所有元素进行异或运算：
`nums[0] ^ nums[1] ^ nums[2] ^ ... ^ nums[n-1]`

根据异或的性质，所有出现两次的元素，两两异或后结果为 0。最后剩下的就是那个只出现一次的元素与 0 的异或结果，也就是那个元素本身。

**算法流程：**
1.  初始化结果 `result = 0`。
2.  遍历数组 `nums` 中的每个元素 `num`。
3.  将 `result` 与 `num` 进行异或运算：`result = result ^ num`。
4.  遍历结束后，`result` 就是那个只出现一次的元素。
5.  返回 `result`。

### 3. 代码实现 (Python - 位运算)

```python
from typing import List
import functools
import operator

class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        """
        使用位运算 (异或) 找到只出现一次的数字。
        时间复杂度 O(N)，空间复杂度 O(1)。
        """
        result = 0
        for num in nums:
            result ^= num # result = result ^ num
        return result

    # Pythonic 写法 (使用 functools.reduce 和 operator.xor)
    def singleNumber_pythonic(self, nums: List[int]) -> int:
        """
        使用 functools.reduce 和 operator.xor 的 Pythonic 写法。
        """
        return functools.reduce(operator.xor, nums)

```

### 4. 复杂度分析

- **时间复杂度：** O(N)，只需要遍历数组一次。
- **空间复杂度：** O(1)，只需要一个额外的变量 `result` 来存储异或结果。
