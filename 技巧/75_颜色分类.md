给定一个包含红色、白色和蓝色、共 `n` 个元素的数组 `nums` ，**[原地](https://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95)** 对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色顺序排列。

我们使用整数 `0`、 `1` 和 `2` 分别表示红色、白色和蓝色。

必须在不使用库内置的 sort 函数的情况下解决这个问题。

**示例 1：**

```
输入：nums = [2,0,2,1,1,0]
输出：[0,0,1,1,2,2]
```

**示例 2：**

```
输入：nums = [2,0,1]
输出：[0,1,2]
```

**提示：**

*   `n == nums.length`
*   `1 <= n <= 300`
*   `nums[i]` 为 `0`、`1` 或 `2`

**进阶：**

*   你能想出一个仅使用常数空间的一趟扫描算法吗？

## 解决方法

### 1. 问题理解

**目标：** 对包含 0, 1, 2 三种元素的数组进行原地排序，使得所有 0 在前，所有 1 在中间，所有 2 在后。
**约束：**
1.  原地排序 (in-place)，即空间复杂度 O(1)。
2.  不能使用库函数 `sort`。
**进阶要求：** 一趟扫描 (one-pass) 算法，即时间复杂度 O(N)。
**输入：** 整数数组 `nums`，元素只包含 0, 1, 2。
**输出：** 无（原地修改 `nums`）。

### 2. 思路分析

#### 方法一：计数排序 (两趟扫描)

1.  **第一趟扫描：** 遍历数组，统计 0, 1, 2 各自出现的次数。
2.  **第二趟扫描：** 根据统计的次数，重写原数组。先写入 `count_0` 个 0，然后写入 `count_1` 个 1，最后写入 `count_2` 个 2。

- **时间复杂度：** O(N) + O(N) = O(N)。
- **空间复杂度：** O(1)，只需要常数空间存储三个计数器。
- **优点：** 思路简单直观。
- **缺点：** 需要两次遍历数组，不满足进阶要求的一趟扫描。

#### 方法二：双指针 (荷兰国旗问题 - 一趟扫描)

这是解决此类问题的经典方法，也称为荷兰国旗问题 (Dutch National Flag problem)。使用三个指针来划分数组：

- `p0`：指向下一个应该放置 0 的位置。`nums[0...p0-1]` 的所有元素都是 0。
- `curr`：指向当前正在处理的元素。`nums[p0...curr-1]` 的所有元素都是 1。
- `p2`：指向下一个应该放置 2 的位置。`nums[p2+1...n-1]` 的所有元素都是 2。

**初始化：** `p0 = 0`, `curr = 0`, `p2 = n - 1`。

**遍历过程：** `curr` 指针从左向右扫描数组，直到 `curr > p2`。
在 `while curr <= p2` 循环中：

1.  **如果 `nums[curr] == 0`：**
    - 当前元素是 0，应该放到 `p0` 指向的位置。
    - 交换 `nums[curr]` 和 `nums[p0]`。
    - `p0` 向右移动一位 (`p0 += 1`)。
    - `curr` 向右移动一位 (`curr += 1`)。为什么 `curr` 也要移动？因为我们把 `nums[p0]` 换过来了，而 `nums[p0...curr-1]` 区域的元素保证是 1，所以换过来的元素不可能是 2，只可能是 0 或 1。如果是 0，下次循环处理；如果是 1，它已经在正确的位置了。所以可以直接移动 `curr`。
2.  **如果 `nums[curr] == 2`：**
    - 当前元素是 2，应该放到 `p2` 指向的位置的右边。
    - 交换 `nums[curr]` 和 `nums[p2]`。
    - `p2` 向左移动一位 (`p2 -= 1`)。
    - **注意：`curr` 指针此时不移动！** 因为从 `p2` 交换过来的元素 `nums[curr]` 可能是 0, 1 或 2，需要下一轮循环让 `curr` 重新判断这个新换过来的元素。
3.  **如果 `nums[curr] == 1`：**
    - 当前元素是 1，它已经在正确的位置（在 0 和 2 之间）。
    - `curr` 向右移动一位 (`curr += 1`)。

**循环结束：** 当 `curr > p2` 时，数组排序完成。

- **时间复杂度：** O(N)，`curr` 指针遍历数组一次。虽然 `p0` 和 `p2` 也在移动，但每个元素最多被访问和交换常数次。
- **空间复杂度：** O(1)，原地排序。
- **优点：** 只需一趟扫描，满足所有要求。

### 3. 代码实现 (Python)

#### 方法一：计数排序

```python
from typing import List

class Solution:
    def sortColors_counting(self, nums: List[int]) -> None:
        """
        计数排序 (两趟扫描)
        Do not return anything, modify nums in-place instead.
        """
        count0, count1, count2 = 0, 0, 0
        # Pass 1: Count
        for num in nums:
            if num == 0:
                count0 += 1
            elif num == 1:
                count1 += 1
            else:
                count2 += 1
        
        # Pass 2: Overwrite
        n = len(nums)
        idx = 0
        for _ in range(count0):
            nums[idx] = 0
            idx += 1
        for _ in range(count1):
            nums[idx] = 1
            idx += 1
        for _ in range(count2):
            nums[idx] = 2
            idx += 1
```

#### 方法二：双指针 (荷兰国旗问题) - 推荐

```python
from typing import List

class Solution:
    def sortColors(self, nums: List[int]) -> None:
        """
        双指针 (荷兰国旗问题 - 一趟扫描)
        Do not return anything, modify nums in-place instead.
        """
        n = len(nums)
        p0, curr, p2 = 0, 0, n - 1
        
        while curr <= p2:
            if nums[curr] == 0:
                # Swap with p0
                nums[p0], nums[curr] = nums[curr], nums[p0]
                p0 += 1
                curr += 1
            elif nums[curr] == 2:
                # Swap with p2
                nums[p2], nums[curr] = nums[curr], nums[p2]
                p2 -= 1
                # curr does not increment here!
            else: # nums[curr] == 1
                curr += 1

# 示例调用

# nums2 = [2, 0, 1]

```

### 4. 复杂度分析

- **方法一 (计数排序)：** 时间 O(N)，空间 O(1)。
- **方法二 (双指针)：** 时间 O(N)，空间 O(1)。

**结论：** 双指针（荷兰国旗）方法更优，因为它只需要一趟扫描。

    - "可以先遍历一遍统计 0, 1, 2 的数量，再遍历一遍覆盖原数组。"
    - "**复杂度:** 时间 O(N)，空间 O(1)。满足基本要求，但需要两趟扫描。"
3.  **方法二：双指针/荷兰国旗 (进阶解法)**：
    - "为了实现一趟扫描，可以使用类似荷兰国旗问题的三指针方法。"
    - "**指针定义:**
        - `p0`: 维护 0 的右边界 (下一个 0 的位置)。
        - `curr`: 当前扫描的元素。
        - `p2`: 维护 2 的左边界 (下一个 2 的位置)。"
    - "**不变量/分区:** 始终保持 `nums[0...p0-1]` 全是 0，`nums[p2+1...n-1]` 全是 2，`nums[p0...curr-1]` 全是 1。"
    - "**遍历逻辑:** `curr` 从左向右扫描 (`while curr <= p2`)："
        - "遇到 0: 与 `nums[p0]` 交换，`p0++`, `curr++`。"
        - "遇到 2: 与 `nums[p2]` 交换，`p2--`。**`curr` 不动**，因为换过来的元素需要重新判断。"
        - "遇到 1: `curr++`。"
    - "**复杂度:** 时间 O(N)，空间 O(1)。满足所有要求。"
