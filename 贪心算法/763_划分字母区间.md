给你一个字符串 `s` 。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。

返回一个表示每个字符串片段的长度的列表。

**示例 1：**

```
输入：s = "ababcbacadefegdehijhklij"
输出：[9,7,8]
解释：
划分结果为 "ababcbaca"、"defegde"、"hijhklij" 。
每个字母最多出现在一个片段中。
像 "ababcbacadefegde", "hijhklij" 这样的划分是错误的，因为划分的片段数较少。
```

**示例 2：**

```
输入：s = "eccbbbbdec"
输出：[10]
```

**提示：**

*   `1 <= s.length <= 500`
*   `s` 只包含小写字母

## 解决方法

### 1. 问题理解

**目标：** 将字符串 `s` 划分成尽可能多的片段。
**约束：** 同一个字母只能出现在一个片段中。
**输出：** 一个列表，包含每个片段的长度。

**核心约束解读：** 如果一个片段包含了某个字母（例如 'a'），那么字符串 `s` 中所有的 'a' 都必须包含在这个片段内。

### 2. 思路分析 (贪心算法)

为了使片段数量尽可能多，我们应该让每个片段尽可能短。

考虑第一个片段。它必须包含 `s[0]`。为了满足约束，这个片段必须至少延伸到 `s[0]` 在字符串 `s` 中最后一次出现的位置。

但是，这个片段内可能还包含其他字符。例如，如果 `s = "abacaba"`，第一个片段包含 `s[0] = 'a'`，'a' 最后出现在索引 6。所以片段至少是 `s[0...6]`。但在这个范围内，还出现了 'b' (最后出现在索引 4) 和 'c' (最后出现在索引 2)。为了满足约束，片段必须延伸到这些字符中最后出现位置的最远者。

**贪心策略：**
遍历字符串，对于当前正在构建的片段，不断扩展其右边界，确保该边界是片段内所有字符最后出现位置的最大值。当遍历的索引 `i` 刚好到达这个右边界时，说明找到了一个满足条件的、尽可能短的片段。

**算法流程：**
1.  **预处理 - 记录最后出现位置：**
    - 遍历一次字符串 `s`，使用一个哈希表（或大小为 26 的数组）`last_occurrence` 记录每个字符最后出现的索引。
2.  **划分片段：**
    - 初始化 `start = 0`，表示当前片段的起始索引。
    - 初始化 `end = 0`，表示当前片段必须延伸到的最远索引。
    - 初始化 `result = []`，用于存储每个片段的长度。
    - 遍历字符串 `s`，索引从 `i = 0` 到 `n - 1`：
        - **更新片段边界：** 对于当前字符 `s[i]`，查询其最后出现的位置 `last_occurrence[s[i]]`。更新当前片段必须延伸到的最远索引 `end = max(end, last_occurrence[s[i]])`。
        - **判断片段结束：** 如果当前遍历的索引 `i` 刚好等于 `end`，这意味着从 `start` 到 `i` 的这个子串 `s[start...i]` 包含了其中所有字符的最后一次出现。这是一个有效的、尽可能短的片段。
            - 计算片段长度：`size = i - start + 1`。
            - 将长度添加到结果列表：`result.append(size)`。
            - 更新下一个片段的起始位置：`start = i + 1`。
3.  **返回结果：** 遍历结束后，返回 `result` 列表。

**为什么这个贪心策略有效？**
- 我们希望片段尽可能短。
- 对于从 `start` 开始的片段，它必须至少延伸到 `end` 位置，其中 `end` 是 `s[start...i]` 中所有字符最后出现位置的最大值。
- 当 `i == end` 时，我们找到了一个满足条件的最小片段。因为如果片段在 `i` 之前结束，那么 `s[i]`（或 `s[start...i]` 中的某个字符）的最后一次出现就会落在片段之外，违反了约束。而如果片段延伸到 `i` 之后，它就不是最短的了。
- 因此，在 `i == end` 时切分，可以保证当前片段最短，从而使得后续能划分出尽可能多的片段。

### 3. 代码实现 (Python - 贪心)

```python
from typing import List

class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        """
        使用贪心算法划分字母区间。
        """
        n = len(s)
        if n == 0:
            return []
            
        # 1. 预处理：记录每个字符最后出现的位置
        last_occurrence = {char: i for i, char in enumerate(s)}
        # 或者使用数组：
        # last_occurrence_arr = [0] * 26
        # for i, char in enumerate(s):
        #     last_occurrence_arr[ord(char) - ord('a')] = i
            
        result = []
        start = 0 # 当前片段的起始索引
        end = 0   # 当前片段需要到达的最远索引
        
        # 2. 划分片段
        for i in range(n):
            # 更新当前片段需要到达的最远索引
            current_char_last_occurrence = last_occurrence[s[i]]
            # current_char_last_occurrence = last_occurrence_arr[ord(s[i]) - ord('a')]
            end = max(end, current_char_last_occurrence)
            
            # 如果当前索引到达了片段的终点
            if i == end:
                # 找到了一个片段
                size = i - start + 1
                result.append(size)
                # 更新下一个片段的起始位置
                start = i + 1
                # end 会在下一次循环开始时根据 s[start] 的 last_occurrence 自然更新
                
        return result

# 示例调用
# sol = Solution()
# print(sol.partitionLabels("ababcbacadefegdehijhklij")) # [9, 7, 8]
# print(sol.partitionLabels("eccbbbbdec"))             # [10]
# print(sol.partitionLabels("a"))                     # [1]
```

### 4. 复杂度分析

- **时间复杂度：** O(N)。第一次遍历记录最后出现位置需要 O(N)。第二次遍历划分片段需要 O(N)。
- **空间复杂度：** O(M)，其中 M 是字符集的大小。用于存储 `last_occurrence`。由于字符集是小写字母，M=26，所以空间复杂度是 O(1)。结果列表的空间不计入额外空间复杂度。

### 5. 如何在面试中讲解

1.  **问题理解**：
    - "目标是将字符串划分成最多的片段，要求每个字母只出现在一个片段中。"
    - "关键约束：如果一个片段包含字母 'x'，那么字符串中所有的 'x' 都必须在这个片段里。"
2.  **核心思路：贪心**：
    - "为了最大化片段数量，每个片段应该尽可能短。"
    - "考虑一个片段的开始 `start`。这个片段必须延伸到多远？它必须包含从 `start` 开始遇到的所有字符的最后一次出现位置。"
3.  **算法流程**：
    - "**预处理:** 先遍历一次字符串，记录每个字符最后出现的位置 `last_occurrence`。"
    - "**划分:**
        - 初始化 `start = 0`, `end = 0`, `result = []`。
        - 再次遍历字符串，索引为 `i`。
        - 在每一步 `i`，我们查看当前字符 `s[i]` 的最后出现位置 `last[s[i]]`。用这个位置更新当前片段必须达到的最远边界 `end = max(end, last[s[i]])`。
        - **判断切分点:** 如果当前索引 `i` 恰好等于 `end`，说明从 `start` 到 `i` 的所有字符，它们的最后出现位置都在 `[start, i]` 这个区间内。我们找到了一个最短的有效片段。
        - 记录片段长度 `i - start + 1` 到 `result`。
        - 更新下一个片段的起始点 `start = i + 1`。"
    - "返回 `result`。"
4.  **正确性解释**：
    - "在 `i == end` 时切分是贪心的。因为片段必须至少延伸到 `end`，而在 `i == end` 时切分可以确保当前片段是满足条件的最小片段，为后续划分留下最大的空间，从而使总片段数最多。"
5.  **代码演示与复杂度**：
    - "展示两遍遍历的代码（预处理 + 划分）。"
    - "时间复杂度 O(N)。"
    - "空间复杂度 O(1)（因为字符集大小固定）。"
