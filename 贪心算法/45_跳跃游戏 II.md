给定一个长度为 `n` 的 **0 索引**整数数组 `nums`。初始位置为 `nums[0]`。

每个元素 `nums[i]` 表示从索引 `i` 向前跳转的最大长度。换句话说，如果你在 `nums[i]` 处，你可以跳转到任意 `nums[i + j]` 处:

*   `0 <= j <= nums[i]`
*   `i + j < n`

返回到达 `nums[n - 1]` 的最小跳跃次数。生成的测试用例可以到达 `nums[n - 1]`。

**示例 1:**

```
输入: nums = [2,3,1,1,4]
输出: 2
解释: 跳到最后一个位置的最小跳跃次数是 2。
     从下标为 0 跳到下标为 1 的位置，跳 1 步，然后跳 3 步到达数组的最后一个位置。
```

**示例 2:**

```
输入: nums = [2,3,0,1,4]
输出: 2
```

**提示:**

*   `1 <= nums.length <= 10^4`
*   `0 <= nums[i] <= 1000`
*   题目保证可以到达 `nums[n-1]`

## 解决方法

### 1. 问题理解

**目标：** 找到从数组第一个位置（索引 0）跳到最后一个位置（索引 `n-1`）所需的**最小跳跃次数**。
**规则：** 在索引 `i` 处，最多可以向前跳 `nums[i]` 步。
**保证：** 题目保证终点总是可达的。
**输入：** 非负整数数组 `nums`。
**输出：** 一个整数，表示最小跳跃次数。

### 2. 思路分析 (贪心算法)

与 "跳跃游戏 I" 不同，这里我们不仅要判断是否可达，还要计算最小的跳跃次数。我们可以采用贪心策略，在每一步都选择能够跳到**最远位置**的那个点。

**核心思想：**
- 维护当前这一步能够到达的最远距离 `current_max_reach`。
- 维护下一步能够到达的最远距离 `next_max_reach`。
- 记录跳跃次数 `jumps`。

**算法流程：**
1.  **初始化：**
    - 跳跃次数 `jumps = 0`。
    - 当前这一步能到达的最远索引 `current_max_reach = 0`。
    - 下一步能到达的最远索引 `next_max_reach = 0`。
    - 数组长度 `n = len(nums)`。
2.  **遍历数组：** 遍历数组 `nums`，索引从 `i = 0` 到 `n - 2` (因为当 `i` 到达 `n-1` 时已经到达终点，不需要再跳了)。
    - **更新下一步的最远距离：** 在当前位置 `i`，它可以跳到的最远距离是 `i + nums[i]`。我们用这个距离来更新 `next_max_reach`，取当前 `next_max_reach` 和 `i + nums[i]` 中的较大值。即 `next_max_reach = max(next_max_reach, i + nums[i])`。这代表了从当前这一步覆盖的范围内所有点出发，下一步能跳到的最远位置。
    - **判断是否需要跳跃：** 当遍历到索引 `i` 等于 `current_max_reach` 时，意味着我们已经到达了当前这一步所能走到的最远边界。此时，必须进行下一次跳跃才能继续前进。
        - 增加跳跃次数 `jumps += 1`。
        - 更新当前这一步能到达的最远距离为之前计算好的 `next_max_reach`，即 `current_max_reach = next_max_reach`。
        - **提前结束判断 (可选优化)：** 如果此时 `current_max_reach` 已经大于或等于 `n - 1`，说明下一步就能到达终点，可以直接返回 `jumps`。
3.  **返回结果：** 遍历结束后，`jumps` 就是到达终点的最小跳跃次数。

**为什么这个贪心策略有效？**
- 我们每次跳跃的目标是使得下一次跳跃的起点尽可能远，从而覆盖更大的范围。
- `current_max_reach` 代表了第 `jumps` 次跳跃能够到达的最远边界。
- `next_max_reach` 则是在第 `jumps` 次跳跃覆盖的范围 `[..., current_max_reach]` 内，所有点进行第 `jumps + 1` 次跳跃所能到达的最远边界。
- 当 `i` 到达 `current_max_reach` 时，我们必须进行第 `jumps + 1` 次跳跃，并且这次跳跃的最优选择就是跳到能使下一次（第 `jumps + 2` 次）跳得最远的位置，这个信息已经存储在 `next_max_reach` 中。
- 通过这种方式，每一步都选择能达到最远距离的跳跃，保证了以最少的步数覆盖到终点。

### 3. 代码实现 (Python - 贪心)

```python
from typing import List

class Solution:
    def jump(self, nums: List[int]) -> int:
        """
        使用贪心算法计算到达最后一个下标的最小跳跃次数。
        """
        n = len(nums)
        if n <= 1:
            return 0 # 如果只有一个元素或为空，不需要跳跃
            
        jumps = 0               # 跳跃次数
        current_max_reach = 0   # 当前这一跳能到达的最远索引
        next_max_reach = 0      # 通过当前这一跳覆盖的范围，下一步能到达的最远索引
        
        # 遍历到倒数第二个元素即可，因为到达 n-1 就结束了
        for i in range(n - 1): 
            # 更新下一步能到达的最远距离
            next_max_reach = max(next_max_reach, i + nums[i])
            
            # 如果到达了当前这一跳的边界
            if i == current_max_reach:
                # 进行下一次跳跃
                jumps += 1
                # 更新下一跳的边界
                current_max_reach = next_max_reach
                # 优化：如果下一跳的边界已经覆盖终点，可以直接返回
                if current_max_reach >= n - 1:
                    return jumps
                    
        # 由于题目保证能到达终点，循环结束后 jumps 就是结果
        # 正常情况下循环会因为 current_max_reach >= n - 1 而提前结束
        return jumps 

# 示例调用

# print(sol.jump([1,1,1,1]))   # 3
# print(sol.jump([1]))         # 0
```

### 4. 复杂度分析

- **时间复杂度：** O(N)，只需要一次遍历数组。
- **空间复杂度：** O(1)，只需要常数个额外变量。
