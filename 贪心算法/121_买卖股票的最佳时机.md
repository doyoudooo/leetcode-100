给定一个数组 `prices` ，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择 **某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0` 。

**示例 1：**

```
输入：[7,1,5,3,6,4]
输出：5
解释：在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。
     注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格。
```

**示例 2：**

```
输入：prices = [7,6,4,3,1]
输出：0
解释：在这种情况下, 没有交易完成, 所以最大利润为 0。
```

**提示：**

*   `1 <= prices.length <= 10^5`
*   `0 <= prices[i] <= 10^4`

## 解决方法

### 1. 问题理解

**目标：** 找到在给定价格数组 `prices` 中，通过一次买入和一次卖出（买入必须在卖出之前）所能获得的最大利润。
**输入：** 股票价格数组 `prices`。
**输出：** 最大利润，如果无法获利则为 0。

### 2. 思路分析

#### 方法一：暴力法 (超时)

遍历所有可能的买入和卖出组合。对于每个买入日 `i`，遍历其后的所有卖出日 `j` (`j > i`)，计算利润 `prices[j] - prices[i]`，并找到其中的最大值。

**复杂度分析:**
- 时间复杂度：O(N^2)，两层循环。
- 空间复杂度：O(1)。
- 对于 N <= 10^5 的数据规模，O(N^2) 会超时。

#### 方法二：贪心思想 (一次遍历)

我们希望在历史最低点买入，然后在之后的某一天卖出以获得最大利润。

**算法流程：**
1.  **初始化：**
    - 记录迄今为止遇到的最低价格 `min_price`，初始值为第一天的价格 `prices[0]` (或者一个非常大的数 `float('inf')`)。
    - 记录迄今为止获得的最大利润 `max_profit`，初始值为 0。
2.  **遍历价格数组：** 从第二天开始（或第一天，如果 `min_price` 初始化为极大值）遍历 `prices` 数组：
    - 对于当前价格 `current_price = prices[i]`：
        - **计算潜在利润：** 计算如果今天卖出，能获得的利润 `potential_profit = current_price - min_price`。
        - **更新最大利润：** 更新 `max_profit = max(max_profit, potential_profit)`。
        - **更新最低价格：** 更新 `min_price = min(min_price, current_price)`。
3.  **返回结果：** 遍历结束后，`max_profit` 就是所能获得的最大利润。

**为什么这个贪心策略有效？**
- 我们在遍历过程中，始终维护着 `[0...i]` 区间内的最低价格 `min_price`。
- 对于第 `i` 天的价格 `prices[i]`，如果在今天卖出，那么为了利润最大化，买入点必然是 `[0...i-1]` 中的最低点，也就是我们维护的 `min_price`。
- `prices[i] - min_price` 就代表了在第 `i` 天卖出可能获得的最大利润。
- 我们只需要在遍历过程中不断更新这个可能的最大利润，最终得到全局的最大利润。

### 3. 代码实现 (Python - 贪心)

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        """
        使用贪心思想计算最大利润。
        """
        if not prices or len(prices) < 2:
            return 0
            
        min_price = float('inf') # 记录历史最低价格
        max_profit = 0           # 记录最大利润
        
        for price in prices:
            # 更新最低价格
            min_price = min(min_price, price)
            # 更新最大利润 (今天卖出的利润 vs 之前的最大利润)
            max_profit = max(max_profit, price - min_price)
            
        return max_profit

# 示例调用

# print(sol.maxProfit([7,6,4,3,1])) # 0
```

### 4. 复杂度分析

- **时间复杂度：** O(N)，只需要一次遍历价格数组。
- **空间复杂度：** O(1)，只需要常数个额外变量。
