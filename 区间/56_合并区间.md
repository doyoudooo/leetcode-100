以数组 `intervals` 表示若干个区间的集合，其中 `intervals[i] = [start_i, end_i]` 。请你合并所有重叠的区间，并返回 *一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间* 。

**示例 1：**

```
输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
解释：区间 [1,3] 和 [2,6] 重叠, 将它们合并为 [1,6].
```

**示例 2：**

```
输入：intervals = [[1,4],[4,5]]
输出：[[1,5]]
解释：区间 [1,4] 和 [4,5] 可被视为重叠区间。
```

**提示：**

*   `1 <= intervals.length <= 10^4`
*   `intervals[i].length == 2`
*   `0 <= start_i <= end_i <= 10^4`

## 解决方法

### 1. 问题理解

**目标：** 合并给定的区间列表中所有重叠的区间。
**输入：** 一个区间列表 `intervals`，每个区间表示为 `[start, end]`。
**输出：** 一个新的区间列表，其中所有重叠区间已被合并，且覆盖了原始所有区间。
**重叠定义：** 两个区间 `[a, b]` 和 `[c, d]` 重叠，如果它们有共同的部分。例如，`b >= c` (假设 `a <= c`)。特别地，`[1, 4]` 和 `[4, 5]` 也视为重叠。

### 2. 思路分析

合并区间的关键在于**排序**。如果我们按区间的起始点进行排序，那么可以合并的区间一定会出现在相邻的位置。

**算法流程：**
1.  **排序：** 将 `intervals` 数组按照每个区间的起始点 `start_i` 升序排序。
2.  **初始化结果：** 创建一个空列表 `merged` 用于存储合并后的区间。将排序后的第一个区间加入 `merged`。
3.  **遍历与合并：** 从排序后的第二个区间开始遍历：
    - 获取当前区间 `current_interval = [current_start, current_end]`。
    - 获取 `merged` 列表中的最后一个区间 `last_merged_interval = [last_start, last_end]`。
    - **检查重叠：** 如果 `current_start <= last_end` (当前区间的起始点小于等于上一个合并区间的结束点)，说明它们重叠或相邻。
        - **合并：** 更新 `merged` 中最后一个区间的结束点为 `max(last_end, current_end)`。即 `merged[-1][1] = max(last_end, current_end)`。
    - **不重叠：** 如果 `current_start > last_end`，说明当前区间与上一个合并区间不重叠，将 `current_interval` 作为一个新的区间添加到 `merged` 列表中。
4.  **返回结果：** 遍历结束后，`merged` 列表即为最终合并后的结果。

### 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        """
        合并重叠区间。
        Args:
            intervals: 区间列表，每个区间为 [start, end]。
        Returns:
            合并后的不重叠区间列表。
        """
        if not intervals:
            return []
            
        # 1. 按起始点排序 O(N log N)
        intervals.sort(key=lambda x: x[0])
        
        # 2. 初始化结果列表
        merged = [intervals[0]]
        
        # 3. 遍历与合并 O(N)
        for i in range(1, len(intervals)):
            current_start, current_end = intervals[i]
            last_start, last_end = merged[-1]
            
            # 检查是否重叠
            if current_start <= last_end:
                # 重叠，更新上一个合并区间的结束点
                merged[-1][1] = max(last_end, current_end)
            else:
                # 不重叠，添加新区间
                merged.append([current_start, current_end])
                
        return merged
```

### 4. 复杂度分析

- **时间复杂度：** O(N log N)。主要瓶颈在于排序。遍历合并的过程是 O(N)。
- **空间复杂度：** O(log N) 或 O(N)。
    - 排序算法可能需要 O(log N) (快速排序平均) 或 O(N) (归并排序) 的额外空间（取决于具体实现和语言）。
    - 结果列表 `merged` 最坏情况下需要 O(N) 空间（如果没有区间可以合并）。
