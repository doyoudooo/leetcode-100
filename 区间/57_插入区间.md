给你一个 **无重叠的** ，按照区间起始端点排序的区间列表 `intervals`，其中 `intervals[i] = [start_i, end_i]` 表示第 `i` 个区间的开始和结束，并且 `intervals[i]` 按 `start_i` 升序排列。同样给定一个区间 `newInterval = [start, end]` 表示另一个区间的开始和结束。

在 `intervals` 中插入 `newInterval`，使得 `intervals` 依然按照 `start_i` 升序排列，且区间之间不重叠（如果有必要的话，可以合并区间）。

返回插入之后的 `intervals`。

**示例 1：**

```
输入：intervals = [[1,3],[6,9]], newInterval = [2,5]
输出：[[1,5],[6,9]]
```

**示例 2：**

```
输入：intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]], newInterval = [4,8]
输出：[[1,2],[3,10],[12,16]]
解释：这是因为新的区间 [4,8] 与 [3,5],[6,7],[8,10] 重叠。
```

**示例 3：**

```
输入：intervals = [], newInterval = [5,7]
输出：[[5,7]]
```

**示例 4：**

```
输入：intervals = [[1,5]], newInterval = [2,3]
输出：[[1,5]]
```

**示例 5：**

```
输入：intervals = [[1,5]], newInterval = [2,7]
输出：[[1,7]]
```

**提示：**

*   `0 <= intervals.length <= 10^4`
*   `intervals[i].length == 2`
*   `0 <= start_i <= end_i <= 10^5`
*   `intervals` 按 `start_i` 升序排列
*   `newInterval.length == 2`
*   `0 <= start <= end <= 10^5`

## 解决方法

### 1. 问题理解

**目标：** 将一个新的区间 `newInterval` 插入到一个已排序（按起始点升序）且不重叠的区间列表 `intervals` 中，并合并必要的区间，使得最终列表仍然有序且不重叠。
**输入：**
- `intervals`: 已排序、不重叠的区间列表。
- `newInterval`: 要插入的新区间。
**输出：** 插入并合并后的区间列表。

### 2. 思路分析

由于 `intervals` 已经按起始点排序，我们可以利用这个特性来高效地找到 `newInterval` 的插入位置以及需要合并的区间。

我们可以将整个过程分为三个阶段：

1.  **处理 `newInterval` 之前的区间：** 遍历 `intervals`，将所有结束点严格小于 `newInterval` 起始点的区间直接加入结果列表 `result`。这些区间肯定在 `newInterval` 之前且不重叠。
2.  **处理与 `newInterval` 重叠的区间：** 继续遍历 `intervals`，找到所有与 `newInterval` 重叠的区间。将 `newInterval` 与这些重叠区间合并成一个新的大区间。合并的逻辑是：
    - 新区间的起始点是 `min(newInterval.start, overlapping_interval.start)`。
    - 新区间的结束点是 `max(newInterval.end, overlapping_interval.end)`。
    - 不断更新这个合并后的 `newInterval`，直到遇到第一个不重叠的区间。
    - 将最终合并好的 `newInterval` 加入结果列表 `result`。
3.  **处理 `newInterval` 之后的区间：** 将 `intervals` 中剩余的（即起始点严格大于合并后 `newInterval` 结束点的）区间直接加入结果列表 `result`。

**简化思路 (一次遍历)：**
我们可以用一次遍历来完成这个过程。

1.  **初始化：** 创建结果列表 `result`。设置一个索引 `i` 遍历 `intervals`。
2.  **添加不重叠的前缀：** 遍历 `intervals`，只要当前区间 `intervals[i]` 的结束点 `intervals[i][1]` 小于 `newInterval[0]`，就将 `intervals[i]` 加入 `result`，并递增 `i`。
3.  **合并重叠区间：** 继续遍历 `intervals`，只要当前区间 `intervals[i]` 的起始点 `intervals[i][0]` 小于等于 `newInterval[1]`，说明存在重叠。更新 `newInterval` 的边界：
    - `newInterval[0] = min(newInterval[0], intervals[i][0])`
    - `newInterval[1] = max(newInterval[1], intervals[i][1])`
    - 递增 `i`。
    - 循环结束后，`newInterval` 已经包含了所有与之重叠的区间。将这个合并后的 `newInterval` 加入 `result`。
4.  **添加不重叠的后缀：** 将 `intervals` 中剩余的区间（从当前索引 `i` 开始）全部加入 `result`。
5.  **返回结果：** 返回 `result`。

### 3. 代码实现 (Python - 简化思路)

```python
from typing import List

class Solution:
    def insert(self, intervals: List[List[int]], newInterval: List[int]) -> List[List[int]]:
        """
        插入新区间并合并重叠区间。
        Args:
            intervals: 已排序、不重叠的区间列表。
            newInterval: 要插入的新区间。
        Returns:
            插入并合并后的区间列表。
        """
        result = []
        n = len(intervals)
        i = 0
        
        # 1. 添加所有在 newInterval 之前的区间
        while i < n and intervals[i][1] < newInterval[0]:
            result.append(intervals[i])
            i += 1
            
        # 2. 合并所有与 newInterval 重叠的区间
        #    当前 intervals[i] 的结束点 >= newInterval 的起始点
        #    并且 intervals[i] 的起始点 <= newInterval 的结束点
        while i < n and intervals[i][0] <= newInterval[1]:
            # 更新 newInterval 的边界以包含当前区间
            newInterval[0] = min(newInterval[0], intervals[i][0])
            newInterval[1] = max(newInterval[1], intervals[i][1])
            i += 1
            
        # 将合并后的 newInterval 加入结果
        result.append(newInterval)
        
        # 3. 添加所有在 newInterval 之后的区间
        while i < n:
            result.append(intervals[i])
            i += 1
            
        return result
```

### 4. 复杂度分析

- **时间复杂度：** O(N)。只需要一次遍历 `intervals` 列表。
- **空间复杂度：** O(N)。需要一个额外的列表 `result` 来存储结果，最坏情况下包含 N+1 个区间（如果 `newInterval` 不与任何区间合并）。
