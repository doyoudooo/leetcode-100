给定一个区间的集合 `intervals` ，其中 `intervals[i] = [start_i, end_i]` 。返回 *需要移除区间的最小数量，使剩余区间互不重叠* 。

**示例 1:**

```
输入: intervals = [[1,2],[2,3],[3,4],[1,3]]
输出: 1
解释: 移除 [1,3] 后，剩下的区间没有重叠。
```

**示例 2:**

```
输入: intervals = [ [1,2], [1,2], [1,2] ]
输出: 2
解释: 你需要移除两个 [1,2] 来使剩下的区间没有重叠。
```

**示例 3:**

```
输入: intervals = [ [1,2], [2,3] ]
输出: 0
解释: 你不需要移除任何区间，因为它们已经是无重叠的了。
```

**提示:**

*   `1 <= intervals.length <= 10^5`
*   `intervals[i].length == 2`
*   `-5 * 10^4 <= start_i < end_i <= 5 * 10^4`

## 解决方法

### 1. 问题理解

**目标：** 给定一组区间，找到需要移除的最少区间数量，使得剩下的区间互不重叠。
**等价问题：** 找到这组区间中**最多**能选择多少个互不重叠的区间。移除的数量 = 总区间数 - 最多可选的不重叠区间数。
**不重叠定义：** 两个区间 `[a, b]` 和 `[c, d]` 不重叠，如果 `b <= c` 或 `d <= a`。注意，边界接触不算重叠，例如 `[1,2]` 和 `[2,3]` 不算重叠。

### 2. 思路分析 (贪心算法)

这是一个典型的区间调度问题，可以使用贪心算法解决。关键在于确定贪心的策略：按什么标准排序，以及如何选择区间？

**贪心策略：按结束点排序**

1.  **排序：** 将所有区间按照**结束点 `end_i`** 升序排序。如果结束点相同，按起始点升序排序（虽然对于本题，结束点相同时按起始点排序与否影响不大，但这是个好习惯）。
2.  **选择：**
    - 选择第一个区间（结束点最早的区间）作为第一个不重叠区间。
    - 遍历排序后的剩余区间：
        - 对于当前区间 `current_interval`，如果它的起始点 `current_start` **大于等于** 上一个选定区间的结束点 `last_selected_end`，说明当前区间与上一个选定的区间不重叠。
        - 那么，选择当前区间作为下一个不重叠区间，并更新 `last_selected_end` 为当前区间的结束点。
        - 如果 `current_start < last_selected_end`，说明当前区间与上一个选定的区间重叠，**跳过**（即移除）当前区间。
3.  **计数：** 统计总共选了多少个不重叠的区间 `count`。
4.  **计算结果：** 需要移除的区间数量 = `总区间数 n - count`。

**为什么按结束点排序是有效的？**
- 目标是尽可能多地选择不重叠的区间。
- 按结束点排序，优先选择结束点早的区间，可以为后面的区间留出更多的空间，从而更有可能选择更多的区间。
- 假设我们选择了区间 `i`（它的结束点是当前可选区间中最早的）。对于任何与 `i` 重叠的区间 `j`，`j` 的结束点必然大于等于 `i` 的结束点。如果我们选择 `j` 而不是 `i`，那么 `j` 占用的时间段更长（或一样长），留给后续区间的空间不会比选择 `i` 更多。因此，选择结束点最早的区间 `i` 是最优（或至少不差于）选择任何与它重叠的区间 `j`。

**另一种贪心策略（错误）：按起始点排序**
如果按起始点排序，选择第一个区间后，遇到重叠区间时，我们无法确定是保留当前区间还是移除它更好。例如 `[[1,10], [2,3], [3,4]]`，按起始点排序后是 `[[1,10], [2,3], [3,4]]`。如果选择 `[1,10]`，后面两个都不能选，总共选 1 个。但最优是选 `[2,3]` 和 `[3,4]`，总共选 2 个。

### 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def eraseOverlapIntervals(self, intervals: List[List[int]]) -> int:
        """
        计算需要移除的最小区间数量，使剩余区间不重叠。
        Args:
            intervals: 区间列表。
        Returns:
            需要移除的最小区间数量。
        """
        if not intervals:
            return 0
            
        n = len(intervals)
        
        # 1. 按结束点升序排序 O(N log N)
        intervals.sort(key=lambda x: x[1])
        
        # 2. 贪心选择不重叠区间
        count = 1 # 至少选择第一个区间
        last_selected_end = intervals[0][1]
        
        for i in range(1, n):
            current_start = intervals[i][0]
            # 如果当前区间的起始点 >= 上一个选定区间的结束点
            if current_start >= last_selected_end:
                # 选择当前区间
                count += 1
                last_selected_end = intervals[i][1]
            # else: # 重叠，跳过（相当于移除）当前区间
                
        # 3. 计算需要移除的数量
        removed_count = n - count
        return removed_count

#   [1,100]: 1 < 22, 跳过

```

### 4. 复杂度分析

- **时间复杂度：** O(N log N)。主要瓶颈在于按结束点排序。贪心选择的过程是 O(N)。
- **空间复杂度：** O(log N) 或 O(N)。取决于排序算法使用的空间。
