给定一个会议时间安排的数组 `intervals` ，每个会议时间都会包括开始和结束的时间 `intervals[i] = [start_i, end_i]` ，请你判断一个人是否能够参加这里面的全部会议。

**示例 1：**

```
输入：intervals = [[0,30],[5,10],[15,20]]
输出：false
解释：[0,30] 和 [5,10] 重叠；[0,30] 和 [15,20] 重叠。
```

**示例 2：**

```
输入：intervals = [[7,10],[2,4]]
输出：true
解释：两个区间没有重叠。
```

**提示：**

*   `0 <= intervals.length <= 10^4`
*   `intervals[i].length == 2`
*   `0 <= start_i < end_i <= 10^6`

---

## 解决方法

### 1. 问题理解

**目标：** 判断给定的所有会议时间是否存在重叠。如果存在任何重叠，则一个人无法参加所有会议，返回 `False`；否则返回 `True`。
**输入：** 一个区间列表 `intervals`，代表会议的起止时间。
**输出：** `True` 或 `False`。
**重叠定义：** 两个会议 `[s1, e1]` 和 `[s2, e2]` 重叠，如果它们的时间段有交集。例如，`s1 < e2` 且 `s2 < e1`。

### 2. 思路分析 (排序检查)

判断是否有重叠的最直接方法是先对会议进行排序，然后检查相邻的会议是否有时间冲突。

**算法流程：**
1.  **排序：** 将 `intervals` 数组按照会议的**起始时间 `start_i`** 升序排序。
2.  **检查相邻区间：** 遍历排序后的 `intervals` 列表，从第二个会议开始（索引 `i = 1`）：
    - 获取当前会议 `current_interval = [current_start, current_end]`。
    - 获取上一个会议 `previous_interval = [previous_start, previous_end]` (即 `intervals[i-1]`)。
    - **检查重叠：** 如果当前会议的起始时间 `current_start` **严格小于** 上一个会议的结束时间 `previous_end` (`current_start < previous_end`)，说明这两个会议时间有重叠。
    - 一旦发现重叠，立即返回 `False`。
3.  **无重叠：** 如果遍历完所有相邻会议都没有发现重叠，说明所有会议时间都不冲突，返回 `True`。

**为什么按起始时间排序有效？**
- 按起始时间排序后，如果存在重叠，那么重叠的会议一定会在排序后的列表中相邻或者相近。
- 我们只需要检查每个会议 `i` 是否与其紧邻的前一个会议 `i-1` 重叠即可。因为如果会议 `i` 与更早的会议 `j` (`j < i-1`) 重叠，那么由于 `intervals[i-1].start >= intervals[j].start`，会议 `i` 必然也与会议 `i-1` 重叠（或者 `i-1` 与 `j` 重叠，这在检查 `i-1` 时会被发现）。
- 具体来说，如果 `intervals[i].start < intervals[i-1].end`，则必然重叠。

### 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def canAttendMeetings(self, intervals: List[List[int]]) -> bool:
        """
        判断是否可以参加所有会议 (即是否存在重叠区间)。
        Args:
            intervals: 会议时间列表 [[start, end], ...]
        Returns:
            True 如果可以参加所有会议 (无重叠)，False 如果存在重叠。
        """
        if not intervals or len(intervals) < 2:
            return True # 0 或 1 个会议，肯定不重叠
            
        # 1. 按起始时间排序 O(N log N)
        intervals.sort(key=lambda x: x[0])
        
        # 2. 检查相邻区间是否有重叠 O(N)
        for i in range(1, len(intervals)):
            current_start = intervals[i][0]
            previous_end = intervals[i-1][1]
            
            # 如果当前会议开始时间早于上一个会议的结束时间，则重叠
            if current_start < previous_end:
                return False
                
        # 遍历完成，没有发现重叠
        return True

# 示例调用

# print(sol.canAttendMeetings(intervals = [[13,15],[1,13]]))       # True (边界接触不算重叠)
```

### 4. 复杂度分析

- **时间复杂度：** O(N log N)。主要瓶颈在于排序。检查重叠的过程是 O(N)。
- **空间复杂度：** O(log N) 或 O(N)。取决于排序算法使用的空间。
