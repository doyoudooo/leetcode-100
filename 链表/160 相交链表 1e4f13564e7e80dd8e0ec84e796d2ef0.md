# LeetCode 160: 相交链表（详细解析）

## 1. 问题理解

**目标：** 找出两个单链表的第一个相交节点。

**输入：**

- 两个单链表的头节点 `headA` 和 `headB`

**输出：**

- 如果两个链表相交，返回相交的第一个节点
- 如果两个链表不相交，返回 `null`

**相交定义：**

- 两个链表有一个公共节点，且从该节点开始直到链表结束，路径完全相同
- 这意味着两个链表在相交节点后共享完全相同的节点（不仅仅是值相同，而是节点引用相同）

**约束条件：**

- 不允许修改链表结构
- 时间复杂度应为 O(m+n)，空间复杂度应为 O(1)
- 链表中节点数量范围为 [0, 10^4]

## 2. 普通人的思路（及遇到的困难）

### 思路一：使用哈希集合

**想法：** 把第一个链表的所有节点存入哈希集合，然后检查第二个链表的每个节点是否在集合中。

**实现步骤：**

1. 创建一个哈希集合 `set`
2. 遍历链表 A，将每个节点加入 `set`
3. 遍历链表 B，对于每个节点，检查它是否在 `set` 中
4. 如果在，则该节点是相交点，返回它
5. 如果遍历完 B 也没找到，则返回 `null`

**复杂度：**

- 时间复杂度：O(m+n)
- 空间复杂度：O(m)，其中 m 是链表 A 的长度

**缺点：** 需要额外的 O(m) 空间，不满足题目的空间 O(1) 要求。

### 思路二：测量链表长度

**想法：** 计算两个链表的长度差，让较长的链表先走差值步数，然后同时遍历两个链表寻找相同节点。

**实现步骤：**

1. 计算链表 A 和链表 B 的长度
2. 计算两链表的长度差 `diff`
3. 让较长的链表先走 `diff` 步
4. 然后两个链表同时前进，比较每一对节点是否相同
5. 第一个相同的节点就是相交点

**复杂度：**

- 时间复杂度：O(m+n)
- 空间复杂度：O(1)

**缺点：** 实现较为繁琐，需要多次遍历链表。

## 3. 更优雅的方法（双指针技巧）

**核心思想：** 使用两个指针 `pA` 和 `pB`，让它们分别从链表 A 和链表 B 的头部开始遍历。当一个指针到达链表末尾时，将它重定向到另一个链表的头部，继续遍历。

**为什么这样有效？**

- 假设链表 A 长度为 a，链表 B 长度为 b，相交部分长度为 c。
- 不相交的部分长度分别为：a-c 和 b-c。
- 指针 `pA` 的路径：遍历链表 A(a步) + 遍历链表 B(b步) = a+b步
- 指针 `pB` 的路径：遍历链表 B(b步) + 遍历链表 A(a步) = b+a步
- 两个指针走过的总路径长度相同，都是 a+b 步
- 如果有相交点，两个指针必然会在相交点相遇
- 如果没有相交点，两个指针最终都会到达 `null`

**图解：**

```
链表A: a1 → a2 → c1 → c2 → c3
             ↗
链表B: b1 → b2

```

- 指针 `pA` 的路径：a1 → a2 → c1 → c2 → c3 → b1 → b2 → c1 ...
- 指针 `pB` 的路径：b1 → b2 → c1 → c2 → c3 → a1 → a2 → c1 ...
- 两个指针会在第一个相交节点 c1 处相遇

## 4. 示例演示（双指针法）

以示例 1 为例：

```
链表A: 4 → 1 → 8 → 4 → 5
                ↗
链表B: 5 → 6 → 1

```

1. `pA` 指向链表 A 的头节点(4)，`pB` 指向链表 B 的头节点(5)
2. `pA` 移动：4 → 1 → 8 → 4 → 5 → null，重置到链表 B 头节点：5
3. `pB` 移动：5 → 6 → 1 → 8 → 4 → 5 → null，重置到链表 A 头节点：4
4. `pA` 继续：5 → 6 → 1 → 8
5. `pB` 继续：4 → 1 → 8
6. 此时 `pA` 和 `pB` 都指向节点 8，这就是相交点

## 5. 代码实现

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) {
 *         val = x;
 *         next = null;
 *     }
 * }
 */
public class Solution {
    /**
     * 找出两个单链表的相交节点
     * 方法：双指针技巧
     * @param headA 第一个链表的头节点
     * @param headB 第二个链表的头节点
     * @return 相交节点，如果不存在则返回 null
     */
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        // 如果任一链表为空，不可能相交
        if (headA == null || headB == null) {
            return null;
        }

        // 初始化两个指针
        ListNode pA = headA;
        ListNode pB = headB;

        // 当 pA 和 pB 不相等时，继续移动
        while (pA != pB) {
            // 如果 pA 到达链表 A 的末尾，将其重定向到链表 B 的头部
            // 否则，pA 向后移动
            pA = (pA == null) ? headB : pA.next;

            // 如果 pB 到达链表 B 的末尾，将其重定向到链表 A 的头部
            // 否则，pB 向后移动
            pB = (pB == null) ? headA : pB.next;
        }

        // 此时 pA 和 pB 要么都指向相交节点，要么都是 null（如果不相交）
        return pA;
    }
}

```

## 6. 代码解析

**初始化：**

- 首先检查两个链表是否为空，如果任一链表为空，不可能有相交点。
- 初始化两个指针 `pA` 和 `pB`，分别指向链表 A 和链表 B 的头节点。

**主循环逻辑：**

- 当 `pA` 和 `pB` 不相等时，继续循环。
- 如果 `pA` 到达链表 A 的末尾（即 `pA == null`），将其重定向到链表 B 的头部；否则，`pA` 向后移动一步。
- 同样，如果 `pB` 到达链表 B 的末尾，将其重定向到链表 A 的头部；否则，`pB` 向后移动一步。

**循环终止条件：**

- 当 `pA == pB` 时，循环终止。
- 此时，`pA` 和 `pB` 要么都指向相交节点，要么都是 `null`（如果两个链表不相交）。

**返回值：**

- 返回 `pA`（或 `pB`，它们相等）作为相交节点，或者 `null` 表示没有相交。

## 7. 复杂度分析

**时间复杂度：** O(m + n)

- 在最坏情况下，每个指针都需要遍历两个链表各一次，总路径长度为 m+n
- 如果有相交点，两个指针可能提前相遇，实际复杂度可能小于 O(m+n)

**空间复杂度：** O(1)

- 只使用了两个指针变量 `pA` 和 `pB`，不依赖于输入规模的额外空间
