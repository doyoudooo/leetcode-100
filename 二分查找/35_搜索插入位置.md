给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

请必须使用时间复杂度为 `O(log n)` 的算法。

**示例 1:**

```
输入: nums = [1,3,5,6], target = 5
输出: 2
```

**示例 2:**

```
输入: nums = [1,3,5,6], target = 2
输出: 1
```

**示例 3:**

```
输入: nums = [1,3,5,6], target = 7
输出: 4
```

**提示:**

*   `1 <= nums.length <= 10^4`
*   `-10^4 <= nums[i] <= 10^4`
*   `nums` 为 **无重复元素** 的 **升序** 排列数组
*   `-10^4 <= target <= 10^4`

## 解决方法

### 1. 问题理解

**目标：** 在一个 **已排序** 且 **无重复元素** 的数组 `nums` 中：
1.  如果找到目标值 `target`，返回其索引。
2.  如果找不到 `target`，返回它应该被插入的位置，以保持数组的有序性。
**约束：** 必须使用 O(log n) 时间复杂度的算法。这强烈暗示了使用 **二分查找**。

### 2. 思路分析 (二分查找)

二分查找的核心是在有序数组中快速定位元素。这个问题可以转化为：**查找第一个大于或等于 `target` 的元素的索引**。

- 如果数组中存在 `target`，那么第一个大于或等于 `target` 的元素就是 `target` 本身，其索引就是我们要找的。
- 如果数组中不存在 `target`，那么第一个大于或等于 `target` 的元素的位置，就是 `target` 应该插入的位置。

**二分查找变种：查找下界 (Lower Bound)**

我们需要找到满足 `nums[index] >= target` 的最小 `index`。

**算法流程：**
1.  初始化左右指针：`left = 0`, `right = n` (注意 `right` 初始化为数组长度 `n`，而不是 `n-1`)。
    - 这样定义的搜索区间是 `[left, right)`，左闭右开。
    - 循环条件是 `left < right`。
    - `mid` 的计算是 `left + (right - left) // 2`。
2.  循环条件：`left < right`。
3.  计算中间索引 `mid = left + (right - left) // 2`。
4.  比较 `nums[mid]` 和 `target`：
    - **如果 `nums[mid] >= target`：**
        - 这意味着 `mid` 可能是我们要找的第一个大于或等于 `target` 的位置，或者答案在 `mid` 的左边。
        - 我们需要继续在左半部分（包括 `mid`）搜索，所以更新 `right = mid`。
    - **如果 `nums[mid] < target`：**
        - 这意味着 `mid` 以及 `mid` 左边的所有元素都小于 `target`。
        - 答案一定在 `mid` 的右边。
        - 我们需要继续在右半部分（不包括 `mid`）搜索，所以更新 `left = mid + 1`。
5.  循环结束条件：当 `left == right` 时，循环终止。
6.  返回结果：此时 `left` (或 `right`) 指向的就是第一个大于或等于 `target` 的元素的位置，也就是目标值应该在的位置或插入的位置。

**另一种常见的二分查找写法 (搜索区间 `[left, right]`，闭区间)：**
1.  初始化 `left = 0`, `right = n - 1`。
2.  循环条件：`left <= right`。
3.  计算 `mid = left + (right - left) // 2`。
4.  比较 `nums[mid]` 和 `target`：
    - **如果 `nums[mid] == target`：** 直接返回 `mid`。
    - **如果 `nums[mid] < target`：** 目标值在右侧，`left = mid + 1`。
    - **如果 `nums[mid] > target`：** 目标值在左侧，`right = mid - 1`。
5.  循环结束条件：当 `left > right` 时，循环终止。
6.  返回结果：如果循环结束时仍未找到 `target`，说明 `target` 不在数组中。此时 `left` 指针指向的位置就是 `target` 应该插入的位置。返回 `left`。

**为什么第二种写法的循环结束后 `left` 是插入位置？**
- 循环结束时 `left = right + 1`。
- 考虑最后一次循环：
    - 如果是 `nums[mid] < target` 导致 `left = mid + 1`，那么 `left` 指向的是第一个可能大于 `target` 的位置。
    - 如果是 `nums[mid] > target` 导致 `right = mid - 1`，那么 `left` 仍然保持在 `mid` 或其右侧，指向的是第一个大于 `target` 的位置。
- 最终 `left` 指向的是第一个大于 `target` 的元素的位置，或者如果 `target` 比所有元素都大，则 `left` 会变成 `n`。这正好是插入位置。

**推荐写法：**
第一种写法（查找下界）更通用，可以直接找到插入位置，无需区分 `target` 是否存在。

### 3. 代码实现 (Python - 二分查找)

#### 写法一：查找下界 (Lower Bound) - 推荐

```python
from typing import List

class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        """
        查找第一个大于或等于 target 的元素的索引 (Lower Bound)。
        搜索区间 [left, right)
        """
        left, right = 0, len(nums) # 注意 right 的初始值
        
        while left < right:
            mid = left + (right - left) // 2
            if nums[mid] >= target:
                # mid 可能是答案，或者答案在左边
                right = mid 
            else: # nums[mid] < target
                # 答案一定在 mid 右边
                left = mid + 1
                
        # 循环结束时，left (或 right) 就是插入位置
        return left 
```

#### 写法二：标准二分查找 + 处理未找到情况

```python
from typing import List

class Solution:
    def searchInsert_v2(self, nums: List[int], target: int) -> int:
        """
        标准二分查找，循环结束后返回 left。
        搜索区间 [left, right]
        """
        left, right = 0, len(nums) - 1
        
        while left <= right:
            mid = left + (right - left) // 2
            if nums[mid] == target:
                return mid
            elif nums[mid] < target:
                left = mid + 1
            else: # nums[mid] > target
                right = mid - 1
                
        # 循环结束，未找到 target，left 是插入位置
        return left
```

### 4. 复杂度分析

- **时间复杂度：** O(log N)，其中 N 是数组 `nums` 的长度。每次循环将搜索区间减半。
- **空间复杂度：** O(1)。只使用了常数个额外变量。
