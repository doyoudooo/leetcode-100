给你一个满足下述两条属性的 `m x n` 整数矩阵：

*   每行中的整数从左到右按非严格递增顺序排列。
*   每行的第一个整数大于前一行的最后一个整数。

给你一个整数 `target` ，如果 `target` 在矩阵中，返回 `true` ；否则，返回 `false` 。

**示例 1：**

![mat.jpg](https://assets.leetcode.com/uploads/2020/10/05/mat.jpg)

```
输入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3
输出：true
```

**示例 2：**

![mat2.jpg](https://assets.leetcode.com/uploads/2020/10/05/mat2.jpg)

```
输入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 13
输出：false
```

**提示：**

*   `m == matrix.length`
*   `n == matrix[i].length`
*   `1 <= m, n <= 100`
*   `-10^4 <= matrix[i][j], target <= 10^4`

## 解决方法

### 1. 问题理解

**目标：** 在一个特殊的 `m x n` 矩阵中查找目标值 `target`。
**矩阵特性：**
1.  **行内有序：** 每行从左到右递增。
2.  **行间有序：** 当前行的第一个元素大于上一行的最后一个元素。
**输入：** `m x n` 矩阵 `matrix`，目标值 `target`。
**输出：** 布尔值，`True` 如果 `target` 存在，`False` 否则。

**关键洞察：** 由于第二个特性（行间有序），整个矩阵可以看作是一个 **展开后的一维有序数组**。例如，示例 1 的矩阵可以看作 `[1, 3, 5, 7, 10, 11, 16, 20, 23, 30, 34, 60]`。

### 2. 思路分析

#### 方法一：两次二分查找 (O(log m + log n))

利用矩阵的两个有序特性。

1.  **定位行：**
    - 矩阵的每一行第一个元素构成一个升序序列（`matrix[0][0]`, `matrix[1][0]`, ..., `matrix[m-1][0]`）。
    - 我们可以对 **第一列** 进行二分查找，找到 **最后一个** 满足 `matrix[row][0] <= target` 的行 `row`。
    - 如果 `target` 存在，它必定在这一行 `row` 中（或者如果 `target` 小于 `matrix[0][0]`，则不存在）。
    - 注意边界：如果找不到这样的行（即 `target` 小于所有行的第一个元素），则 `target` 不存在。
2.  **定位列：**
    - 在确定了目标可能存在的行 `row` 之后，对该行 `matrix[row]` 进行标准的二分查找，看是否存在 `target`。

**算法流程 (两次二分)：**
1.  获取行数 `m` 和列数 `n`。处理空矩阵或空行的情况。
2.  **二分查找行：**
    - 对行的索引 `0` 到 `m-1` 进行二分查找。
    - 目标是找到最大的 `row_idx` 使得 `matrix[row_idx][0] <= target`。
    - 可以使用查找下界 (lower bound) 的变种，查找第一个 `matrix[row][0] > target` 的行，然后取其前一行。或者直接查找最后一个小于等于 `target` 的行。
    - 设找到的目标行为 `target_row`。如果找不到（`target` 比 `matrix[0][0]` 还小），返回 `False`。
3.  **二分查找列：**
    - 在 `matrix[target_row]` 这一行（索引从 `0` 到 `n-1`）进行标准的二分查找 `target`。
    - 如果找到，返回 `True`。
    - 如果找不到，返回 `False`。

#### 方法二：一次二分查找 (O(log(m*n)))

将 `m x n` 的矩阵 **逻辑上** 视为一个长度为 `m * n` 的一维有序数组。

**映射关系：**
- 矩阵中的元素 `matrix[row][col]` 对应到一维数组中的索引 `index = row * n + col`。
- 一维数组中的索引 `index` 对应到矩阵中的位置 `row = index // n`, `col = index % n`。

**算法流程 (一次二分)：**
1.  获取行数 `m` 和列数 `n`。处理空矩阵或空行的情况。
2.  初始化二分查找的左右边界：`left = 0`, `right = m * n - 1` (搜索区间 `[left, right]`)。
3.  循环条件：`left <= right`。
4.  计算中间索引 `mid_index = left + (right - left) // 2`。
5.  将 `mid_index` 映射回矩阵的行列：`row = mid_index // n`, `col = mid_index % n`。
6.  获取中间值 `mid_val = matrix[row][col]`。
7.  比较 `mid_val` 和 `target`：
    - 如果 `mid_val == target`，返回 `True`。
    - 如果 `mid_val < target`，目标在右侧，`left = mid_index + 1`。
    - 如果 `mid_val > target`，目标在左侧，`right = mid_index - 1`。
8.  循环结束，未找到 `target`，返回 `False`。

**比较：** 方法二更简洁，只进行一次二分查找，理论上常数因子可能更小。

### 3. 代码实现 (Python)

#### 方法一：两次二分查找

```python
from typing import List
import bisect

class Solution:
    def searchMatrix_two_searches(self, matrix: List[List[int]], target: int) -> bool:
        """
        使用两次二分查找。
        """
        m = len(matrix)
        if m == 0:
            return False
        n = len(matrix[0])
        if n == 0:
            return False

        # 1. 二分查找定位行 (找到最后一个 matrix[row][0] <= target 的行)
        row_left, row_right = 0, m - 1
        target_row = -1
        while row_left <= row_right:
            mid_row = row_left + (row_right - row_left) // 2
            if matrix[mid_row][0] <= target:
                target_row = mid_row # 可能是这一行
                row_left = mid_row + 1 # 尝试找更大的行
            else: # matrix[mid_row][0] > target
                row_right = mid_row - 1
        
        if target_row == -1: # target 比所有行的第一个元素都小
            return False

        # 2. 二分查找定位列 (在 target_row 行查找 target)
        col_left, col_right = 0, n - 1
        while col_left <= col_right:
            mid_col = col_left + (col_right - col_left) // 2
            if matrix[target_row][mid_col] == target:
                return True
            elif matrix[target_row][mid_col] < target:
                col_left = mid_col + 1
            else:
                col_right = mid_col - 1
                
        return False

    # 使用 bisect 简化行查找 (查找插入点)
    def searchMatrix_two_searches_bisect(self, matrix: List[List[int]], target: int) -> bool:
        m = len(matrix)
        if m == 0: return False
        n = len(matrix[0])
        if n == 0: return False

        # 找到第一个大于 target 的行的索引
        first_col = [matrix[i][0] for i in range(m)]
        row_idx = bisect.bisect_right(first_col, target) 
        
        # target 应该在前一行 (row_idx - 1)
        target_row = row_idx - 1

        if target_row < 0: # target 比 matrix[0][0] 还小
             return False

        # 在 target_row 行查找 target
        col_idx = bisect.bisect_left(matrix[target_row], target)
        
        # 检查找到的位置是否是 target
        return col_idx < n and matrix[target_row][col_idx] == target

```

#### 方法二：一次二分查找 - 推荐

```python
from typing import List

class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        """
        将矩阵视为一维数组，进行一次二分查找。
        """
        m = len(matrix)
        if m == 0:
            return False
        n = len(matrix[0])
        if n == 0:
            return False
            
        left, right = 0, m * n - 1
        
        while left <= right:
            mid_index = left + (right - left) // 2
            # 将一维索引映射回二维
            row = mid_index // n
            col = mid_index % n
            mid_val = matrix[row][col]
            
            if mid_val == target:
                return True
            elif mid_val < target:
                left = mid_index + 1
            else: # mid_val > target
                right = mid_index - 1
                
        return False
```

### 4. 复杂度分析

- **方法一 (两次二分)：**
    - 时间复杂度：O(log m + log n)。第一次二分查找行 O(log m)，第二次二分查找列 O(log n)。
    - 空间复杂度：O(1) (如果行查找不创建新列表)。如果像 `searchMatrix_two_searches_bisect` 中创建了 `first_col` 列表，则空间复杂度为 O(m)。
- **方法二 (一次二分)：**
    - 时间复杂度：O(log(m*n))。对 `m*n` 个元素进行二分查找。因为 `log(m*n) = log m + log n`，所以时间复杂度与方法一相同。
    - 空间复杂度：O(1)。

**结论：** 两种方法的时间复杂度相同，方法二（一次二分）的代码更简洁，通常是首选。
