整数数组 `nums` 按升序排列，数组中的值 **互不相同** 。

在传递给函数之前，`nums` 在预先未知的某个下标 `k`（`0 <= k < nums.length`）上进行了 **旋转**，使数组变为 `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]`（下标 **从 0 开始** 计数）。例如， `[0,1,2,4,5,6,7]` 在下标 `3` 处旋转后可能变为 `[4,5,6,7,0,1,2]` 。

给你 **旋转后** 的数组 `nums` 和一个整数 `target` ，如果 `nums` 中存在这个目标值 `target` ，则返回它的下标，否则返回 `-1` 。

你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

**示例 1：**

```
输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4
```

**示例 2：**

```
输入：nums = [4,5,6,7,0,1,2], target = 3
输出：-1
```

**示例 3：**

```
输入：nums = [1], target = 0
输出：-1
```

**提示：**

*   `1 <= nums.length <= 5000`
*   `-10^4 <= nums[i] <= 10^4`
*   `nums` 中的每个值都 **独一无二**
*   题目数据保证 `nums` 在预先未知的某个下标上进行了旋转
*   `-10^4 <= target <= 10^4`

## 解决方法

### 1. 问题理解

**目标：** 在一个经过旋转的、原本升序且无重复元素的数组 `nums` 中查找目标值 `target`。
**旋转：** 数组在某个未知点 `k` 被切开并交换前后部分。
**约束：** 必须使用 O(log n) 时间复杂度的算法，暗示使用**二分查找**。
**输出：** 如果找到 `target`，返回其索引；否则返回 -1。

### 2. 思路分析 (变形二分查找)

虽然数组被旋转了，但它仍然具有部分有序的特性。具体来说，对于任意中间点 `mid`，数组 `[left...mid]` 和 `[mid...right]` 至少有一个是完全有序的。我们可以利用这个特性来修改二分查找。

**算法流程：**
1.  **初始化指针：** `left = 0`, `right = n - 1`。
2.  **循环条件：** `left <= right`。
3.  **计算中间索引：** `mid = left + (right - left) // 2`。
4.  **检查 `nums[mid]`：**
    - 如果 `nums[mid] == target`：找到，返回 `mid`。
5.  **判断哪一半是有序的：**
    - **如果 `nums[left] <= nums[mid]`：** 说明左半部分 `[left...mid]` 是有序的。
        - **检查 `target` 是否在有序的左半部分：** 如果 `nums[left] <= target < nums[mid]`，那么 `target` 肯定在左半部分，更新 `right = mid - 1`。
        - **否则：** `target` 不在有序的左半部分，那么它只可能在右半部分（即使右半部分可能无序），更新 `left = mid + 1`。
    - **如果 `nums[left] > nums[mid]`：** 说明右半部分 `[mid...right]` 是有序的。
        - **检查 `target` 是否在有序的右半部分：** 如果 `nums[mid] < target <= nums[right]`，那么 `target` 肯定在右半部分，更新 `left = mid + 1`。
        - **否则：** `target` 不在有序的右半部分，那么它只可能在左半部分（即使左半部分可能无序），更新 `right = mid - 1`。
6.  **循环结束：** 如果 `left > right`，说明 `target` 不在数组中，返回 -1。

**关键点：** 每次迭代，我们都能确定 `target` 是否在当前 `mid` 分割出的**有序**的那一半里。如果不在有序的那一半，就去另一半（可能是无序的）继续查找。这样每次都能将搜索范围缩小一半，保证了 O(log n) 的复杂度。

### 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def search(self, nums: List[int], target: int) -> int:
        """
        在旋转排序数组中使用二分查找目标值。
        Args:
            nums: 旋转后的排序数组。
            target: 目标值。
        Returns:
            目标值的索引，如果不存在则返回 -1。
        """
        left, right = 0, len(nums) - 1
        
        while left <= right:
            mid = left + (right - left) // 2
            
            if nums[mid] == target:
                return mid
            
            # 判断 [left...mid] 是否有序
            if nums[left] <= nums[mid]: 
                # 左半部分有序
                # 检查 target 是否在有序的左半部分
                if nums[left] <= target < nums[mid]:
                    right = mid - 1 # 在左半部分查找
                else:
                    left = mid + 1  # 在右半部分查找
            else: 
                # 右半部分 [mid...right] 有序
                # 检查 target 是否在有序的右半部分
                if nums[mid] < target <= nums[right]:
                    left = mid + 1   # 在右半部分查找
                else:
                    right = mid - 1 # 在左半部分查找
                    
        # 循环结束，未找到 target
        return -1
```

### 4. 复杂度分析

- **时间复杂度：** O(log N)。每次迭代将搜索空间减半。
- **空间复杂度：** O(1)。只需要常数空间存储指针。
