已知一个长度为 `n` 的数组，预先按照升序排列，经由 `1` 到 `n` 次 **旋转** 后，得到输入数组。例如，原数组 `nums = [0,1,2,4,5,6,7]` 在变化后可能得到：
*   若旋转 `4` 次，则可以得到 `[4,5,6,7,0,1,2]`
*   若旋转 `7` 次，则可以得到 `[0,1,2,4,5,6,7]`

注意，数组 `[a[0], a[1], a[2], ..., a[n-1]]` **旋转一次** 的结果为数组 `[a[n-1], a[0], a[1], a[2], ..., a[n-2]]` 。

给你一个元素值 **互不相同** 的数组 `nums` ，它原来是一个升序排列的数组，并按上述情形进行了多次旋转。请你找出并返回数组中的 **最小元素** 。

你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

**示例 1：**

```
输入：nums = [3,4,5,1,2]
输出：1
解释：原数组为 [1,2,3,4,5] ，旋转 3 次得到输入数组。
```

**示例 2：**

```
输入：nums = [4,5,6,7,0,1,2]
输出：0
解释：原数组为 [0,1,2,4,5,6,7] ，旋转 4 次得到输入数组。
```

**示例 3：**

```
输入：nums = [11,13,15,17]
输出：11
解释：原数组为 [11,13,15,17] ，旋转 4 次得到输入数组。
```

**提示：**

*   `n == nums.length`
*   `1 <= n <= 5000`
*   `-5000 <= nums[i] <= 5000`
*   `nums` 中的所有整数 **互不相同**
*   `nums` 原来是一个升序排序的数组，并进行了 `1` 至 `n` 次旋转

## 解决方法

### 1. 问题理解

**目标：** 在一个经过旋转的、原本升序且无重复元素的数组 `nums` 中找到**最小元素**。
**旋转：** 数组可能旋转了 1 到 n 次。
**约束：** 必须使用 O(log n) 时间复杂度的算法，暗示使用**二分查找**。
**输出：** 数组中的最小元素。

### 2. 思路分析 (二分查找)

旋转后的数组具有一个关键特性：**最小值是数组中唯一一个比它右边邻居（如果存在）大的元素（考虑循环数组）**，或者说，**最小值是数组中唯一一个比它左边邻居（如果存在）小的元素**。更重要的是，最小值将数组分成了两段升序的部分（其中一段可能为空，如果数组未旋转或旋转 n 次）。

我们可以利用二分查找来定位这个最小值。关键在于如何根据中间值 `nums[mid]` 与边界值（通常是 `nums[right]`）的比较来缩小搜索范围。

**算法流程：**
1.  **初始化指针：** `left = 0`, `right = n - 1`。
2.  **循环条件：** `left < right`。我们最终的目标是找到唯一的最小值，当 `left == right` 时循环结束，此时 `left`（或 `right`）指向的就是最小值。
3.  **计算中间索引：** `mid = left + (right - left) // 2`。
4.  **比较 `nums[mid]` 与 `nums[right]`：**
    - **如果 `nums[mid] < nums[right]`：** 这表明 `[mid...right]` 这部分是严格升序的（因为元素互不相同）。最小值**不可能**在 `(mid...right]` 这个开区间内，因为它比 `nums[mid]` 还小。最小值可能就是 `nums[mid]`，或者在 `mid` 的左边。因此，我们将搜索范围缩小到 `[left...mid]`，更新 `right = mid`。
    - **如果 `nums[mid] > nums[right]`：** 这表明最小值一定在 `mid` 的右边，即在 `[mid+1...right]` 这个区间内。因为 `nums[mid]` 比右边界 `nums[right]` 大，说明旋转点（最小值）在 `mid` 的右侧。更新 `left = mid + 1`。
    - **`nums[mid] == nums[right]` 的情况：** 由于题目保证元素互不相同，这种情况不会发生。
5.  **循环结束：** 当 `left == right` 时，循环结束。此时 `left`（或 `right`）指向的元素就是数组中的最小值。返回 `nums[left]`。

**为什么比较 `nums[mid]` 和 `nums[right]`？**
- 比较 `nums[mid]` 和 `nums[right]` 可以明确地判断出 `[mid...right]` 是否有序。
- 如果比较 `nums[mid]` 和 `nums[left]`，当 `nums[mid] > nums[left]` 时，我们只能确定 `[left...mid]` 是有序的，但无法确定最小值是在左边还是右边（例如 `[3, 4, 5, 1, 2]` 中 `mid=2`, `nums[mid]=5`, `nums[left]=3`，最小值在右边；`[1, 2, 3, 4, 5]` 中 `mid=2`, `nums[mid]=3`, `nums[left]=1`，最小值在左边）。因此，比较 `nums[right]` 更能有效地缩小范围。

### 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def findMin(self, nums: List[int]) -> int:
        """
        在旋转排序数组中查找最小值。
        Args:
            nums: 旋转后的排序数组 (元素互不相同)。
        Returns:
            数组中的最小元素。
        """
        left, right = 0, len(nums) - 1
        
        # 循环条件 left < right
        # 最终 left 和 right 会指向同一个元素，即最小值
        while left < right:
            mid = left + (right - left) // 2
            
            # 如果 mid 比 right 小，说明 [mid...right] 是升序的
            # 最小值可能在 mid 或者 mid 的左边
            if nums[mid] < nums[right]:
                right = mid 
            # 如果 mid 比 right 大，说明最小值在 mid 的右边
            else: # nums[mid] > nums[right] (因为元素互不相同)
                left = mid + 1
                
        # 循环结束时 left == right，指向最小值
        return nums[left]
```

### 4. 复杂度分析

- **时间复杂度：** O(log N)。二分查找每次将搜索范围减半。
- **空间复杂度：** O(1)。只需要常数空间存储指针。

2.  **核心思路：二分查找**：
    - "旋转数组的特性是最小值将数组分为两段升序序列。我们可以利用二分查找来定位这个最小值。"
3.  **关键比较与范围缩小**：
    - "在二分查找中，关键是如何根据 `mid` 的值来判断最小值在哪一半，从而缩小搜索范围。"
    - "比较 `nums[mid]` 和 `nums[right]` 是一个有效的方法。"
    - "**如果 `nums[mid] < nums[right]`:** 说明从 `mid` 到 `right` 这部分是严格升序的。最小值肯定不在 `(mid, right]` 这个区间，它要么是 `nums[mid]`，要么在 `mid` 的左边。所以，我们可以安全地将搜索范围缩小到 `[left, mid]`，即 `right = mid`。"
    - "**如果 `nums[mid] > nums[right]`:** 说明 `mid` 处于旋转点左侧的较大值部分，而最小值（旋转点）一定在 `mid` 的右侧。所以，我们将搜索范围缩小到 `[mid + 1, right]`，即 `left = mid + 1`。"
4.  **循环条件与结束**：
    - "循环条件使用 `left < right`。当 `left == right` 时，我们就找到了唯一的候选者，即最小值。"
    - "循环结束后，返回 `nums[left]` (或 `nums[right]`)。"
5.  **处理边界与特殊情况**：
    - "数组只有一个元素时，直接返回该元素（循环条件 `left < right` 不满足，直接返回 `nums[left]`）。"
    - "数组未旋转（完全升序）时，`nums[mid]` 总是小于 `nums[right]`，`right` 会不断向左移动，最终 `left` 和 `right` 都停在索引 0，返回 `nums[0]`，正确。"
6.  **代码演示与复杂度**：
