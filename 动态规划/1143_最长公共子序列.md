给定两个字符串 `text1` 和 `text2`，返回这两个字符串的最长 **公共子序列** 的长度。如果不存在 **公共子序列** ，返回 `0` 。

一个字符串的 **子序列** 是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。

*   例如，`"ace"` 是 `"abcde"` 的子序列，但 `"aec"` 不是 `"abcde"` 的子序列。

两个字符串的 **公共子序列** 是这两个字符串所共同拥有的子序列。

**示例 1：**

```
输入：text1 = "abcde", text2 = "ace" 
输出：3  
解释：最长公共子序列是 "ace" ，它的长度为 3 。
```

**示例 2：**

```
输入：text1 = "abc", text2 = "abc"
输出：3
解释：最长公共子序列是 "abc" ，它的长度为 3 。
```

**示例 3：**

```
输入：text1 = "abc", text2 = "def"
输出：0
解释：两个字符串没有公共子序列，返回 0 。
```

**提示：**

*   `1 <= text1.length, text2.length <= 1000`
*   `text1` 和 `text2` 仅由小写英文字母组成。

## 解决方法

### 1. 问题理解

**目标：** 找到两个给定字符串 `text1` 和 `text2` 的最长公共子序列 (LCS) 的长度。
**子序列：** 从原字符串删除零个或多个字符，保持剩余字符相对顺序不变。
**公共子序列：** 同时是两个字符串的子序列。
**输入：** 两个字符串 `text1`, `text2`。
**输出：** 最长公共子序列的长度。

### 2. 思路分析 (动态规划)

这是另一个经典的动态规划问题。

**状态定义：**
设 `dp[i][j]` 为 `text1` 的前 `i` 个字符（即 `text1[0...i-1]`）和 `text2` 的前 `j` 个字符（即 `text2[0...j-1]`）的最长公共子序列的长度。
我们的目标是求 `dp[m][n]`，其中 `m = len(text1)`, `n = len(text2)`。

**状态转移方程 (递推关系)：**
考虑如何计算 `dp[i][j]`。这取决于 `text1[i-1]` 和 `text2[j-1]` 这两个字符是否相等。

1.  **如果 `text1[i-1] == text2[j-1]`：**
    - 这意味着这两个相等的字符可以同时作为公共子序列的一部分。
    - 那么 `text1[0...i-1]` 和 `text2[0...j-1]` 的最长公共子序列，就等于 `text1[0...i-2]` 和 `text2[0...j-2]` 的最长公共子序列长度加 1。
    - 即 `dp[i][j] = dp[i-1][j-1] + 1`。

2.  **如果 `text1[i-1] != text2[j-1]`：**
    - 这意味着这两个字符至少有一个不能同时包含在最长公共子序列的末尾。
    - 我们需要考虑两种情况，取其中的最大值：
        - 情况一：最长公共子序列可能存在于 `text1[0...i-1]` 和 `text2[0...j-2]` 中（即不考虑 `text2[j-1]`）。其长度为 `dp[i][j-1]`。
        - 情况二：最长公共子序列可能存在于 `text1[0...i-2]` 和 `text2[0...j-1]` 中（即不考虑 `text1[i-1]`）。其长度为 `dp[i-1][j]`。
    - 即 `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`。

**合并两种情况：**
`dp[i][j] = dp[i-1][j-1] + 1`  if `text1[i-1] == text2[j-1]`
`dp[i][j] = max(dp[i-1][j], dp[i][j-1])` if `text1[i-1] != text2[j-1]`

**基准情况 (Base Cases)：**
- `dp[0][j] = 0` for all `j`：`text1` 为空字符串时，与任何 `text2` 的子串的 LCS 长度都是 0。
- `dp[i][0] = 0` for all `i`：`text2` 为空字符串时，与任何 `text1` 的子串的 LCS 长度都是 0。
- `dp[0][0] = 0`。

**算法流程 (DP 数组)：**
1.  获取 `text1` 和 `text2` 的长度 `m` 和 `n`。
2.  创建一个 `(m+1) x (n+1)` 的 DP 数组 `dp`，并初始化所有元素为 0（这自动处理了基准情况）。
3.  外层循环：遍历 `i` 从 1 到 `m`。
4.  内层循环：遍历 `j` 从 1 到 `n`。
5.  根据 `text1[i-1]` 和 `text2[j-1]` 是否相等，应用状态转移方程计算 `dp[i][j]`。
6.  返回 `dp[m][n]`。

**空间优化 (滚动数组)：**
观察到 `dp[i][j]` 只依赖于 `dp[i-1][j-1]`, `dp[i-1][j]`, `dp[i][j-1]`。这意味着我们只需要存储上一行和当前行的状态。可以用两个一维数组实现。
甚至可以只用一个一维数组实现，但需要注意更新顺序或使用临时变量。

**算法流程 (空间优化 - 两个数组)：**
1.  创建两个大小为 `n+1` 的数组 `prev_dp` 和 `curr_dp`，初始化为 0。
2.  外层循环 `i` 从 1 到 `m`。
3.  内层循环 `j` 从 1 到 `n`。
4.  根据 `text1[i-1]` 和 `text2[j-1]` 是否相等，使用 `prev_dp` 的值计算 `curr_dp[j]`。
    - If `text1[i-1] == text2[j-1]`: `curr_dp[j] = prev_dp[j-1] + 1`
    - Else: `curr_dp[j] = max(prev_dp[j], curr_dp[j-1])`
5.  内层循环结束后，将 `curr_dp` 的内容复制到 `prev_dp` (或者直接交换引用)。
6.  外层循环结束后，`prev_dp[n]` (或 `curr_dp[n]`，取决于最后一次复制) 就是结果。

**算法流程 (空间优化 - 一个数组)：**
1.  创建大小为 `n+1` 的数组 `dp`，初始化为 0。
2.  外层循环 `i` 从 1 到 `m`。
3.  在内层循环开始前，记录 `dp[0]` 的值（即 `dp[i-1][j-1]` 在 `j=1` 时的值），通常是 0。用一个变量 `prev_diag` (代表左上角的值)。
4.  内层循环 `j` 从 1 到 `n`。
5.  记录 `dp[j]` 的旧值（即 `dp[i-1][j]`）到临时变量 `temp`。
6.  根据 `text1[i-1]` 和 `text2[j-1]` 是否相等，使用 `prev_diag` (即 `dp[i-1][j-1]`) 和 `dp[j-1]` (即 `dp[i][j-1]`) 来更新 `dp[j]` (即 `dp[i][j]`)。
    - If `text1[i-1] == text2[j-1]`: `dp[j] = prev_diag + 1`
    - Else: `dp[j] = max(dp[j], dp[j-1])` (注意这里的 `dp[j]` 是旧值 `dp[i-1][j]`)
7.  更新 `prev_diag = temp`，为下一次内层循环准备。
8.  外层循环结束后，`dp[n]` 就是结果。

(空间优化 - 一个数组的实现稍微复杂，面试中用两个数组或直接用二维数组通常更清晰)

### 3. 代码实现 (Python)

#### 方法一：动态规划 (二维 DP 数组)

```python
class Solution:
    def longestCommonSubsequence_2d(self, text1: str, text2: str) -> int:
        """
        使用二维 DP 数组计算最长公共子序列长度。
        """
        m, n = len(text1), len(text2)
        # dp[i][j] 表示 text1[0...i-1] 和 text2[0...j-1] 的 LCS 长度
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i - 1] == text2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
                    
        return dp[m][n]

```

#### 方法二：动态规划 (空间优化 - 两个一维数组)

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        """
        使用空间优化的动态规划 (两个一维数组) 计算 LCS 长度。
        """
        m, n = len(text1), len(text2)
        
        # 确保 n 是较小的维度，可以进一步优化空间
        if m < n:
            return self.longestCommonSubsequence(text2, text1) 
            
        prev_dp = [0] * (n + 1)
        curr_dp = [0] * (n + 1)
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i - 1] == text2[j - 1]:
                    curr_dp[j] = prev_dp[j - 1] + 1
                else:
                    # curr_dp[j-1] 是 dp[i][j-1]
                    # prev_dp[j] 是 dp[i-1][j]
                    curr_dp[j] = max(prev_dp[j], curr_dp[j - 1])
            # 更新 prev_dp = curr_dp 的一种方式 (避免列表复制)
            prev_dp, curr_dp = curr_dp, prev_dp 
            # 注意 curr_dp (现在是之前的 prev_dp) 需要清零或重新创建，
            # 但因为下一轮循环会覆盖，不清零也可以。
            # 为了清晰，可以 curr_dp = [0] * (n + 1)
            
        # 因为最后交换了，结果在 prev_dp 中
        return prev_dp[n] 
```

### 4. 复杂度分析

- **二维 DP 数组方法：**
    - 时间复杂度：O(m * n)，其中 m 和 n 分别是两个字符串的长度。需要填充 `m*n` 个状态。
    - 空间复杂度：O(m * n)，需要 `(m+1) x (n+1)` 的 DP 数组。
- **空间优化方法 (两个/一个数组)：**
    - 时间复杂度：O(m * n)。
    - 空间复杂度：O(min(m, n))。通过确保较短的字符串作为内层循环的维度，空间复杂度可以优化到 O(min(m, n))。
