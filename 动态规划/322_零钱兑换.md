给你一个整数数组 `coins` ，表示不同面额的硬币；以及一个整数 `amount` ，表示总金额。

计算并返回可以凑成总金额所需的 **最少的硬币个数** 。如果没有任何一种硬币组合能组成总金额，返回 `-1` 。

你可以认为每种硬币的数量是无限的。

**示例 1：**

```
输入：coins = [1, 2, 5], amount = 11
输出：3 
解释：11 = 5 + 5 + 1
```

**示例 2：**

```
输入：coins = [2], amount = 3
输出：-1
```

**示例 3：**

```
输入：coins = [1], amount = 0
输出：0
```

**提示：**

*   `1 <= coins.length <= 12`
*   `1 <= coins[i] <= 2^31 - 1`
*   `0 <= amount <= 10^4`

## 解决方法

### 1. 问题理解

**目标：** 使用给定面额的硬币（每种无限量）凑成指定的总金额 `amount`，要求使用的硬币数量最少。
**输入：** 硬币面额数组 `coins`，总金额 `amount`。
**输出：** 最少硬币数量，如果无法凑成则返回 -1。
**特点：** 每种硬币可以使用任意多次，这是典型的 **完全背包** 问题变种（求最小值）。

### 2. 思路分析 (动态规划)

我们可以使用动态规划来解决这个问题。

**状态定义：**
设 `dp[i]` 为凑成金额 `i` 所需的最少硬币数量。我们的目标是求 `dp[amount]`。

**状态转移方程 (递推关系)：**
考虑如何凑成金额 `i`。它可以由凑成金额 `i - coin` 再加上一个面额为 `coin` 的硬币得到。其中 `coin` 是 `coins` 数组中的任意一个面额，且 `coin <= i`。
为了使 `dp[i]` 最小，我们需要遍历所有可用的硬币面额 `coin`，并找到 `dp[i - coin]` 的最小值，然后加 1（因为我们加上了 `coin` 这一个硬币）。
`dp[i] = min(dp[i - coin] + 1)` for all `coin` in `coins` such that `coin <= i`.

**基准情况 (Base Cases)：**
- `dp[0] = 0`：凑成金额 0 需要 0 个硬币。

**初始化：**
- 创建一个大小为 `amount + 1` 的 DP 数组 `dp`。
- 初始化 `dp[0] = 0`。
- 将 `dp` 数组的其他所有元素初始化为一个较大的值，表示初始时认为无法凑成或需要很多硬币。这个值应该比可能的最大硬币数（即 `amount`，如果只有面额为 1 的硬币）还要大。一个常用的选择是 `amount + 1` 或 `float('inf')`。

**算法流程 (DP 数组)：**
1.  创建大小为 `amount + 1` 的 DP 数组 `dp`。
2.  初始化 `dp[0] = 0`，其余元素为 `amount + 1` (或 `float('inf')`)。
3.  外层循环：遍历金额 `i` 从 1 到 `amount`，计算 `dp[i]`。
4.  内层循环：遍历 `coins` 数组中的每个硬币面额 `coin`：
    - 如果 `i >= coin` 并且 `dp[i - coin]` 不是初始化的那个大值（表示金额 `i - coin` 是可以凑成的）：
        - 更新 `dp[i] = min(dp[i], dp[i - coin] + 1)`。
5.  返回结果：
    - 遍历结束后，检查 `dp[amount]` 的值。
    - 如果 `dp[amount]` 仍然是初始化的那个大值 (`amount + 1` 或 `float('inf')`)，说明无法凑成总金额 `amount`，返回 -1。
    - 否则，返回 `dp[amount]`。

**注意内外循环顺序：**
在这个问题（完全背包求最小值/最大值）中，外层循环遍历金额（背包容量），内层循环遍历硬币（物品）是标准的做法，可以确保正确性。如果内外循环颠倒，需要确保内层循环（金额）是从小到大遍历的。

### 3. 代码实现 (Python - 动态规划)

```python
from typing import List
import math

class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        """
        使用动态规划计算凑成总金额所需的最少硬币数量。
        """
        # dp[i] 表示凑成金额 i 所需的最少硬币数量
        # 初始化为一个不可能达到的值，比如 amount + 1
        dp = [amount + 1] * (amount + 1) 
        dp[0] = 0 # 凑成金额 0 需要 0 个硬币
        
        # 遍历所有金额 i 从 1 到 amount
        for i in range(1, amount + 1):
            # 遍历所有硬币面额 coin
            for coin in coins:
                # 如果当前金额 i 大于等于硬币面额 coin
                # 并且金额 i - coin 是可以凑成的 (dp[i-coin] != amount + 1)
                # 这里其实可以省略 dp[i-coin] != amount + 1 的判断，
                # 因为如果 dp[i-coin] 是 amount + 1，那么 dp[i-coin] + 1 会更大，
                # min 操作自然会选择 dp[i] 原来的值（可能是 amount+1 或更小的值）
                if i >= coin:
                    dp[i] = min(dp[i], dp[i - coin] + 1)
                    
        # 如果 dp[amount] 仍然是初始值 amount + 1，说明无法凑成
        return dp[amount] if dp[amount] != amount + 1 else -1
```

### 4. 复杂度分析

- **时间复杂度：** O(S * N)，其中 S 是总金额 `amount`，N 是硬币面额的数量 `len(coins)`。我们需要计算 S 个状态，每个状态需要遍历 N 个硬币。
- **空间复杂度：** O(S)，需要大小为 `amount + 1` 的 DP 数组。
