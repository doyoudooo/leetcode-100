给你一个整数数组 `nums` ，找到其中最长严格递增子序列的长度。

**子序列** 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

**示例 1：**

```
输入：nums = [10,9,2,5,3,7,101,18]
输出：4
解释：最长递增子序列是 [2,3,7,101]，因此长度为 4 。
```

**示例 2：**

```
输入：nums = [0,1,0,3,2,3]
输出：4
```

**示例 3：**

```
输入：nums = [7,7,7,7,7,7,7]
输出：1
```

**提示：**

*   `1 <= nums.length <= 2500`
*   `-10^4 <= nums[i] <= 10^4`

**进阶：**

*   你能将算法的时间复杂度降低到 `O(n log(n))` 吗?

## 解决方法

### 1. 问题理解

**目标：** 找到给定整数数组 `nums` 中最长严格递增子序列的长度。
**子序列：** 可以通过删除数组中的一些（或零个）元素，但不改变剩余元素的相对顺序得到。
**严格递增：** 子序列中的每个元素都必须严格大于其前一个元素。
**输入：** 整数数组 `nums`。
**输出：** 最长递增子序列的长度。

### 2. 思路分析

#### 方法一：动态规划 (O(N^2))

这是比较直观的 DP 解法。

**状态定义：**
设 `dp[i]` 为以 `nums[i]` **结尾** 的最长递增子序列的长度。

**状态转移方程 (递推关系)：**
要计算 `dp[i]`，我们需要考虑 `nums[i]` 能接在哪个递增子序列的后面。
遍历 `j` 从 0 到 `i-1`：
- 如果 `nums[i] > nums[j]`，说明 `nums[i]` 可以接在以 `nums[j]` 结尾的递增子序列后面，形成一个更长的递增子序列。这个新子序列的长度是 `dp[j] + 1`。
- 我们需要找到所有满足 `nums[i] > nums[j]` 的 `j` 中，使得 `dp[j] + 1` 最大的那个值，作为 `dp[i]` 的值。
- 如果找不到任何 `j` 使得 `nums[i] > nums[j]`（例如 `nums[i]` 是目前为止最小的元素），那么以 `nums[i]` 结尾的最长递增子序列就是它本身，长度为 1。

所以，状态转移方程为：
`dp[i] = max(dp[j] + 1)` for all `0 <= j < i` such that `nums[i] > nums[j]`.
如果不存在这样的 `j`，则 `dp[i] = 1`。

更简洁的写法：
初始化 `dp[i] = 1` (表示至少包含 `nums[i]` 自己)。
然后遍历 `j` 从 0 到 `i-1`，如果 `nums[i] > nums[j]`，则 `dp[i] = max(dp[i], dp[j] + 1)`。

**基准情况 (Base Cases)：**
`dp[0] = 1`。或者说，所有 `dp[i]` 的初始值都可以看作 1。

**最终结果：**
最长递增子序列不一定以最后一个元素结尾。因此，最终结果是 `dp` 数组中的最大值，即 `max(dp)`。

**算法流程 (DP 数组)：**
1.  获取数组长度 `n`。如果 `n == 0`，返回 0。
2.  创建大小为 `n` 的 DP 数组 `dp`，并将所有元素初始化为 1。
3.  外层循环：遍历 `i` 从 1 到 `n-1`。
4.  内层循环：遍历 `j` 从 0 到 `i-1`。
5.  如果 `nums[i] > nums[j]`，更新 `dp[i] = max(dp[i], dp[j] + 1)`。
6.  循环结束后，返回 `dp` 数组中的最大值。

#### 方法二：贪心 + 二分查找 (O(N log N))

这种方法更优，利用了贪心的思想和二分查找。

**核心思想：**
维护一个数组 `tails`，其中 `tails[k]` 存储的是所有长度为 `k+1` 的递增子序列中，**结尾元素最小** 的那个值。

**为什么这样维护？**
结尾元素越小，越有利于后续接上更多的元素，从而可能形成更长的递增子序列。

**算法流程：**
1.  初始化一个空列表 `tails`。
2.  遍历 `nums` 数组中的每个元素 `num`：
    - **二分查找：** 在 `tails` 数组中查找第一个大于或等于 `num` 的元素的位置 `idx`。
        - 可以使用 `bisect_left` (Python) 或手动实现二分查找。
    - **更新 `tails`：**
        - 如果 `idx == len(tails)`，说明 `num` 比 `tails` 中所有的元素都大。这意味着我们可以将 `num` 接在目前最长的递增子序列后面，形成一个更长的递增子序列。将 `num` 追加到 `tails` 数组末尾。此时，最长递增子序列的长度增加了 1。
        - 如果 `idx < len(tails)`，说明 `tails[idx]` 是第一个大于或等于 `num` 的元素。这意味着 `num` 可以替换 `tails[idx]`。这样做并不会改变当前已找到的最长递增子序列的长度，但是它更新了长度为 `idx+1` 的递增子序列的最小结尾元素为 `num`（一个更小的值），这为将来接上更多元素提供了更好的可能性。所以，执行 `tails[idx] = num`。
3.  **返回结果：** 遍历结束后，`tails` 数组的长度就是最长递增子序列的长度。

**`tails` 数组的性质：**
`tails` 数组始终是严格递增的。这是因为：
- 当我们追加元素时，是追加了一个比所有现有元素都大的数。
- 当我们替换元素 `tails[idx]` 时，是用一个更小的数 `num` 替换它。由于 `num` 小于 `tails[idx]`，且根据二分查找的定义，`num` 大于 `tails[idx-1]`（如果 `idx > 0`），所以替换后数组仍然保持递增。

### 3. 代码实现 (Python)

#### 方法一：动态规划 (O(N^2))

```python
from typing import List

class Solution:
    def lengthOfLIS_dp(self, nums: List[int]) -> int:
        """
        使用 O(N^2) 动态规划计算最长递增子序列长度。
        """
        n = len(nums)
        if n == 0:
            return 0
            
        # dp[i] 表示以 nums[i] 结尾的最长递增子序列的长度
        dp = [1] * n 
        
        for i in range(n):
            for j in range(i):
                if nums[i] > nums[j]:
                    dp[i] = max(dp[i], dp[j] + 1)
                    
        # 结果是 dp 数组中的最大值
        return max(dp) if dp else 0
```

#### 方法二：贪心 + 二分查找 (O(N log N))

```python
from typing import List
import bisect

class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        """
        使用贪心 + 二分查找计算最长递增子序列长度。O(N log N)
        """
        tails = [] # tails[k] 存储长度为 k+1 的 LIS 的最小末尾元素
        
        for num in nums:
            # 在 tails 中查找第一个大于等于 num 的元素的位置
            idx = bisect.bisect_left(tails, num)
            
            if idx == len(tails):
                # 如果 num 比 tails 中所有元素都大，则追加，LIS 长度加 1
                tails.append(num)
            else:
                # 否则，用 num 替换掉那个第一个大于等于它的元素
                # 这会使得未来可能有更长的 LIS
                tails[idx] = num
                
        return len(tails)

# 示例调用

# print(sol.lengthOfLIS([7,7,7,7,7,7,7]))       # 1
```

### 4. 复杂度分析

- **方法一 (DP)：**
    - 时间复杂度：O(N^2)。两层嵌套循环。
    - 空间复杂度：O(N)。需要大小为 N 的 DP 数组。
- **方法二 (贪心 + 二分查找)：**
    - 时间复杂度：O(N log N)。遍历数组 N 次，每次在 `tails` 数组中进行二分查找，`tails` 数组长度最多为 N，所以二分查找是 O(log N)。
    - 空间复杂度：O(N)。需要 `tails` 数组存储结尾元素，最坏情况下长度为 N。
