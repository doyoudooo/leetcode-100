假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶？

**示例 1：**

```
输入：n = 2
输出：2
解释：有两种方法可以爬到楼顶。
1. 1 阶 + 1 阶
2. 2 阶
```

**示例 2：**

```
输入：n = 3
输出：3
解释：有三种方法可以爬到楼顶。
1. 1 阶 + 1 阶 + 1 阶
2. 1 阶 + 2 阶
3. 2 阶 + 1 阶
```

**提示：**

*   `1 <= n <= 45`

## 解决方法

### 1. 问题理解

**目标：** 计算爬到 `n` 阶楼梯顶部的不同方法数量。
**规则：** 每次可以爬 1 阶或 2 阶。
**输入：** 楼梯阶数 `n`。
**输出：** 不同的方法总数。

### 2. 思路分析 (动态规划)

这是一个经典的动态规划问题。

**状态定义：**
设 `dp[i]` 为爬到第 `i` 阶楼梯的不同方法数。我们的目标是求 `dp[n]`。

**状态转移方程 (递推关系)：**
考虑如何到达第 `i` 阶楼梯：
1.  可以从第 `i-1` 阶爬 1 阶到达。到达第 `i-1` 阶的方法数是 `dp[i-1]`。
2.  可以从第 `i-2` 阶爬 2 阶到达。到达第 `i-2` 阶的方法数是 `dp[i-2]`。

因此，到达第 `i` 阶的总方法数是到达第 `i-1` 阶和第 `i-2` 阶的方法数之和：
`dp[i] = dp[i-1] + dp[i-2]` (对于 `i >= 2`)

**基准情况 (Base Cases)：**
- `dp[0]`：爬到第 0 阶（可以理解为起点，还没开始爬）。有 1 种方法（就是待在原地）。`dp[0] = 1`。
- `dp[1]`：爬到第 1 阶。只能从第 0 阶爬 1 阶。有 1 种方法。`dp[1] = 1`。
- `dp[2]`：爬到第 2 阶。可以从第 1 阶爬 1 阶 (方法数 `dp[1]`)，也可以从第 0 阶爬 2 阶 (方法数 `dp[0]`)。`dp[2] = dp[1] + dp[0] = 1 + 1 = 2`。这与递推公式一致。

**另一种基准情况定义：**
如果认为 `dp[i]` 是爬到第 `i` 阶楼梯顶的方法数，且 `n >= 1`。
- `dp[1] = 1` (只能爬 1 阶)
- `dp[2] = 2` (可以 1+1 或 2)
- `dp[i] = dp[i-1] + dp[i-2]` (对于 `i >= 3`)
这种定义下，我们需要计算 `dp[1]` 到 `dp[n]`。

两种定义本质上都是斐波那契数列。使用 `dp[0]=1, dp[1]=1` 的定义更方便数组索引从 0 开始。

**算法流程 (DP 数组)：**
1.  创建一个大小为 `n+1` 的 DP 数组 `dp`。
2.  初始化基准情况：`dp[0] = 1`, `dp[1] = 1`。
3.  使用循环从 `i = 2` 到 `n` 计算 `dp[i] = dp[i-1] + dp[i-2]`。
4.  返回 `dp[n]`。

**空间优化 (滚动变量)：**
观察到 `dp[i]` 只依赖于 `dp[i-1]` 和 `dp[i-2]`。我们可以只用两个变量来存储前两个状态，从而将空间复杂度从 O(N) 优化到 O(1)。

**算法流程 (空间优化)：**
1.  处理边界情况：如果 `n <= 1`，返回 1。
2.  初始化前两个状态：`prev2 = 1` (对应 `dp[0]`)，`prev1 = 1` (对应 `dp[1]`)。
3.  使用循环从 `i = 2` 到 `n`：
    - 计算当前状态 `current = prev1 + prev2`。
    - 更新前两个状态：`prev2 = prev1`，`prev1 = current`。
4.  循环结束后，`prev1` (或 `current`) 就是 `dp[n]` 的值，返回它。

### 3. 代码实现 (Python)

#### 方法一：动态规划 (DP 数组)

```python
class Solution:
    def climbStairs_dp_array(self, n: int) -> int:
        """
        使用 DP 数组计算爬楼梯方法数。
        """
        if n <= 1:
            return 1
            
        dp = [0] * (n + 1)
        dp[0] = 1
        dp[1] = 1
        
        for i in range(2, n + 1):
            dp[i] = dp[i - 1] + dp[i - 2]
            
        return dp[n]
```

#### 方法二：动态规划 (空间优化)

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        """
        使用空间优化的动态规划计算爬楼梯方法数。
        """
        if n <= 1:
            return 1
            
        # prev2 对应 dp[i-2], prev1 对应 dp[i-1]
        prev2 = 1 
        prev1 = 1
        
        for i in range(2, n + 1):
            current = prev1 + prev2
            prev2 = prev1
            prev1 = current
            
        return prev1 # 或者 return current
```

#### 方法三：递归 + 记忆化 (自顶向下)

```python
class Solution:
    def climbStairs_memo(self, n: int) -> int:
        """
        使用递归加记忆化计算爬楼梯方法数。
        """
        memo = {}
        def solve(k):
            if k <= 1:
                return 1
            if k in memo:
                return memo[k]
            
            memo[k] = solve(k - 1) + solve(k - 2)
            return memo[k]
            
        return solve(n)
```

### 4. 复杂度分析

- **DP 数组方法：**
    - 时间复杂度：O(N)，需要循环 N 次。
    - 空间复杂度：O(N)，需要大小为 N+1 的 DP 数组。
- **空间优化方法：**
    - 时间复杂度：O(N)，需要循环 N 次。
    - 空间复杂度：O(1)，只需要常数个额外变量。
- **递归 + 记忆化方法：**
    - 时间复杂度：O(N)，每个状态 `solve(k)` 只计算一次。
    - 空间复杂度：O(N)，递归深度最大为 N，记忆化哈希表最多存储 N 个状态。

**结论：** 空间优化的动态规划方法是最高效的。

### 5. 如何在面试中讲解

1.  **问题理解**：
    - "目标是计算到达 n 阶楼梯顶部的不同方式数，每次可以走 1 或 2 步。"
2.  **识别问题类型**：
    - "这是一个典型的动态规划问题，因为它具有最优子结构（到达第 i 阶的方法数依赖于到达更低阶的方法数）和重叠子问题（计算 dp[i] 时会重复用到 dp[i-1] 和 dp[i-2] 等）。"
3.  **DP 思路**：
    - "**状态定义:** `dp[i]` 表示到达第 `i` 阶的方法数。"
    - "**递推关系:** 要想到达第 `i` 阶，要么从 `i-1` 走一步，要么从 `i-2` 走两步。所以 `dp[i] = dp[i-1] + dp[i-2]`。"
    - "**基准情况:** `dp[0] = 1` (在起点)，`dp[1] = 1` (走一步)。"
4.  **实现方法一：DP 数组**：
    - "可以创建一个大小为 `n+1` 的数组，根据基准情况和递推关系填充数组，最后返回 `dp[n]`。"
    - "**复杂度:** 时间 O(N)，空间 O(N)。"
5.  **实现方法二：空间优化**：
    - "观察到 `dp[i]` 只依赖于前两项，所以不需要存储整个 DP 数组。"
    - "可以用两个变量 `prev1` 和 `prev2` 来存储 `dp[i-1]` 和 `dp[i-2]`，然后迭代计算 `current = prev1 + prev2`，并更新 `prev1` 和 `prev2`。"
    - "**复杂度:** 时间 O(N)，空间 O(1)。这是最优的方法。"
6.  **实现方法三：递归 + 记忆化 (可选)**：
    - "也可以用自顶向下的递归来写，`solve(n) = solve(n-1) + solve(n-2)`。为了避免重复计算，使用一个哈希表或数组进行记忆化。"
    - "**复杂度:** 时间 O(N)，空间 O(N)（递归栈 + 记忆化存储）。"
7.  **代码演示**：
    - "优先展示空间优化的 O(1) 空间复杂度的代码。"
