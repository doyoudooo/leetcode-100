给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。请你判断是否可以利用字典中出现的单词拼接出 `s` 。

**注意：** 不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

**示例 1：**

```
输入: s = "leetcode", wordDict = ["leet", "code"]
输出: true
解释: 返回 true 因为 "leetcode" 可以由 "leet" 和 "code" 拼接成。
```

**示例 2：**

```
输入: s = "applepenapple", wordDict = ["apple", "pen"]
输出: true
解释: 返回 true 因为 "applepenapple" 可以由 "apple" "pen" "apple" 拼接成。
     注意，你可以重复使用字典中的单词。
```

**示例 3：**

```
输入: s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
输出: false
```

**提示：**

*   `1 <= s.length <= 300`
*   `1 <= wordDict.length <= 1000`
*   `1 <= wordDict[i].length <= 20`
*   `s` 和 `wordDict[i]` 仅有小写英文字母组成
*   `wordDict` 中的所有字符串 **互不相同**

## 解决方法

### 1. 问题理解

**目标：** 判断给定的字符串 `s` 是否可以被空格拆分为一个或多个在字典 `wordDict` 中出现的单词。
**输入：** 字符串 `s`，单词字典 `wordDict` (列表形式)。
**输出：** 布尔值，`True` 如果可以拆分，`False` 否则。
**注意：** 字典中的单词可以重复使用。

### 2. 思路分析 (动态规划)

这个问题可以看作是：字符串 `s` 能否由字典中的单词“组成”。这符合动态规划的特征，即一个大问题可以分解为依赖于小问题的解。

**状态定义：**
设 `dp[i]` 为一个布尔值，表示字符串 `s` 的前 `i` 个字符（即子串 `s[0...i-1]`）是否可以被 `wordDict` 中的单词成功拆分。
我们的目标是求 `dp[n]`，其中 `n = len(s)`。

**状态转移方程 (递推关系)：**
要判断 `dp[i]` 是否为 `True`，我们需要检查是否存在一个分割点 `j` ( `0 <= j < i` )，使得：
1.  `s` 的前 `j` 个字符 `s[0...j-1]` 可以被成功拆分（即 `dp[j]` 为 `True`）。
2.  并且，从 `j` 到 `i-1` 的子串 `s[j...i-1]` 恰好是字典 `wordDict` 中的一个单词。

如果能找到这样一个 `j`，那么 `dp[i]` 就为 `True`。
`dp[i] = OR(dp[j] and (s[j...i-1] in wordDict))` for all `0 <= j < i`.

**基准情况 (Base Cases)：**
- `dp[0] = True`：表示空字符串可以被（零个单词）成功拆分。这是递推的起点。

**优化：**
- 为了快速查找 `s[j...i-1]` 是否在 `wordDict` 中，可以将 `wordDict` 转换为哈希集合 (Set)。
- 还可以记录字典中单词的最大长度 `max_word_len`。在内层循环检查 `s[j...i-1]` 时，如果 `i - j > max_word_len`，则该子串不可能在字典中，可以提前跳过。

**算法流程 (DP 数组)：**
1.  获取字符串 `s` 的长度 `n`。
2.  将 `wordDict` 转换为哈希集合 `word_set` 以便 O(1) 查找。
3.  (可选优化) 计算 `wordDict` 中单词的最大长度 `max_word_len`。
4.  创建大小为 `n + 1` 的 DP 布尔数组 `dp`。
5.  初始化 `dp[0] = True`，其余为 `False`。
6.  外层循环：遍历 `i` 从 1 到 `n` (计算 `dp[i]`)。
7.  内层循环：遍历 `j` 从 0 到 `i-1` (寻找分割点)。
    - (可选优化) 如果 `i - j > max_word_len`，可以 `continue` 或 `break` (如果 `j` 是从 `i-1` 向下遍历)。
    - 提取子串 `substring = s[j:i]`。
    - 如果 `dp[j]` 为 `True` 并且 `substring` 在 `word_set` 中：
        - 设置 `dp[i] = True`。
        - 跳出内层循环 (`break`)，因为只要找到一种拆分方式即可。
8.  返回 `dp[n]`。

### 3. 代码实现 (Python - 动态规划)

```python
from typing import List

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        """
        使用动态规划判断字符串是否可以被字典单词拆分。
        """
        n = len(s)
        word_set = set(wordDict) # O(L*W) L=avg word len, W=dict size
        
        # dp[i] 表示 s 的前 i 个字符 s[0...i-1] 是否可以被拆分
        dp = [False] * (n + 1)
        dp[0] = True # 空字符串可以被拆分
        
        # (可选优化) 获取最大单词长度
        # max_word_len = 0
        # for word in wordDict:
        #     max_word_len = max(max_word_len, len(word))

        # 遍历字符串 s 的每个位置 i (作为子串的结尾)
        for i in range(1, n + 1):
            # 遍历所有可能的分割点 j (作为子串的开头)
            # j 从 0 到 i-1
            for j in range(i): 
                # (可选优化) 剪枝：如果子串长度超过最大单词长度，跳过
                # if i - j > max_word_len:
                #    continue 
                
                # 检查 s[0...j-1] 是否可拆分 (dp[j])
                # 以及 s[j...i-1] 是否是字典中的单词
                substring = s[j:i]
                if dp[j] and substring in word_set:
                    dp[i] = True
                    break # 找到一种拆分方式即可确定 dp[i] 为 True
                    
        return dp[n]
```

### 4. 复杂度分析

- **时间复杂度：** O(N^2 * L) 或 O(N^3)，取决于字符串切片和哈希查找的实现。
    - 外层循环 N 次，内层循环最多 N 次。
    - 在内层循环中，字符串切片 `s[j:i]` 需要 O(i-j) 时间，最坏是 O(N)。
    - 哈希集合查找 `substring in word_set` 平均 O(L)，其中 L 是子串长度 (最长为 N)，最坏 O(L)。
    - 如果切片和哈希查找都按子串长度算，总复杂度近似 O(N^3)。
    - 如果假设哈希查找是 O(1)（忽略字符串哈希计算时间），且切片是 O(N)，则为 O(N^3)。
    - 如果切片优化为 O(1)（某些语言实现），哈希查找 O(L)，则为 O(N^2 * L_avg)。
    - **更精确分析：** 总共检查 O(N^2) 个子串，每个子串检查是否在字典中。假设检查一个长度为 k 的子串需要 O(k) 时间（哈希计算），总时间是 Σ (i-j) for i=1..N, j=0..i-1，这近似于 O(N^3)。
    - **使用最大长度优化：** 如果加入 `max_word_len` 优化，内层循环的次数可以减少到 `max_word_len`，切片和查找的时间也受限于 `max_word_len`。时间复杂度可以优化到 O(N * M * L)，其中 M 是 `max_word_len`，L 是哈希查找时间（平均 O(M)）。近似 O(N * M^2)。
- **空间复杂度：** O(N + W*L)，其中 N 是 DP 数组的大小，W 是字典大小，L 是平均单词长度（用于存储哈希集合）。
