给你一个整数 `n` ，返回 *和为 `n` 的完全平方数的最少数量* 。

**完全平方数** 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，`1`、`4`、`9` 和 `16` 都是完全平方数，而 `3` 和 `11` 不是。

**示例 1：**

```
输入：n = 12
输出：3 
解释：12 = 4 + 4 + 4
```

**示例 2：**

```
输入：n = 13
输出：2
解释：13 = 4 + 9
```

**提示：**

*   `1 <= n <= 10^4`

## 解决方法

### 1. 问题理解

**目标：** 找到组成给定整数 `n` 所需的最少完全平方数的数量。
**输入：** 正整数 `n`。
**输出：** 最少的完全平方数数量。
**完全平方数：** 1, 4, 9, 16, 25, ...

### 2. 思路分析 (动态规划)

这个问题可以看作是一个组合优化问题，寻找最少的“物品”（完全平方数）来凑成目标值 `n`。这与“零钱兑换”问题类似，非常适合使用动态规划。

**状态定义：**
设 `dp[i]` 为组成整数 `i` 所需的最少完全平方数的数量。我们的目标是求 `dp[n]`。

**状态转移方程 (递推关系)：**
考虑如何组成整数 `i`。它可以由一个较小的整数 `i - j*j` 加上一个完全平方数 `j*j` 得到。其中 `j*j` 是小于等于 `i` 的任意一个完全平方数。
为了使 `dp[i]` 最小，我们需要遍历所有可能的 `j` (使得 `j*j <= i`)，并找到 `dp[i - j*j]` 的最小值，然后加 1（因为我们加上了 `j*j` 这一个完全平方数）。
`dp[i] = min(dp[i - j*j] + 1)` for all `1 <= j` such that `j*j <= i`.

**基准情况 (Base Cases)：**
- `dp[0] = 0`：组成 0 需要 0 个完全平方数。

**算法流程 (DP 数组)：**
1.  创建一个大小为 `n+1` 的 DP 数组 `dp`。
2.  初始化：`dp[0] = 0`。将 `dp` 数组的其他所有元素初始化为一个较大的值（例如 `n+1` 或 `float('inf')`），表示初始时认为无法组成或需要很多个数。
3.  外层循环：遍历 `i` 从 1 到 `n`，计算 `dp[i]`。
4.  内层循环：遍历 `j` 从 1 开始，只要 `j*j <= i`：
    - 计算 `square = j * j`。
    - 更新 `dp[i] = min(dp[i], dp[i - square] + 1)`。
5.  返回 `dp[n]`。

**优化：** 可以在外层循环之前预先计算出所有小于等于 `n` 的完全平方数，存储在一个列表中，内层循环直接遍历这个列表。

### 3. 代码实现 (Python - 动态规划)

```python
import math

class Solution:
    def numSquares(self, n: int) -> int:
        """
        使用动态规划计算组成 n 所需的最少完全平方数数量。
        """
        # dp[i] 表示组成整数 i 所需的最少完全平方数数量
        dp = [float('inf')] * (n + 1)
        dp[0] = 0
        
        # 预计算小于等于 n 的所有完全平方数 (可选优化)
        # max_sqrt = int(math.sqrt(n))
        # squares = [k*k for k in range(1, max_sqrt + 1)]
        
        for i in range(1, n + 1):
            # 遍历所有小于等于 i 的完全平方数 j*j
            j = 1
            while j * j <= i:
                square = j * j
                dp[i] = min(dp[i], dp[i - square] + 1)
                j += 1
            # 如果使用预计算的 squares 列表：
            # for square in squares:
            #     if square > i:
            #         break
            #     dp[i] = min(dp[i], dp[i - square] + 1)

        return dp[n]

```

### 4. 复杂度分析

- **时间复杂度：** O(N * sqrt(N))。外层循环 `n` 次，内层循环最多 `sqrt(n)` 次。
- **空间复杂度：** O(N)，需要大小为 `n+1` 的 DP 数组。

### 5. 其他方法简介

- **广度优先搜索 (BFS):** 可以将问题看作图搜索。节点是 0 到 `n` 的整数。从 `n` 开始，每次减去一个完全平方数，看最少几步能到达 0。这相当于在图中找 `n` 到 0 的最短路径。BFS 天然适合找最短路径。通常 BFS 在此问题上表现更好。
- **数学方法 (Lagrange 四平方和定理):**
    - 任何正整数都可以表示为至多四个平方数的和。所以答案只可能是 1, 2, 3, 4。
    - 答案为 1：当 `n` 本身是完全平方数。
    - 答案为 4：当 `n` 满足 `n = 4^k * (8m + 7)`。
    - 答案为 2：当 `n` 可以表示为两个平方数的和 `a^2 + b^2`。
    - 否则答案为 3。
    - 这个方法效率最高 (O(sqrt(N)))，但需要数论知识。
