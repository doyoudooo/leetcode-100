一条包含字母 `A-Z` 的消息通过以下映射进行了 **编码** ：

```
'A' -> "1"
'B' -> "2"
...
'Z' -> "26"
```

要 **解码** 已编码的消息，所有数字必须基于上述映射的方法，反向映射回字母（可能有多种方法）。例如，`"11106"` 可以映射为：

*   `"AAJF"` ，将消息分组为 `(1 1 10 6)`
*   `"KJF"` ，将消息分组为 `(11 10 6)`

注意，消息不能分组为 `(1 11 06)` ，因为 `"06"` 不能映射为 `"F"` ，这是由于 `"6"` 和 `"06"` 在映射中并不等价。

给你一个只含数字的 **非空** 字符串 `s` ，请计算并返回 **解码** 方法的总数 。

题目数据保证答案肯定是一个 **32 位** 的整数。

**示例 1：**

```
输入：s = "12"
输出：2
解释：它可以解码为 "AB"（1 2）或者 "L"（12）。
```

**示例 2：**

```
输入：s = "226"
输出：3
解释：它可以解码为 "BZ" (2 26), "VF" (22 6), 或者 "BBF" (2 2 6) 。
```

**示例 3：**

```
输入：s = "0"
输出：0
解释：没有字符映射到以 0 开头的数字。
含有 0 的有效映射是 'J' -> "10" 和 'T' -> "20" 。
由于没有字符映射到以 0 开头的数字，所以 "0" 不能被解码。
```

**示例 4：**

```
输入：s = "06"
输出：0
解释："06" 不能映射到 "F" ，因为字符串含有前导 0（`"6"` 和 `"06"` 不同）。
```

**提示：**

*   `1 <= s.length <= 100`
*   `s` 只包含数字，并且可能包含前导零。

## 解决方法

### 1. 问题理解

**目标：** 计算给定数字字符串 `s` 的解码方法总数。
**编码规则：** 'A' -> "1", 'B' -> "2", ..., 'Z' -> "26"。
**解码约束：**
- 只能解码为 1 到 26 对应的字母。
- 数字 '0' 不能单独解码。
- 以 '0' 开头的两位数（如 "01", "06"）无效。有效的含 0 组合只有 "10" 和 "20"。
**输入：** 只包含数字的非空字符串 `s`。
**输出：** 解码方法的总数。

### 2. 思路分析 (动态规划)

这个问题类似于“爬楼梯”，当前状态的解法数量依赖于之前状态的解法数量。

**状态定义：**
设 `dp[i]` 为字符串 `s` 的前 `i` 个字符（即 `s[0...i-1]`）的解码方法总数。
我们的目标是求 `dp[n]`，其中 `n = len(s)`。

**状态转移方程 (递推关系)：**
考虑如何计算 `dp[i]`。这取决于第 `i` 个字符 `s[i-1]` 以及它与前一个字符 `s[i-2]` 的组合。

1.  **考虑单个字符 `s[i-1]`：**
    - 如果 `s[i-1]` 是 '1' 到 '9' 之间的数字，那么它可以单独解码。这种情况下，解码方法数至少包含了解码 `s[0...i-2]` 的所有方法。
    - 贡献：`dp[i-1]` (如果 `s[i-1]` != '0')

2.  **考虑两个字符 `s[i-2]s[i-1]`：**
    - 如果 `s[i-2]` 是 '1'，那么 `s[i-2]s[i-1]` 组成的两位数是 "10" 到 "19"，都可以解码。
    - 如果 `s[i-2]` 是 '2'，那么 `s[i-2]s[i-1]` 组成的两位数必须是 "20" 到 "26"，才能解码。
    - 如果这两个字符可以组合解码，那么解码方法数还包含了将 `s[i-2]s[i-1]` 作为一个整体解码的情况，其数量等于解码 `s[0...i-3]` 的方法数。
    - 贡献：`dp[i-2]` (如果 `s[i-2]s[i-1]` 组成的两位数在 "10" 到 "26" 之间)

**合并：**
`dp[i]` 的值是上述两种情况贡献的总和。

- **Case 1: `s[i-1]` != '0'**
    - `dp[i] += dp[i-1]`
- **Case 2: `i >= 2` and `s[i-2]s[i-1]` forms a valid number ("10" to "26")**
    - Check if `s[i-2] == '1'` OR (`s[i-2] == '2'` and `s[i-1]` is '0' to '6').
    - If valid, `dp[i] += dp[i-2]`

**基准情况 (Base Cases)：**
- `dp[0] = 1`：表示空字符串有一种解码方式（解码为空）。这是为了方便递推 `dp[1]` 和 `dp[2]`。
- `dp[1]`：
    - 如果 `s[0]` 是 '0'，则 `dp[1] = 0`。
    - 如果 `s[0]` 是 '1' 到 '9'，则 `dp[1] = 1` (等于 `dp[0]`)。

**算法流程 (DP 数组)：**
1.  获取字符串 `s` 的长度 `n`。
2.  创建大小为 `n + 1` 的 DP 数组 `dp`。
3.  初始化 `dp[0] = 1`。
4.  计算 `dp[1]`：如果 `s[0] == '0'`，`dp[1] = 0`；否则 `dp[1] = 1`。
5.  循环：遍历 `i` 从 2 到 `n`。
6.  在循环内计算 `dp[i]`：
    - 初始化 `dp[i] = 0`。
    - **检查单字符解码：**
        - `one_digit = int(s[i-1])`
        - 如果 `1 <= one_digit <= 9`，则 `dp[i] += dp[i-1]`。
    - **检查双字符解码：**
        - `two_digits = int(s[i-2:i])`
        - 如果 `10 <= two_digits <= 26`，则 `dp[i] += dp[i-2]`。
7.  返回 `dp[n]`。

**空间优化 (滚动变量)：**
观察到 `dp[i]` 只依赖于 `dp[i-1]` 和 `dp[i-2]`。我们可以只用常数空间来存储这两个值。

**算法流程 (空间优化)：**
1.  获取字符串 `s` 的长度 `n`。
2.  处理特殊情况 `s[0] == '0'`，直接返回 0。
3.  初始化 `prev = 1` (代表 `dp[i-2]`)，`curr = 1` (代表 `dp[i-1]`)。这里 `curr` 初始为 1 是因为 `dp[1]` 在 `s[0]` 非 0 时为 1。
4.  循环：遍历 `i` 从 2 到 `n`。
5.  计算当前的解码数 `next_val`：
    - 初始化 `next_val = 0`。
    - **检查单字符解码：**
        - `one_digit = int(s[i-1])`
        - 如果 `1 <= one_digit <= 9`，则 `next_val += curr`。
    - **检查双字符解码：**
        - `two_digits = int(s[i-2:i])`
        - 如果 `10 <= two_digits <= 26`，则 `next_val += prev`。
6.  更新 `prev = curr`, `curr = next_val`。
7.  循环结束后，`curr` 就是 `dp[n]` 的结果。

### 3. 代码实现 (Python)

#### 方法一：动态规划 (DP 数组)

```python
class Solution:
    def numDecodings_dp(self, s: str) -> int:
        """
        使用 DP 数组计算解码方法总数。
        """
        n = len(s)
        # dp[i] 表示 s 的前 i 个字符 s[0...i-1] 的解码方法数
        dp = [0] * (n + 1)
        dp[0] = 1 # 空字符串有一种解码方式
        
        # 处理 dp[1]
        if s[0] == '0':
            dp[1] = 0
        else:
            dp[1] = 1
            
        for i in range(2, n + 1):
            # 检查单字符解码 s[i-1]
            one_digit = int(s[i-1])
            if 1 <= one_digit <= 9:
                dp[i] += dp[i-1]
                
            # 检查双字符解码 s[i-2]s[i-1]
            two_digits = int(s[i-2:i])
            if 10 <= two_digits <= 26:
                dp[i] += dp[i-2]
                
        return dp[n]

```

#### 方法二：动态规划 (空间优化)

```python
class Solution:
    def numDecodings(self, s: str) -> int:
        """
        使用空间优化的动态规划计算解码方法总数。
        """
        n = len(s)
        if s[0] == '0':
            return 0
        if n == 1:
            return 1
            
        # prev 代表 dp[i-2], curr 代表 dp[i-1]
        prev = 1 
        curr = 1 # dp[1] is 1 if s[0] != '0'
        
        for i in range(2, n + 1):
            next_val = 0
            
            # 检查单字符解码 s[i-1]
            one_digit = int(s[i-1])
            if 1 <= one_digit <= 9:
                next_val += curr
                
            # 检查双字符解码 s[i-2]s[i-1]
            two_digits = int(s[i-2:i])
            if 10 <= two_digits <= 26:
                next_val += prev
                
            # 更新状态
            prev = curr
            curr = next_val
            
            # 如果当前 curr 为 0，说明无法继续解码，提前返回
            if curr == 0:
                return 0

        return curr
```

### 4. 复杂度分析

- **方法一 (DP 数组)：**
    - 时间复杂度：O(N)，其中 N 是字符串 `s` 的长度。需要遍历字符串一次填充 DP 数组。
    - 空间复杂度：O(N)。需要大小为 N+1 的 DP 数组。
- **方法二 (空间优化)：**
    - 时间复杂度：O(N)。
    - 空间复杂度：O(1)。只需要常数个变量。

1.  **问题理解**：
    - "目标是计算一个数字字符串有多少种解码方式，遵循 A=1...Z=26 的规则。"
    - "强调特殊情况：'0' 不能单独解码，'0' 开头的两位数无效（除了 '10', '20'）。"
2.  **识别问题类型**：
    - "这是一个典型的动态规划问题，类似于爬楼梯或斐波那契数列。当前位置的解码数依赖于之前位置的解码数。"
3.  **DP 思路 (DP 数组)**：
    - "**状态定义:** `dp[i]` 表示字符串 `s` 前 `i` 个字符的解码方法总数。"
    - "**递推关系:** `dp[i]` 的值取决于 `s[i-1]` 能否单独解码，以及 `s[i-2]s[i-1]` 能否组合解码。"
        - "如果 `s[i-1]` 是 1-9，则 `dp[i]` 可以从 `dp[i-1]` 转移过来。"
        - "如果 `s[i-2]s[i-1]` 是 10-26，则 `dp[i]` 还可以从 `dp[i-2]` 转移过来。"
        - "`dp[i]` 是这两种情况的和。"
    - "**基准情况:** `dp[0] = 1` (空串)。`dp[1]` 根据 `s[0]` 是否为 '0' 决定。"
    - "**实现:** 创建 `dp` 数组，处理 `dp[0]` 和 `dp[1]`，然后循环从 `i=2` 到 `n` 计算 `dp[i]`。"
    - "**复杂度:** 时间 O(N)，空间 O(N)。"
4.  **空间优化**：
    - "观察到 `dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，可以用两个变量 `prev` 和 `curr` 来代替 DP 数组，将空间复杂度降为 O(1)。"
    - "循环中计算 `next_val = (contribution from curr) + (contribution from prev)`，然后更新 `prev = curr`, `curr = next_val`。"
    - "**复杂度:** 时间 O(N)，空间 O(1)。"
5.  **代码演示**：
    - "优先展示空间优化的 O(1) 方法，因为它更优。如果需要，也可以写出 O(N) 空间的版本。"
