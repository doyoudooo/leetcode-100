给定一个非负整数 `numRows`，生成「杨辉三角」的前 `numRows` 行。

在「杨辉三角」中，每个数是它左上方和右上方的数的和。

![Pascal's Triangle](https://upload.wikimedia.org/wikipedia/commons/0/0d/PascalTriangleAnimated2.gif)

**示例 1:**

```
输入: numRows = 5
输出: [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
```

**示例 2:**

```
输入: numRows = 1
输出: [[1]]
```

**提示:**

*   `1 <= numRows <= 30`

## 解决方法

### 1. 问题理解

**目标：** 生成杨辉三角的前 `numRows` 行。
**规则：**
- 杨辉三角是一个二维结构。
- 第 `i` 行（从 0 开始计数）有 `i+1` 个元素。
- 每行的第一个和最后一个元素都是 1。
- 对于第 `i` 行的第 `j` 个元素（`0 < j < i`），它的值等于第 `i-1` 行的第 `j-1` 个元素和第 `j` 个元素的和。
**输入：** 行数 `numRows`。
**输出：** 一个包含前 `numRows` 行的二维列表。

### 2. 思路分析 (动态规划 / 模拟)

我们可以直接根据杨辉三角的生成规则来模拟构建过程。这可以看作是一种动态规划，因为每一行的生成都依赖于上一行。

**状态定义：**
`triangle[i]` 表示杨辉三角的第 `i` 行（从 0 开始计数）。

**递推关系：**
- `triangle[i][0] = 1`
- `triangle[i][i] = 1`
- `triangle[i][j] = triangle[i-1][j-1] + triangle[i-1][j]` (for `0 < j < i`)

**算法流程：**
1.  **初始化：** 创建一个空列表 `result` 来存储整个杨辉三角。
2.  **处理边界：** 如果 `numRows == 0`，返回空列表 `[]`。
3.  **生成第一行：** 将 `[1]` 添加到 `result`。
4.  **循环生成后续行：** 从 `i = 1` 到 `numRows - 1` (代表生成第 1 行到第 `numRows - 1` 行，共 `numRows` 行)：
    - 获取上一行 `prev_row = result[i-1]`。
    - 创建当前行 `current_row`，并添加第一个元素 `1`。
    - 遍历上一行的相邻元素来计算当前行的中间元素：对于 `j` 从 1 到 `len(prev_row) - 1` (即 `i-1`)，计算 `value = prev_row[j-1] + prev_row[j]`，并将 `value` 添加到 `current_row`。
    - 添加当前行的最后一个元素 `1`。
    - 将 `current_row` 添加到 `result`。
5.  **返回结果：** 返回 `result`。

### 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        """
        生成杨辉三角的前 numRows 行。
        """
        if numRows <= 0:
            return []
            
        triangle = []
        
        for i in range(numRows):
            # 第 i 行有 i+1 个元素
            current_row = [1] * (i + 1) 
            
            # 计算中间元素的值 (如果行号 i >= 2)
            if i >= 2:
                prev_row = triangle[i - 1]
                for j in range(1, i): # j 的范围是 1 到 i-1
                    current_row[j] = prev_row[j - 1] + prev_row[j]
                    
            triangle.append(current_row)
            
        return triangle

```

### 4. 复杂度分析

- **时间复杂度：** O(numRows^2)。我们需要生成 `numRows` 行，第 `i` 行需要计算 `i-1` 个中间元素，每个计算是 O(1)。总计算次数大约是 1 + 2 + ... + (numRows-1)，这是 O(numRows^2) 级别的。
- **空间复杂度：** O(numRows^2)。我们需要存储整个杨辉三角，其元素总数约为 numRows^2 / 2。如果只考虑额外空间（不包括结果存储），则为 O(1) 或 O(numRows)（取决于是否需要存储上一行）。但通常结果本身的空间会被计算在内。
