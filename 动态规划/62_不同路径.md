## 解决方法

### 1. 问题理解

**目标：** 计算从 `m x n` 网格的左上角 `(0, 0)` 到右下角 `(m-1, n-1)` 的不同路径数量。
**约束：** 机器人只能向下或向右移动。
**输入：** 网格的行数 `m` 和列数 `n`。
**输出：** 不同的路径总数。

### 2. 思路分析

#### 方法一：动态规划 (O(m*n))

这是一个典型的路径计数问题，非常适合使用动态规划。

**状态定义：**
设 `dp[i][j]` 为从左上角 `(0, 0)` 到达网格中位置 `(i, j)` 的不同路径数量。
我们的目标是求 `dp[m-1][n-1]`。

**状态转移方程 (递推关系)：**
要到达位置 `(i, j)`，机器人只能从两个方向过来：
1.  从上方：从位置 `(i-1, j)` 向下移动一步。
2.  从左方：从位置 `(i, j-1)` 向右移动一步。

因此，到达 `(i, j)` 的总路径数等于到达 `(i-1, j)` 的路径数加上到达 `(i, j-1)` 的路径数。
`dp[i][j] = dp[i-1][j] + dp[i][j-1]` (对于 `i > 0` 且 `j > 0`)

**基准情况 (Base Cases)：**
- **第一行：** 对于网格的第一行 `(0, j)`，机器人只能一直向右移动才能到达。所以 `dp[0][j] = 1` for all `0 <= j < n`。
- **第一列：** 对于网格的第一列 `(i, 0)`，机器人只能一直向下移动才能到达。所以 `dp[i][0] = 1` for all `0 <= i < m`。
- **起点：** `dp[0][0] = 1` (只有一种方式到达起点，即原地不动或视为起始状态)。

**算法流程 (DP 数组)：**
1.  创建一个 `m x n` 的 DP 数组 `dp`。
2.  初始化第一行和第一列的所有元素为 1。
3.  外层循环：遍历行 `i` 从 1 到 `m-1`。
4.  内层循环：遍历列 `j` 从 1 到 `n-1`。
5.  应用状态转移方程计算 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`。
6.  返回 `dp[m-1][n-1]`。

**空间优化 (滚动数组)：**
观察到 `dp[i][j]` 只依赖于 `dp[i-1][j]` (上一行的同一列) 和 `dp[i][j-1]` (当前行的前一列)。
我们可以只用一个一维数组来优化空间。

**算法流程 (空间优化 - 一个数组)：**
1.  创建一个大小为 `n` 的一维数组 `dp`。
2.  初始化 `dp` 的所有元素为 1 (这代表了第一行的路径数)。
3.  外层循环：遍历行 `i` 从 1 到 `m-1`。
4.  内层循环：遍历列 `j` 从 1 到 `n-1`。
5.  更新 `dp[j]`：新的 `dp[j]` (代表 `dp[i][j]`) 等于旧的 `dp[j]` (代表 `dp[i-1][j]`) 加上新的 `dp[j-1]` (代表 `dp[i][j-1]`)。
    `dp[j] = dp[j] + dp[j-1]`
    (注意：`dp[0]` 始终为 1，代表每行的第一列)。
6.  外层循环结束后，`dp[n-1]` 就是结果。

#### 方法二：组合数学 (O(min(m, n)))

从 `(0, 0)` 到 `(m-1, n-1)`，机器人总共需要移动 `(m-1) + (n-1)` 步。
其中，必须有 `m-1` 步是向下移动，`n-1` 步是向右移动。
问题转化为：在总共 `(m-1) + (n-1)` 步中，选择 `m-1` 步向下移动（剩下的 `n-1` 步自然就是向右移动），有多少种不同的选择方法？

这是一个组合问题，答案是组合数 C(总步数, 向下步数) 或 C(总步数, 向右步数)。
总步数 = `m + n - 2`
向下步数 = `m - 1`
向右步数 = `n - 1`

路径数 = C(m + n - 2, m - 1) = C(m + n - 2, n - 1)

计算组合数 C(N, k) = N! / (k! * (N-k)!)。
为了避免计算巨大的阶乘导致溢出，可以边乘边除：
C(N, k) = (N * (N-1) * ... * (N-k+1)) / k!

**算法流程 (组合数学)：**
1.  计算总步数 `N = m + n - 2`。
2.  计算需要选择的步数 `k = min(m - 1, n - 1)` (选择较小的可以减少计算量)。
3.  计算组合数 C(N, k)。可以使用循环来计算分子和分母的乘积，并进行约分或直接计算。
    ```python
    result = 1
    for i in range(k):
        result = result * (N - i) // (i + 1)
    return result
    ```
4.  返回计算结果。

### 3. 代码实现 (Python)

#### 方法一：动态规划 (二维 DP)

```python
class Solution:
    def uniquePaths_dp_2d(self, m: int, n: int) -> int:
        """
        使用二维 DP 数组计算不同路径数量。
        """
        dp = [[0] * n for _ in range(m)]
        
        # 初始化第一行和第一列
        for i in range(m):
            dp[i][0] = 1
        for j in range(n):
            dp[0][j] = 1
            
        # 填充剩余部分
        for i in range(1, m):
            for j in range(1, n):
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
                
        return dp[m - 1][n - 1]
```

#### 方法一：动态规划 (空间优化 - 一维 DP)

```python
class Solution:
    def uniquePaths_dp_1d(self, m: int, n: int) -> int:
        """
        使用空间优化的一维 DP 数组计算不同路径数量。
        """
        # dp 数组大小为 n (列数)
        dp = [1] * n 
        
        # 从第二行开始计算 (i 从 1 到 m-1)
        for i in range(1, m):
            # 从第二列开始更新 (j 从 1 到 n-1)
            # dp[0] 始终是 1，不需要更新
            for j in range(1, n):
                # dp[j] (新) = dp[j] (旧，来自上一行) + dp[j-1] (新，来自当前行左侧)
                dp[j] += dp[j - 1]
                
        return dp[n - 1]
```

#### 方法二：组合数学

```python
import math

class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        """
        使用组合数学计算不同路径数量。
        """
        # 总步数 N = m + n - 2
        # 选择步数 k = min(m - 1, n - 1)
        N = m + n - 2
        k = min(m - 1, n - 1)
        
        # 计算 C(N, k)
        result = 1
        # 分子: N * (N-1) * ... * (N-k+1)
        # 分母: k * (k-1) * ... * 1
        for i in range(k):
            # 避免溢出，边乘边除
            result = result * (N - i) // (i + 1)
            
        return result
```

### 4. 复杂度分析

- **方法一 (DP - 二维)：**
    - 时间复杂度：O(m * n)。需要填充 `m x n` 的 DP 表。
    - 空间复杂度：O(m * n)。需要 `m x n` 的 DP 数组。
- **方法一 (DP - 一维)：**
    - 时间复杂度：O(m * n)。
    - 空间复杂度：O(min(m, n))。通过确保 DP 数组大小是较小的维度 `min(m, n)` 来实现。
- **方法二 (组合数学)：**
    - 时间复杂度：O(min(m, n))。计算组合数 C(N, k) 需要 O(k) 次乘法和除法，其中 `k = min(m-1, n-1)`。
    - 空间复杂度：O(1)。只需要常数个额外变量。

**结论：** 组合数学方法在时间和空间上都是最优的。动态规划（尤其是一维优化）也是常见的解法。

    - "**递推关系:** 到达 `(i, j)` 只能从 `(i-1, j)` 或 `(i, j-1)` 来，所以 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`。"

    - "**实现:** 可以用二维数组 O(m*n) 空间，或优化为一维数组 O(min(m, n)) 空间。"

    - "**核心思想:** 从 `(0, 0)` 到 `(m-1, n-1)` 总共需要走 `m+n-2` 步，其中 `m-1` 步向下，`n-1` 步向右。"
    - "**转化:** 问题等价于在 `m+n-2` 步中选择 `m-1` 步向下（或选择 `n-1` 步向右）的组合数。"
    - "**公式:** C(m+n-2, m-1) 或 C(m+n-2, n-1)。"
    - "**实现:** 可以用循环高效计算组合数，避免大数阶乘溢出。"
    - "**复杂度:** 时间 O(min(m, n))，空间 O(1)。"
