给你一个字符串 `s`，找到 `s` 中最长的回文子串。

如果字符串的反序与原始字符串相同，则该字符串称为回文字符串。

**示例 1：**

```
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。
```

**示例 2：**

```
输入：s = "cbbd"
输出："bb"
```

**提示：**

*   `1 <= s.length <= 1000`
*   `s` 仅由数字和英文字母组成

## 解决方法

### 1. 问题理解

**目标：** 找到给定字符串 `s` 中最长的回文子串。
**回文串：** 正读和反读都一样的字符串。
**子串：** 字符串中连续的一段字符序列。
**输入：** 字符串 `s`。
**输出：** `s` 中的一个最长回文子串（如果有多个，返回任意一个即可）。

### 2. 思路分析

#### 方法一：动态规划 (O(N^2))

**状态定义：**
设 `dp[i][j]` 为一个布尔值，表示子串 `s[i...j]` (包含 `i` 和 `j`) 是否是回文串。

**状态转移方程 (递推关系)：**
要判断 `s[i...j]` 是否是回文串，需要满足两个条件：
1.  两端字符相等：`s[i] == s[j]`。
2.  去掉两端字符后的内部子串 `s[i+1...j-1]` 也是回文串。

所以，状态转移方程为：
`dp[i][j] = (s[i] == s[j]) and dp[i+1][j-1]`

**基准情况 (Base Cases)：**
- **长度为 1 的子串：** `dp[i][i] = True` (单个字符总是回文串)。
- **长度为 2 的子串：** `dp[i][i+1] = (s[i] == s[i+1])`。

**注意事项：**
- 状态转移方程 `dp[i][j]` 依赖于 `dp[i+1][j-1]`。这意味着在计算 `dp[i][j]` 时，`dp[i+1][j-1]` 必须已经被计算出来。
- 这要求我们改变遍历顺序。常见的做法是：
    - 按子串长度 `L` 从 1 到 `n` 遍历。
    - 对于每个长度 `L`，遍历起始索引 `i`，计算 `j = i + L - 1`，然后计算 `dp[i][j]`。
    - 或者，固定右边界 `j`，从 0 到 `n-1` 遍历；内层循环固定左边界 `i`，从 `j` 向 0 遍历。这样可以保证计算 `dp[i][j]` 时，`dp[i+1][j-1]` 已经被计算过。

**记录最长回文子串：**
在填充 `dp` 表的过程中，每当 `dp[i][j]` 被确定为 `True` 时，我们就找到了一个回文子串 `s[i...j]`。我们需要记录下当前找到的最长回文子串的起始索引和长度。

**算法流程 (DP 数组 - 按右边界 j 遍历)：**
1.  获取字符串长度 `n`。如果 `n < 2`，返回 `s` 本身。
2.  创建 `n x n` 的 DP 布尔数组 `dp`。
3.  初始化 `max_len = 1`, `start_index = 0` (用于记录最长回文子串的长度和起始位置)。
4.  外层循环：遍历右边界 `j` 从 1 到 `n-1`。
5.  内层循环：遍历左边界 `i` 从 0 到 `j-1`。
6.  判断 `s[i]` 和 `s[j]` 是否相等：
    - 如果 `s[i] != s[j]`，则 `dp[i][j] = False`。
    - 如果 `s[i] == s[j]`：
        - 如果子串长度 `j - i + 1 <= 2` (即长度为 1 或 2)，则 `dp[i][j] = True`。
        - 如果子串长度 `j - i + 1 > 2`，则 `dp[i][j] = dp[i+1][j-1]`。
7.  如果 `dp[i][j]` 为 `True`，并且当前回文子串长度 `j - i + 1` 大于 `max_len`，则更新 `max_len = j - i + 1` 和 `start_index = i`。
8.  **处理长度为 1 的情况：** 单独处理或在循环开始前初始化 `dp[i][i] = True`。如果按上述 `j` 从 1 开始，`i` 从 0 到 `j-1` 的方式，长度为 1 的情况 `dp[i][i]` 不会被计算。可以在循环外初始化 `dp[k][k]=True` for all `k`，或者在循环内判断 `j-i+1 <= 2`。
9.  返回 `s[start_index : start_index + max_len]`。

#### 方法二：中心扩展法 (O(N^2))

**核心思想：**
回文串都是关于其中心对称的。中心可能是一个字符（奇数长度回文串，如 "aba" 中心是 'b'），也可能是两个字符之间的空隙（偶数长度回文串，如 "abba" 中心是 "bb" 之间的空隙）。
我们可以遍历所有可能的中心，然后从中心向两边扩展，直到不再是回文串为止，记录下找到的最长回文串。

**算法流程：**
1.  获取字符串长度 `n`。如果 `n < 2`，返回 `s` 本身。
2.  初始化 `max_len = 1`, `start_index = 0`。
3.  遍历所有可能的中心 `i` 从 0 到 `n-1`：
    - **奇数长度：** 以 `s[i]` 为中心进行扩展。调用 `expandAroundCenter(s, i, i)`。
    - **偶数长度：** 以 `s[i]` 和 `s[i+1]` 之间的空隙为中心进行扩展。调用 `expandAroundCenter(s, i, i+1)`。
    - 比较两次扩展得到的长度，取最大值 `current_max_len`。
    - 如果 `current_max_len > max_len`，更新 `max_len = current_max_len` 和 `start_index` (计算方式为 `i - (max_len - 1) // 2`)。
4.  **`expandAroundCenter` 函数：**
    - 输入字符串 `s`，左指针 `left`，右指针 `right`。
    - 当 `left >= 0` 且 `right < n` 且 `s[left] == s[right]` 时：
        - `left -= 1`
        - `right += 1`
    - 返回回文串的长度 `right - left - 1`。
5.  返回 `s[start_index : start_index + max_len]`。

### 3. 代码实现 (Python)

#### 方法一：动态规划 (O(N^2))

```python
class Solution:
    def longestPalindrome_dp(self, s: str) -> str:
        """
        使用动态规划计算最长回文子串。
        """
        n = len(s)
        if n < 2:
            return s
            
        dp = [[False] * n for _ in range(n)]
        max_len = 1
        start_index = 0
        
        # 初始化长度为 1 的子串
        for i in range(n):
            dp[i][i] = True
            
        # 填充 dp 表
        # 先遍历右边界 j
        for j in range(1, n):
            # 再遍历左边界 i
            for i in range(j):
                if s[i] == s[j]:
                    # 如果长度小于等于 3 (j-i+1 <= 3, 即 j-i <= 2)
                    # 只需要判断 s[i] == s[j]
                    if j - i <= 2: 
                        dp[i][j] = True
                    else:
                        # 依赖左下角的值
                        dp[i][j] = dp[i + 1][j - 1]
                else:
                    dp[i][j] = False
                    
                # 如果 dp[i][j] 是 True，更新最长回文串信息
                if dp[i][j]:
                    current_len = j - i + 1
                    if current_len > max_len:
                        max_len = current_len
                        start_index = i
                        
        return s[start_index : start_index + max_len]

```

#### 方法二：中心扩展法 (O(N^2))

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        """
        使用中心扩展法计算最长回文子串。
        """
        n = len(s)
        if n < 2:
            return s
            
        start_index = 0
        max_len = 1
        
        def expandAroundCenter(left: int, right: int) -> int:
            # 从中心向两边扩展
            while left >= 0 and right < n and s[left] == s[right]:
                left -= 1
                right += 1
            # 返回回文串的长度
            return right - left - 1

        for i in range(n):
            # 奇数长度回文串
            len1 = expandAroundCenter(i, i)
            # 偶数长度回文串
            len2 = expandAroundCenter(i, i + 1)
            
            current_max_len = max(len1, len2)
            
            if current_max_len > max_len:
                max_len = current_max_len
                # 计算新的起始索引
                start_index = i - (max_len - 1) // 2
                
        return s[start_index : start_index + max_len]
```

### 4. 复杂度分析

- **方法一 (DP)：**
    - 时间复杂度：O(N^2)。需要填充 O(N^2) 个状态，每个状态计算是 O(1)。
    - 空间复杂度：O(N^2)。需要 `N x N` 的 DP 数组。
- **方法二 (中心扩展法)：**
    - 时间复杂度：O(N^2)。有 O(N) 个中心，每个中心最多扩展 O(N) 次。
    - 空间复杂度：O(1)。只需要常数个额外变量来存储结果。

**结论：** 中心扩展法在空间复杂度上更优。在实践中，由于其常数因子较小，通常也比 DP 方法稍快。
