你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组 `nums`，计算你 **不触动警报装置的情况下** ，一夜之内能够偷窃到的最高金额。

**示例 1：**

```
输入：nums = [1,2,3,1]
输出：4
解释：偷窃 1 号房屋 (金额 = 1) ，然后偷窃 3 号房屋 (金额 = 3)。
     偷窃到的最高金额 = 1 + 3 = 4 。
```

**示例 2：**

```
输入：nums = [2,7,9,3,1]
输出：12
解释：偷窃 1 号房屋 (金额 = 2), 偷窃 3 号房屋 (金额 = 9)，接着偷窃 5 号房屋 (金额 = 1)。
     偷窃到的最高金额 = 2 + 9 + 1 = 12 。
```

**提示：**

*   `1 <= nums.length <= 100`
*   `0 <= nums[i] <= 400`

## 解决方法

### 1. 问题理解

**目标：** 在不能偷窃相邻房屋的前提下，从一系列房屋中偷窃到最高总金额。
**输入：** 非负整数数组 `nums`，`nums[i]` 代表第 `i` 个房屋的金额（从 0 开始计数）。
**输出：** 能够偷窃到的最高金额。

### 2. 思路分析 (动态规划)

这是一个典型的动态规划问题。我们需要做出一系列决策（偷或不偷某个房子），并且每个决策会影响后续的决策（不能偷相邻的）。

**状态定义：**
设 `dp[i]` 为考虑前 `i` 个房屋（即 `nums[0]` 到 `nums[i-1]`），能够偷窃到的最高金额。我们的目标是求 `dp[n]`，其中 `n` 是房屋数量。

**状态转移方程 (递推关系)：**
考虑第 `i` 个房屋（对应数组索引 `i-1`）：
1.  **不偷第 `i` 个房屋 (`nums[i-1]`)：** 如果不偷第 `i` 个房屋，那么能获得的最大金额就等于偷前 `i-1` 个房屋能获得的最大金额，即 `dp[i-1]`。
2.  **偷第 `i` 个房屋 (`nums[i-1]`)：** 如果偷第 `i` 个房屋，那么根据规则，就不能偷第 `i-1` 个房屋 (`nums[i-2]`)。因此，最大金额等于偷前 `i-2` 个房屋能获得的最大金额 `dp[i-2]` 加上第 `i` 个房屋的金额 `nums[i-1]`。即 `dp[i-2] + nums[i-1]`。

我们需要在这两种选择中取最大值：
`dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])` (对于 `i >= 2`)

**基准情况 (Base Cases)：**
- `dp[0]`：考虑前 0 个房屋，能偷到的最大金额为 0。`dp[0] = 0`。
- `dp[1]`：考虑前 1 个房屋 (`nums[0]`)，只能选择偷或不偷这一个。最大金额为 `nums[0]`。`dp[1] = nums[0]`。
- `dp[2]`：考虑前 2 个房屋 (`nums[0]`, `nums[1]`)。
    - 不偷 `nums[1]`：最大金额是 `dp[1] = nums[0]`。
    - 偷 `nums[1]`：最大金额是 `dp[0] + nums[1] = 0 + nums[1] = nums[1]`。
    - 所以 `dp[2] = max(nums[0], nums[1])`。
    - 验证递推公式：`dp[2] = max(dp[1], dp[0] + nums[1]) = max(nums[0], 0 + nums[1]) = max(nums[0], nums[1])`。公式成立。

**算法流程 (DP 数组)：**
1.  处理边界情况：如果 `nums` 为空，返回 0。如果只有一个房屋，返回 `nums[0]`。
2.  创建大小为 `n+1` 的 DP 数组 `dp`。
3.  初始化基准情况：`dp[0] = 0`, `dp[1] = nums[0]`。
4.  使用循环从 `i = 2` 到 `n` 计算 `dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])`。
5.  返回 `dp[n]`。

**空间优化 (滚动变量)：**
同样，`dp[i]` 只依赖于 `dp[i-1]` 和 `dp[i-2]`。我们可以用两个变量来优化空间。

**算法流程 (空间优化)：**
1.  处理边界情况：如果 `nums` 为空，返回 0。如果只有一个房屋，返回 `nums[0]`。
2.  初始化前两个状态：`prev2 = 0` (对应 `dp[0]`)，`prev1 = nums[0]` (对应 `dp[1]`)。
3.  使用循环从 `i = 2` 到 `n` (对应房屋索引 `i-1` 从 1 到 `n-1`)：
    - 计算当前状态 `current = max(prev1, prev2 + nums[i-1])`。
    - 更新前两个状态：`prev2 = prev1`，`prev1 = current`。
4.  循环结束后，`prev1` 就是 `dp[n]` 的值，返回它。

### 3. 代码实现 (Python)

#### 方法一：动态规划 (DP 数组)

```python
from typing import List

class Solution:
    def rob_dp_array(self, nums: List[int]) -> int:
        """
        使用 DP 数组解决打家劫舍问题。
        """
        n = len(nums)
        if n == 0:
            return 0
        if n == 1:
            return nums[0]
            
        dp = [0] * (n + 1) # dp[i] 表示考虑前 i 个房屋的最大金额
        dp[0] = 0
        dp[1] = nums[0]
        
        for i in range(2, n + 1):
            # 对应房屋索引 i-1
            # dp[i] = max(不偷第 i 个房子, 偷第 i 个房子)
            dp[i] = max(dp[i - 1], dp[i - 2] + nums[i - 1])
            
        return dp[n]
```

#### 方法二：动态规划 (空间优化)

```python
from typing import List

class Solution:
    def rob(self, nums: List[int]) -> int:
        """
        使用空间优化的动态规划解决打家劫舍问题。
        """
        n = len(nums)
        if n == 0:
            return 0
        if n == 1:
            return nums[0]
            
        # prev2 对应 dp[i-2], prev1 对应 dp[i-1]
        prev2 = 0
        prev1 = nums[0]
        
        for i in range(1, n): # 遍历房屋索引从 1 到 n-1
            # 当前房屋是 nums[i]
            # 计算 dp[i+1]
            current = max(prev1, prev2 + nums[i])
            prev2 = prev1
            prev1 = current
            
        return prev1 # 最终 prev1 存储的是 dp[n]
```

### 4. 复杂度分析

- **DP 数组方法：**
    - 时间复杂度：O(N)，需要循环 N 次。
    - 空间复杂度：O(N)，需要大小为 N+1 的 DP 数组。
- **空间优化方法：**
    - 时间复杂度：O(N)，需要循环 N 次。
    - 空间复杂度：O(1)，只需要常数个额外变量。

**结论：** 空间优化的动态规划方法是最高效的。
