给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长子串** 的长度。

**示例 1:**

```
输入: s = "abcabcbb"
输出: 3 
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。
```

**示例 2:**

```
输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。
```

**示例 3:**

```
输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
     请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。
```

**提示：**

*   `0 <= s.length <= 5 * 10^4`
*   `s` 由英文字母、数字、符号和空格组成

## 解决方法

### 1. 问题理解

**目标：** 找到给定字符串 `s` 中不包含重复字符的最长子串的长度。
**子串 vs 子序列：** 子串必须是连续的，子序列可以不连续。
**输入：** 字符串 `s`。
**输出：** 一个整数，表示最长无重复字符子串的长度。

### 2. 思路分析 (滑动窗口)

这个问题非常适合使用**滑动窗口** (Sliding Window) 的技巧来解决。滑动窗口是一个用于在数组或字符串上执行某些操作的抽象概念。它通常由两个指针（左指针 `left` 和右指针 `right`）定义，表示一个子数组或子字符串。

**核心思想：**
- 维护一个窗口 `[left, right]`，确保这个窗口内的子串始终没有重复字符。
- 不断移动右指针 `right` 来扩大窗口。
- 当窗口内出现重复字符时，移动左指针 `left` 来缩小窗口，直到窗口内不再有重复字符。
- 在整个过程中，记录窗口的最大长度。

**如何检测窗口内的重复字符？**
- 可以使用一个**哈希集合 (Set)** 来存储窗口内当前包含的字符。当向窗口添加新字符时，检查该字符是否已存在于集合中。
- 也可以使用一个**哈希映射 (Dictionary/Map)** 或**数组**来存储窗口内每个字符最后出现的位置。这在移动左指针时更有效率。

**算法流程 (使用哈希集合):**
1.  **初始化：**
    - 左指针 `left = 0`。
    - 最大长度 `max_len = 0`。
    - 哈希集合 `char_set = set()` 用于存储当前窗口内的字符。
2.  **移动右指针：** 使用右指针 `right` 遍历字符串 `s` (从 0 到 `len(s) - 1`)：
    - 获取当前字符 `current_char = s[right]`。
    - **检查重复：** 当 `current_char` 已经存在于 `char_set` 中时：
        - 从 `char_set` 中移除左指针 `left` 指向的字符 `s[left]`。
        - 将左指针 `left` 向右移动一位 (`left += 1`)。
        - 重复此过程，直到 `current_char` 不再存在于 `char_set` 中（即窗口内不再包含重复的 `current_char`）。
    - **添加新字符：** 将 `current_char` 添加到 `char_set` 中。
    - **更新最大长度：** 计算当前窗口的长度 `right - left + 1`，并更新 `max_len = max(max_len, right - left + 1)`。
3.  **返回结果：** 遍历结束后，`max_len` 就是最长无重复字符子串的长度。

**算法流程 (使用哈希映射优化):**
这种方法可以更快地移动左指针。哈希映射 `char_map` 存储字符到其在窗口中**最新出现位置**的映射。

1.  **初始化：**
    - 左指针 `left = 0`。
    - 最大长度 `max_len = 0`。
    - 哈希映射 `char_map = {}` 用于存储字符及其最新索引。
2.  **移动右指针：** 使用右指针 `right` 遍历字符串 `s` (从 0 到 `len(s) - 1`)：
    - 获取当前字符 `current_char = s[right]`。
    - **检查重复及位置：** 如果 `current_char` 在 `char_map` 中，并且其最后出现的位置 `char_map[current_char]` 大于等于当前的左指针 `left` (`char_map[current_char] >= left`)，这意味着 `current_char` 在当前窗口 `[left, right]` 内重复了。
        - **移动左指针：** 为了确保窗口内没有重复，需要将左指针 `left` 移动到重复字符的**下一个位置**，即 `left = char_map[current_char] + 1`。
    - **更新字符位置：** 将当前字符 `current_char` 及其索引 `right` 存入（或更新）哈希映射 `char_map[current_char] = right`。
    - **更新最大长度：** 计算当前有效窗口的长度 `right - left + 1`，并更新 `max_len = max(max_len, right - left + 1)`。
3.  **返回结果：** 遍历结束后，`max_len` 就是最长无重复字符子串的长度。

### 3. 代码实现 (Python)

#### 方法一：滑动窗口 + 哈希集合

```python
class Solution:
    def lengthOfLongestSubstring_set(self, s: str) -> int:
        """
        使用滑动窗口和哈希集合查找最长无重复字符子串的长度。
        """
        n = len(s)
        if n == 0:
            return 0
            
        char_set = set()
        left = 0
        max_len = 0
        
        for right in range(n):
            current_char = s[right]
            # 如果发现重复字符，缩小窗口直到不重复
            while current_char in char_set:
                char_set.remove(s[left])
                left += 1
            # 将当前字符加入集合
            char_set.add(current_char)
            # 更新最大长度
            max_len = max(max_len, right - left + 1)
            
        return max_len
```

#### 方法二：滑动窗口 + 哈希映射 (优化)

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        """
        使用滑动窗口和哈希映射优化查找最长无重复字符子串的长度。
        """
        n = len(s)
        if n == 0:
            return 0
            
        char_map = {} # 存储字符 -> 最新索引
        left = 0
        max_len = 0
        
        for right in range(n):
            current_char = s[right]
            
            # 如果字符已存在且在当前窗口内，更新 left 指针
            if current_char in char_map and char_map[current_char] >= left:
                left = char_map[current_char] + 1
                
            # 更新字符的最新位置
            char_map[current_char] = right
            # 更新最大长度
            max_len = max(max_len, right - left + 1)
            
        return max_len

```

### 4. 复杂度分析

- **方法一 (哈希集合)：**
    - 时间复杂度：O(N)。虽然有 `while` 循环，但每个字符最多被访问两次（一次被 `right` 指针访问，一次可能被 `left` 指针移除）。因此总体是线性的。
    - 空间复杂度：O(M)，其中 M 是字符集的大小。最坏情况下，字符串中所有字符都不同，集合会存储 M 个字符。
- **方法二 (哈希映射)：**
    - 时间复杂度：O(N)。每个字符只被访问一次。哈希映射的操作平均是 O(1)。
    - 空间复杂度：O(M)，其中 M 是字符集的大小。哈希映射需要存储字符及其索引。

**结论：** 方法二（哈希映射优化）通常效率更高，因为它避免了 `while` 循环来移动左指针，而是直接跳到合适的位置。
