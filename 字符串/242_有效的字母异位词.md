给定两个字符串 `s` 和 `t` ，编写一个函数来判断 `t` 是否是 `s` 的字母异位词。

**注意：**若 `s` 和 `t` 中每个字符出现的次数都相同，则称 `s` 和 `t` 互为字母异位词。

**示例 1:**

```
输入: s = "anagram", t = "nagaram"
输出: true
```

**示例 2:**

```
输入: s = "rat", t = "car"
输出: false
```

**提示:**

*   `1 <= s.length, t.length <= 5 * 10^4`
*   `s` 和 `t` 仅包含小写字母

**进阶:** 如果输入字符串包含 unicode 字符怎么办？你能否调整你的解法来应对这种情况？

## 解决方法

### 1. 问题理解

**目标：** 判断两个字符串 `s` 和 `t` 是否互为字母异位词。
**字母异位词定义：** 两个字符串包含完全相同的字符，且每个字符出现的次数也完全相同，只是字符的顺序可能不同。

### 2. 思路分析

#### 方法一：排序

如果两个字符串是字母异位词，那么将它们各自排序后得到的字符串一定是相同的。

**算法流程：**
1.  **检查长度：** 如果 `s` 和 `t` 的长度不同，它们肯定不是字母异位词，直接返回 `False`。
2.  **排序：** 将字符串 `s` 和 `t` 分别转换成字符列表，并进行排序。
3.  **比较：** 比较排序后的两个列表（或转换回字符串后比较）是否相等。如果相等，返回 `True`；否则返回 `False`。

**代码实现 (Python):**

```python
class Solution:
    def isAnagram_sort(self, s: str, t: str) -> bool:
        """
        使用排序判断是否为字母异位词。
        """
        if len(s) != len(t):
            return False
        
        # 对字符串排序后比较 O(N log N)
        return sorted(s) == sorted(t) 
```

**复杂度分析:**
- **时间复杂度：** O(N log N)，其中 N 是字符串的长度。主要开销在于排序。
- **空间复杂度：** O(N) 或 O(log N)，取决于排序算法使用的空间（Python 的 `sorted()` 通常使用 Timsort，空间复杂度为 O(N)）。

#### 方法二：哈希表 (频率计数器)

统计每个字符串中各字符出现的频率，然后比较两个字符串的频率是否完全相同。

**算法流程：**
1.  **检查长度：** 如果 `s` 和 `t` 的长度不同，返回 `False`。
2.  **统计频率：**
    - 创建一个哈希表 `s_counts` (例如 Python 的 `collections.Counter`) 来统计 `s` 中每个字符的出现次数。
    - 创建另一个哈希表 `t_counts` 来统计 `t` 中每个字符的出现次数。
3.  **比较频率：** 比较 `s_counts` 和 `t_counts` 是否相等。如果两个哈希表完全相同（键和对应的值都相同），则返回 `True`；否则返回 `False`。

**优化：** 可以只用一个哈希表。先统计 `s` 的频率，然后遍历 `t`，将对应字符的计数减一。如果在遍历 `t` 的过程中发现某个字符计数变为负数，或者遍历完 `t` 后哈希表中存在非零计数的字符，则说明它们不是字母异位词。

**代码实现 (Python - 使用 Counter):**

```python
import collections

class Solution:
    def isAnagram_counter(self, s: str, t: str) -> bool:
        """
        使用哈希表 (Counter) 判断是否为字母异位词。
        """
        if len(s) != len(t):
            return False
            
        # 统计频率并比较 O(N)
        return collections.Counter(s) == collections.Counter(t)
```

**代码实现 (Python - 手动实现频率计数):**

```python
class Solution:
    def isAnagram_dict(self, s: str, t: str) -> bool:
        """
        手动实现哈希表频率计数。
        """
        if len(s) != len(t):
            return False
            
        s_counts = {}
        t_counts = {}
        
        # 统计 s 的频率 O(N)
        for char in s:
            s_counts[char] = s_counts.get(char, 0) + 1
            
        # 统计 t 的频率 O(N)
        for char in t:
            t_counts[char] = t_counts.get(char, 0) + 1
            
        # 比较两个字典 O(M)，M 是字符集大小 (最多 26)
        return s_counts == t_counts

```

**代码实现 (Python - 单哈希表优化):**

```python
class Solution:
    def isAnagram_single_dict(self, s: str, t: str) -> bool:
        """
        使用单个哈希表优化频率计数。
        """
        if len(s) != len(t):
            return False
            
        counts = {}
        # 统计 s
        for char in s:
            counts[char] = counts.get(char, 0) + 1
            
        # 减去 t 的计数
        for char in t:
            count = counts.get(char, 0)
            if count == 0: # t 中有多余的字符或某个字符数量超过 s
                return False
            counts[char] = count - 1
            
        # 最终检查 counts 是否所有值都为 0 (这一步其实可以省略，因为长度相等保证了)
        # for count in counts.values():
        #     if count != 0:
        #         return False
                
        return True
```

**复杂度分析 (哈希表方法):**
- **时间复杂度：** O(N)，其中 N 是字符串的长度。遍历字符串和操作哈希表都是线性的。比较两个 Counter 也是 O(N) 或 O(M)，M为字符集大小。
- **空间复杂度：** O(M)，其中 M 是字符集的大小。在题目中，M=26（小写字母）。如果处理 Unicode，M 可能很大。

#### 方法三：数组作为频率计数器 (针对小写字母优化)

由于题目明确说明字符串只包含小写字母，我们可以使用一个大小为 26 的数组来代替哈希表，作为频率计数器。数组的索引 `0` 到 `25` 分别对应字母 `'a'` 到 `'z'`。

**算法流程：**
1.  **检查长度：** 如果 `s` 和 `t` 的长度不同，返回 `False`。
2.  **初始化计数数组：** 创建一个大小为 26 的数组 `counts`，并初始化所有元素为 0。
3.  **统计频率差：**
    - 遍历字符串 `s`，对于每个字符 `char`，增加对应索引 `ord(char) - ord('a')` 的计数。
    - 遍历字符串 `t`，对于每个字符 `char`，减少对应索引 `ord(char) - ord('a')` 的计数。
4.  **检查计数：** 遍历 `counts` 数组。如果所有元素的计数都为 0，说明 `s` 和 `t` 是字母异位词，返回 `True`；否则返回 `False`。

**代码实现 (Python):**

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        """
        使用数组作为频率计数器判断是否为字母异位词。
        """
        if len(s) != len(t):
            return False
            
        counts = [0] * 26 # 对应 'a' 到 'z'
        
        # 计算频率差 O(N)
        for i in range(len(s)):
            counts[ord(s[i]) - ord('a')] += 1
            counts[ord(t[i]) - ord('a')] -= 1
            
        # 检查计数是否全为 0 O(M)，M=26
        for count in counts:
            if count != 0:
                return False
                
        return True
```

**复杂度分析 (数组计数器方法):**
- **时间复杂度：** O(N)。遍历字符串是 O(N)，检查数组是 O(M)，M=26 是常数。
- **空间复杂度：** O(M)，M=26。空间复杂度是常数 O(1)。

### 3. 进阶问题：处理 Unicode 字符

如果字符串包含 Unicode 字符，字符集的大小会变得非常大，使用固定大小的数组作为计数器不再合适。这时，**方法二：哈希表 (频率计数器)** 是更通用的解决方案。

- 使用 `collections.Counter` 或手动实现的字典仍然有效。
- 时间复杂度仍然是 O(N)。
- 空间复杂度是 O(M)，其中 M 是字符串中不同 Unicode 字符的数量。在最坏情况下，如果所有字符都不同，M 可能接近 N。

排序方法仍然有效，但需要注意 Unicode 字符的排序规则和效率。

1.  **问题理解**：
    - "判断两个字符串 `s` 和 `t` 是否互为字母异位词，即它们是否包含完全相同的字符及出现次数。"
2.  **方法一：排序**：
    - "**思路:** 字母异位词排序后应该完全相同。"
    - "**流程:** 检查长度 -> 排序 `s` 和 `t` -> 比较排序后的结果。"
    - "**复杂度:** 时间 O(N log N)，空间 O(N) 或 O(log N)。"
    - "**优点:** 代码简洁。
    - "**缺点:** 效率不是最优。"
3.  **方法二：哈希表 (频率计数)**：
    - "**思路:** 统计每个字符在两个字符串中出现的次数，比较次数是否完全一致。"
    - "**流程:** 检查长度 -> 用 Counter 或字典统计 `s` 和 `t` 的频率 -> 比较两个频率表。"
    - "**优化:** 可以用一个哈希表，先加 `s` 的频率，再减 `t` 的频率，最后看是否都归零（或中途是否出现负数）。"
    - "**复杂度:** 时间 O(N)，空间 O(M) (M 为字符集大小)。"
    - "**优点:** 时间效率高。
    - "**缺点:** 需要额外空间。"
4.  **方法三：数组作为频率计数器 (针对小写字母)**：
    - "**思路:** 利用题目限制（仅小写字母），用大小为 26 的数组代替哈希表。"
    - "**流程:** 检查长度 -> 创建大小 26 的数组 -> 遍历 `s` 增加计数，遍历 `t` 减少计数 -> 检查数组是否全为 0。"
    - "**复杂度:** 时间 O(N)，空间 O(1) (因为数组大小固定为 26)。"
    - "**优点:** 时间和空间效率都很高（对于限定字符集）。"
5.  **进阶：Unicode 字符**：
    - "如果包含 Unicode，数组方法失效。哈希表方法仍然适用，空间复杂度变为 O(M)，M 是不同 Unicode 字符数。"
    - "排序方法也适用，但要注意排序效率和规则。"
6.  **总结与选择**：
    - "对于小写字母，数组计数器方法最优。"
    - "对于一般情况或 Unicode，哈希表方法是时间和空间上较好的权衡。"
    - "排序方法最简单，但效率稍差。"
