给你一个字符串 `s` 和一个整数 `k` 。你可以选择字符串中的任一字符，并将其更改为任何其他大写英文字母。该操作最多可执行 `k` 次。

在执行上述操作后，返回包含相同字母的最长子串的长度。

**示例 1：**

```
输入：s = "ABAB", k = 2
输出：4
解释：用两个'A'替换为两个'B',反之亦然。
```

**示例 2：**

```
输入：s = "AABABBA", k = 1
输出：4
解释：
将中间的一个'A'替换为'B',字符串变为 "AABBBBA"。
子串 "BBBB" 有最长重复字母, 长度为 4。
```

**提示：**

*   `1 <= s.length <= 10^5`
*   `s` 仅由大写英文字母组成
*   `0 <= k <= s.length`

## 解决方法

### 1. 问题理解

**目标：** 给定一个字符串 `s` 和一个整数 `k`，找到可以通过最多 `k` 次替换操作得到的、只包含相同字母的最长子串的长度。
**操作：** 可以将任意字符替换为任意其他大写字母，最多 `k` 次。
**关键：** 我们要找的是一个子串，在这个子串中，可以通过最多 `k` 次替换，使得子串中的所有字符都变成同一个字符。这个最长的子串长度是多少？

**转换问题：**
这个问题可以转换为：找到一个最长的子串，该子串中**出现次数最多的字符**的次数加上 `k` 大于等于子串的长度。
即：`window_length - max_frequency <= k`
其中 `window_length` 是子串（窗口）的长度，`max_frequency` 是该子串中出现次数最多的字符的频率。`window_length - max_frequency` 表示将该子串变为全是一种字符所需的最少替换次数。只要这个次数不大于 `k`，这个窗口就是有效的。

### 2. 思路分析 (滑动窗口)

我们可以使用滑动窗口来解决这个问题。

**核心思想：**
- 维护一个窗口 `[left, right]`。
- 记录窗口内每个字符的出现频率。
- 记录窗口内**出现次数最多的字符**的频率 `max_freq`。
- 不断移动右指针 `right` 扩大窗口。
- 检查当前窗口是否满足条件 `(right - left + 1) - max_freq <= k`。
    - 如果满足，说明当前窗口有效，尝试更新最大长度。
    - 如果不满足，说明需要替换的字符数超过了 `k`，此时需要移动左指针 `left` 缩小窗口，直到窗口再次满足条件。

**算法流程：**
1.  **初始化：**
    - 左指针 `left = 0`。
    - 最大长度 `max_len = 0`。
    - 字符频率数组（或哈希表）`counts = [0] * 26` (因为只有大写字母)。
    - 窗口内最高频率 `max_freq = 0`。
2.  **移动右指针：** 使用右指针 `right` 遍历字符串 `s` (从 0 到 `len(s) - 1`)：
    - 获取当前字符 `char = s[right]`。
    - **更新频率：** 增加 `char` 的计数 `counts[ord(char) - ord('A')] += 1`。
    - **更新最高频率：** 更新 `max_freq = max(max_freq, counts[ord(char) - ord('A')])`。
    - **检查窗口有效性：** 计算当前窗口长度 `window_len = right - left + 1`。
        - **如果窗口无效 (`window_len - max_freq > k`)：**
            - 获取左边界字符 `left_char = s[left]`。
            - 减少 `left_char` 的计数 `counts[ord(left_char) - ord('A')] -= 1`。
            - 将左指针 `left` 向右移动一位 (`left += 1`)。
            - **注意：** 这里不需要立即更新 `max_freq`。为什么？因为只有当被移除的 `left_char` 恰好是之前贡献了 `max_freq` 的那个字符，并且它的频率减少后，`max_freq` 才可能需要减小。但即使 `max_freq` 暂时偏大，也只会让窗口更早地（或在相同时间）变得无效，从而促使 `left` 指针右移。而我们关心的是窗口长度的最大值，只要窗口在某个时刻达到了某个长度 `L` 且满足条件，`max_len` 就会被更新为 `L`。之后即使 `max_freq` 暂时偏大导致窗口提前缩小，也不会影响最终结果，因为我们已经记录了合法的最大长度。这种优化避免了每次缩小窗口时重新计算 `max_freq`。
        - **如果窗口有效 (`window_len - max_freq <= k`)：**
            - 更新最大长度 `max_len = max(max_len, window_len)`。或者，由于窗口只在有效时扩展或保持大小，`max_len` 可以直接在循环外等于最终的窗口大小 `right - left + 1`（如果循环结束后计算的话）。更简单的做法是在每次循环结束时都更新 `max_len = max(max_len, right - left + 1)`，因为无效窗口不会让 `max_len` 变得更大。
3.  **返回结果：** 遍历结束后，`max_len` 就是答案。

**简化更新 `max_len` 的逻辑：**
由于我们只在 `window_len - max_freq <= k` 时才可能增大窗口长度，并且当条件不满足时我们会缩小窗口（`left` 增加，`right` 也增加，窗口长度不变或减小），所以窗口的最大长度一定是在满足条件时达到的。因此，我们可以在每次迭代结束时都尝试更新 `max_len`。

```python
class Solution:
    def characterReplacement(self, s: str, k: int) -> int:
        """
        使用滑动窗口计算替换后的最长重复字符子串长度。
        """
        n = len(s)
        if n == 0:
            return 0
            
        counts = [0] * 26 # 频率统计
        left = 0
        max_len = 0
        max_freq = 0 # 窗口内最高频率
        
        for right in range(n):
            char_idx = ord(s[right]) - ord('A')
            counts[char_idx] += 1
            # 更新窗口内的最高频率
            max_freq = max(max_freq, counts[char_idx])
            
            # 当前窗口长度
            window_len = right - left + 1
            
            # 判断是否需要缩小窗口
            # 需要替换的字符数 = 窗口长度 - 最高频率字符数
            if window_len - max_freq > k:
                # 缩小窗口
                left_char_idx = ord(s[left]) - ord('A')
                counts[left_char_idx] -= 1
                left += 1
                # 注意：这里不需要更新 max_freq，因为只有当移除的字符是最高频字符时才可能影响
                # 即使 max_freq 暂时偏大，也只会让窗口更快（或同时）满足收缩条件，不影响最终结果
            
            # 无论窗口是否缩小，都尝试更新 max_len
            # 因为只有在 window_len - max_freq <= k 时，窗口才会扩张或保持最大
            max_len = max(max_len, right - left + 1) 
            # 或者因为窗口长度只增不减（当不满足条件时 left 和 right 都加 1），
            # 所以 max_len 可以直接等于最终的 window_len
            # 但上面的写法更清晰地表达了在每一步都记录可能的最大值

        # 循环结束后，max_len 就是答案
        # 如果采用窗口长度只增不减的理解，也可以直接返回 right - left + 1 (在循环结束后)
        # 但考虑到 right 最后是 n-1，所以应该是 n - left
        # 还是在循环内更新 max_len 最保险和清晰
        return max_len

```

### 4. 复杂度分析

- **时间复杂度：** O(N)，其中 N 是字符串 `s` 的长度。左右指针都最多移动 N 次。
- **空间复杂度：** O(M)，其中 M 是字符集的大小。这里 M=26，所以空间复杂度是 O(1)。
