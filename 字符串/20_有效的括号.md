给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

有效字符串需满足：

1.  左括号必须用相同类型的右括号闭合。
2.  左括号必须以正确的顺序闭合。
3.  每个右括号都有一个对应的相同类型的左括号。

**示例 1：**

```
输入：s = "()"
输出：true
```

**示例 2：**

```
输入：s = "()[]{}"
输出：true
```

**示例 3：**

```
输入：s = "(]"
输出：false
```

**提示：**

*   `1 <= s.length <= 10^4`
*   `s` 仅由括号 `'()[]{}'` 组成

## 解决方法

### 1. 问题理解

**目标：** 判断一个只包含 '()[]{}' 六种括号的字符串是否是有效的。
**有效定义：**
1.  左括号必须由同类型右括号闭合。
2.  括号必须按正确顺序闭合（不能交叉）。
3.  每个右括号都有对应的左括号。

### 2. 思路分析 (栈)

括号匹配问题是栈 (Stack) 数据结构的经典应用场景。栈具有“后进先出”（LIFO）的特性，正好符合括号匹配的规则：最后遇到的左括号应该最先被匹配的右括号闭合。

**算法流程：**
1.  **初始化栈：** 创建一个空栈 `stack`。
2.  **创建括号映射：** 创建一个哈希表 `mapping` 来存储右括号到左括号的映射关系，例如 `mapping = {')': '(', ']': '[', '}': '{'}`。这有助于快速查找匹配的左括号。
3.  **遍历字符串：** 遍历输入字符串 `s` 中的每个字符 `char`：
    - **如果是左括号：** 如果 `char` 是一个左括号 (`'('`, `'['`, `'{'`)，将其压入栈 `stack.append(char)`。
    - **如果是右括号：** 如果 `char` 是一个右括号 (`')'`, `']'`, `'}'`)：
        - **检查栈是否为空：** 如果此时栈为空 (`not stack`)，说明没有对应的左括号来匹配当前的右括号，字符串无效，返回 `False`。
        - **检查栈顶是否匹配：** 弹出栈顶元素 `top_element = stack.pop()`。检查弹出的 `top_element` 是否是当前右括号 `char` 对应的左括号 (`top_element == mapping[char]`)。
            - 如果不匹配，说明括号类型不匹配或顺序错误，字符串无效，返回 `False`。
            - 如果匹配，继续遍历下一个字符。
4.  **最终检查：** 遍历完整个字符串后：
    - **如果栈为空 (`not stack`)：** 说明所有的左括号都被正确匹配并闭合了，字符串有效，返回 `True`。
    - **如果栈不为空：** 说明有多余的左括号没有被闭合，字符串无效，返回 `False`。

### 3. 代码实现 (Python)

```python
class Solution:
    def isValid(self, s: str) -> bool:
        """
        使用栈判断括号字符串是否有效。
        """
        stack = []
        # 存储右括号到左括号的映射
        mapping = {")": "(", "]": "[", "}": "{"}
        
        for char in s:
            # 如果是右括号
            if char in mapping:
                # 检查栈是否为空，或者栈顶是否匹配
                # 如果栈为空，用一个虚拟值 '#' 避免空栈 pop 错误，且保证不匹配
                top_element = stack.pop() if stack else '#' 
                if mapping[char] != top_element:
                    return False
            # 如果是左括号
            else:
                stack.append(char)
                
        # 遍历结束后，栈为空则有效，否则无效
        return not stack

```

### 4. 复杂度分析

- **时间复杂度：** O(N)，其中 N 是字符串 `s` 的长度。需要遍历字符串一次，栈的压入和弹出操作都是 O(1)。
- **空间复杂度：** O(N)。在最坏的情况下，如果字符串全是左括号，栈的大小会增长到 N。
