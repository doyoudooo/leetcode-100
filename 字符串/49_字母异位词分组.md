给你一个字符串数组，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。

**字母异位词** 是由重新排列源单词的所有字母得到的一个新单词。

**示例 1:**

```
输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出: [["bat"],["nat","tan"],["ate","eat","tea"]]
```

**示例 2:**

```
输入: strs = [""]
输出: [[""]]
```

**示例 3:**

```
输入: strs = ["a"]
输出: [["a"]]
```

**提示：**

*   `1 <= strs.length <= 10^4`
*   `0 <= strs[i].length <= 100`
*   `strs[i]` 仅包含小写字母

## 解决方法

### 1. 问题理解

**目标：** 将一个字符串数组 `strs` 中的所有字母异位词分组。
**输入：** 字符串数组 `strs`。
**输出：** 一个列表，其中每个子列表包含互为字母异位词的字符串。输出顺序和子列表内部顺序不限。
**字母异位词定义：** 包含相同字符及相同数量，但顺序不同的字符串。

### 2. 思路分析

核心思想是找到一种方法来**唯一标识**一组字母异位词，然后使用哈希表（字典）将具有相同标识的字符串分组。

#### 方法一：排序 + 哈希表

字母异位词排序后是相同的。我们可以利用这一点作为分组的依据。

**算法流程：**
1.  **初始化哈希表：** 创建一个字典 `anagram_groups`，用于存储分组结果。字典的键是排序后的字符串，值是包含原始字符串的列表。
2.  **遍历字符串数组：** 对于 `strs` 中的每个字符串 `s`：
    - **生成键：** 将字符串 `s` 排序，得到排序后的字符串 `sorted_s` (或者排序后的字符元组，因为列表不能作字典键)。
    - **分组：**
        - 如果 `sorted_s` 不在 `anagram_groups` 的键中，创建一个新的键值对 `anagram_groups[sorted_s] = []`。
        - 将原始字符串 `s` 添加到 `anagram_groups[sorted_s]` 列表中。
3.  **返回结果：** 遍历结束后，`anagram_groups` 的所有值（即那些列表）构成了最终的分组结果。返回 `list(anagram_groups.values())`。

**代码实现 (Python):**

```python
from typing import List
import collections

class Solution:
    def groupAnagrams_sort(self, strs: List[str]) -> List[List[str]]:
        """
        使用排序 + 哈希表对字母异位词进行分组。
        """
        anagram_groups = collections.defaultdict(list) # 使用 defaultdict 简化代码
        
        for s in strs:
            # 对字符串排序作为 key O(K log K), K 是字符串最大长度
            sorted_s_tuple = tuple(sorted(s)) 
            # 或者 sorted_s = "".join(sorted(s))
            
            anagram_groups[sorted_s_tuple].append(s)
            
        return list(anagram_groups.values())

```

**复杂度分析:**
- **时间复杂度：** O(N * K log K)，其中 N 是字符串数组 `strs` 的长度，K 是数组中最长字符串的长度。对于每个字符串，排序需要 O(K log K) 时间。
- **空间复杂度：** O(N * K)。哈希表需要存储所有字符串。

#### 方法二：计数 + 哈希表

字母异位词具有相同的字符计数。我们可以使用字符计数作为分组的依据。

**算法流程：**
1.  **初始化哈希表：** 创建一个字典 `anagram_groups`。字典的键是字符计数的表示（例如一个元组），值是包含原始字符串的列表。
2.  **遍历字符串数组：** 对于 `strs` 中的每个字符串 `s`：
    - **生成键 (字符计数)：** 创建一个大小为 26 的数组（或列表）`counts`，初始化为 0。遍历字符串 `s`，统计每个小写字母的出现次数。
    - 将计数数组 `counts` 转换成一个不可变类型（例如元组 `tuple(counts)`），作为字典的键。
    - **分组：**
        - 如果计数元组 `key` 不在 `anagram_groups` 中，创建 `anagram_groups[key] = []`。
        - 将原始字符串 `s` 添加到 `anagram_groups[key]` 列表中。
3.  **返回结果：** 返回 `list(anagram_groups.values())`。

**代码实现 (Python):**

```python
from typing import List
import collections

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        """
        使用计数 + 哈希表对字母异位词进行分组。
        """
        anagram_groups = collections.defaultdict(list)
        
        for s in strs:
            counts = [0] * 26 # 统计 'a' 到 'z' 的频率 O(K)
            for char in s:
                counts[ord(char) - ord('a')] += 1
            
            # 使用计数元组作为 key
            key = tuple(counts)
            anagram_groups[key].append(s)
            
        return list(anagram_groups.values())
```

**复杂度分析:**
- **时间复杂度：** O(N * K)，其中 N 是字符串数组 `strs` 的长度，K 是数组中最长字符串的长度。对于每个字符串，计算字符计数需要 O(K) 时间。哈希表操作平均 O(K)（取决于键的比较）。
- **空间复杂度：** O(N * K)。哈希表需要存储所有字符串。键（计数元组）的空间是 O(M)，M=26，是常数。

### 3. 对比与选择

- **计数方法 (O(N * K))** 通常比 **排序方法 (O(N * K log K))** 更快，因为计算字符计数比排序字符串更快（当 K > 1 时）。
- 两种方法的空间复杂度都是 O(N * K)。
- 计数方法更优，尤其当字符串长度 K 较大时。
