给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word` 。如果 `word` 存在于网格中，返回 `true` ；否则，返回 `false` 。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

**示例 1：**

```
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCCED"
输出：true
```

**示例 3：**

```
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCB"
输出：false
```
   ![img](https://assets.leetcode.com/uploads/2020/10/15/word1.jpg)

**提示：**

*   `m == board.length`
*   `n = board[i].length`
*   `1 <= m, n <= 6`
*   `1 <= word.length <= 15`
*   `board` 和 `word` 仅由大小写英文字母组成

## 解决方法

### 1. 问题理解

**目标：** 在一个二维字符网格 `board` 中查找是否存在一个给定的单词 `word`。
**规则：**
- 单词路径必须由水平或垂直相邻的单元格构成。
- 路径必须严格按照 `word` 中的字母顺序。
- 同一个单元格内的字母在同一条路径中不能被重复使用。

**输入：**
- `board`: `m x n` 的字符网格。
- `word`: 要查找的单词字符串。
**输出：** `true` 如果找到单词，`false` 如果找不到。

### 2. 思路分析

这是一个典型的在矩阵中使用回溯（深度优先搜索 DFS）来查找路径的问题。

**基本思路：**
遍历网格中的每一个单元格，尝试以该单元格作为起点，进行深度优先搜索，看是否能找到匹配 `word` 的路径。

**回溯过程：**

1.  **主函数逻辑：**
    *   获取网格的行数 `rows` 和列数 `cols`。
    *   遍历网格中的每个单元格 `(r, c)` (从 `0` 到 `rows-1`，`0` 到 `cols-1`)。
    *   如果 `board[r][c]` 与 `word` 的第一个字符 `word[0]` 匹配，则以 `(r, c)` 为起点，调用回溯函数 `backtrack(r, c, 0)` 进行搜索。
    *   如果在任何一次 `backtrack` 调用中返回 `True`，说明找到了单词，主函数直接返回 `True`。
    *   如果遍历完所有单元格作为起点都未能找到单词，则主函数返回 `False`。
2.  **回溯函数 `backtrack(row, col, word_index)`：**
    *   **参数：**
        *   `row`, `col`: 当前正在访问的单元格坐标。
        *   `word_index`: 当前正在匹配 `word` 中的哪个字符的索引。
    *   **递归终止条件 1 (成功找到)：**
        *   如果 `word_index == len(word) - 1`，说明已经成功匹配了 `word` 的所有字符，返回 `True`。
    *   **递归终止条件 2 (无效路径 - 隐式包含在后续检查中)：**
        *   边界检查：`row`, `col` 是否越界。
        *   字符匹配：`board[row][col]` 是否等于 `word[word_index]`。
        *   是否已访问：当前单元格 `(row, col)` 是否在本次搜索路径中已经被访问过。
    *   **标记已访问 (避免重复使用)：**
        *   为了防止在当前路径中重复使用同一个单元格，我们需要标记 `(row, col)` 为已访问。有两种常用方法：
            *   **使用 `visited` 集合/矩阵：** 创建一个与 `board` 同等大小的布尔矩阵 `visited`，或使用一个存储 `(row, col)` 元组的集合。在访问 `(row, col)` 前检查是否已访问，访问时标记，回溯时取消标记。
            *   **原地修改 `board`：** 将 `board[row][col]` 临时修改为一个特殊字符（例如 `"#"` 或空字符串），表示该单元格在当前路径中已被占用。递归返回后，再将其恢复原状。这种方法可以节省额外空间。
    *   **探索相邻单元格 (四个方向)：**
        *   定义四个方向的偏移量 `directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]`。
        *   对于每个方向 `(dr, dc)`：
            *   计算下一个单元格坐标 `next_row = row + dr`, `next_col = col + dc`。
            *   **检查有效性：**
                *   `next_row`, `next_col` 是否在网格边界内 (`0 <= next_row < rows` and `0 <= next_col < cols`)。
                *   `board[next_row][next_col]` 是否等于 `word[word_index + 1]` (下一个要匹配的字符)。
                *   `(next_row, next_col)` 是否未被访问 (根据所选的标记方法判断)。
            *   如果下一个单元格有效：
                *   递归调用 `backtrack(next_row, next_col, word_index + 1)`。
                *   如果递归调用返回 `True`，说明找到了完整路径，当前函数也返回 `True`。
    *   **撤销标记 (回溯)：**
        *   在尝试完所有四个方向后，如果都未能找到路径，需要将当前单元格 `(row, col)` 的访问标记撤销（恢复 `board` 的值或从 `visited` 中移除），以便其他搜索路径可以使用该单元格。
    *   **返回 False：** 如果所有方向都尝试过且未成功，返回 `False`。

**优化：** 在主函数调用 `backtrack` 之前，可以先判断 `board[r][c]` 是否等于 `word[0]`，如果不等，则无需启动以 `(r, c)` 为起点的搜索。

### 3. 代码实现 (Python)

```python
from typing import List

class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        """
        在二维网格中查找单词是否存在。
        Args:
            board: m x n 的字符网格。
            word: 要查找的单词。
        Returns:
            True 如果找到单词，False 如果找不到。
        """
        rows = len(board)
        cols = len(board[0])
        
        # 使用原地修改 board 的方法来标记访问过的单元格
        
        def backtrack(row: int, col: int, word_index: int) -> bool:
            """
            回溯函数核心逻辑。
            Args:
                row, col: 当前单元格坐标。
                word_index: 当前匹配到 word 的索引。
            Returns:
                True 如果从 (row, col) 出发能找到 word[word_index:]，否则 False。
            """
            # 边界检查 或 字符不匹配 (上层调用已保证第一个字符匹配)
            # 这里主要检查递归调用时的边界和字符匹配
            if not (0 <= row < rows and 0 <= col < cols and board[row][col] == word[word_index]):
                 return False # 也可以在上层调用前检查，这里多一层保险

            # 递归终止条件：成功匹配到单词末尾
            if word_index == len(word) - 1:
                return True

            # --- 标记已访问 ---
            original_char = board[row][col]
            board[row][col] = '#' # 临时修改为特殊字符，表示已访问

            # --- 探索相邻单元格 (四个方向) ---
            directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
            found = False
            for dr, dc in directions:
                next_row, next_col = row + dr, col + dc
                
                # 检查下一个单元格是否有效 (边界在 backtrack 内部检查)
                # 递归调用，尝试匹配下一个字符
                if backtrack(next_row, next_col, word_index + 1):
                    found = True
                    break # 找到即可，无需继续探索其他方向

            # --- 撤销标记 (回溯) ---
            board[row][col] = original_char # 恢复原始字符

            return found

        # --- 主函数逻辑：遍历所有可能的起点 ---
        for r in range(rows):
            for c in range(cols):
                # 尝试以 (r, c) 作为起点开始搜索
                # 优化：如果第一个字符就不匹配，则跳过
                if board[r][c] == word[0]:
                    if backtrack(r, c, 0):
                        return True # 如果找到，直接返回 True

        # 如果遍历完所有起点都找不到，返回 False
        return False
```

### 4. 复杂度分析

设网格大小为 M x N，单词长度为 L。

- **时间复杂度：** O(M * N * 3^L) 或 O(M * N * 4^L)
    - 主循环遍历 M * N 个单元格作为起点。
    - 对于每个起点，DFS 的搜索深度最多为 L。
    - 在 DFS 的每一步，我们需要探索最多 4 个邻居。但是，由于不能走回头路（来自上一步的那个邻居不能走），实际上最多只有 3 个新的方向可以探索。
    - 因此，粗略估计是 O(M * N * 3^L)。在 L 较小的情况下，这通常是可以接受的。
- **空间复杂度：** O(L)
    - 主要是递归调用栈的深度，最深为单词的长度 L。
    - 如果使用 `visited` 矩阵/集合，则需要额外的 O(M * N) 空间。使用原地修改法则不需要这部分额外空间。

### 5. 如何在面试中讲解

1.  **问题理解**：
    - "目标是在一个字符网格中查找是否存在一个单词路径，路径由相邻单元格组成，且单元格不能重复使用。"
2.  **核心思路：回溯 (DFS)**：
    - "这是一个典型的在矩阵中搜索路径的问题，可以用深度优先搜索（回溯）来解决。"
    - "基本想法是，遍历网格中的每个单元格，尝试将其作为单词的起点。"
    - "从起点开始，向上下左右四个方向递归地探索，看是否能匹配单词的后续字符。"
3.  **回溯函数设计**：
    - "定义一个递归函数 `backtrack(row, col, wordIndex)`，表示当前在 `(row, col)` 位置，尝试匹配 `word` 的第 `wordIndex` 个字符。"
    - "**Base Case (成功):** 如果 `wordIndex` 等于 `word` 的长度减 1，说明单词已完全匹配，返回 `True`。"
    - "**Base Case (失败/剪枝):**"
        - "检查 `(row, col)` 是否越界。"
        - "检查 `board[row][col]` 是否等于 `word[wordIndex]`。"
        - "检查 `(row, col)` 是否已经被当前路径访问过（防止重复使用）。"
        - "如果任一条件不满足，返回 `False`。"
4.  **防止重复访问**：
    - "在递归进入下一层之前，需要标记当前单元格 `(row, col)` 为已访问。"
    - "常用的方法是：1) 使用一个额外的 `visited` 矩阵或集合；2) **原地修改** `board[row][col]` 为一个特殊字符（如 '#'）。"
    - "原地修改的好处是节省空间。"
5.  **递归探索**：
    - "标记完当前单元格后，遍历其四个相邻单元格 `(nextRow, nextCol)`。"
    - "对每个有效的邻居（未越界、未访问过），递归调用 `backtrack(nextRow, nextCol, wordIndex + 1)`。"
    - "如果任何一个递归调用返回 `True`，则表示找到了路径，当前函数也返回 `True`。"
6.  **回溯（状态恢复）**：
    - "在当前函数返回之前（无论找到路径与否），**必须**将 `(row, col)` 的状态恢复原状（取消访问标记，例如将 '#' 恢复为原始字符）。这对于确保其他搜索分支的正确性至关重要。"
7.  **主流程**：
    - "在主函数中，遍历所有单元格 `(r, c)`。"
    - "如果 `board[r][c]` 等于 `word[0]`，则调用 `backtrack(r, c, 0)`。"
    - "只要有一次 `backtrack` 返回 `True`，整个函数就返回 `True`。"
    - "如果遍历完所有起点都失败，则返回 `False`。"
8.  **复杂度分析**：
    - "时间复杂度大致是 O(M * N * 3^L)，其中 M, N 是网格尺寸，L 是单词长度。因为有 M*N 个起点，DFS 深度为 L，每步最多 3 个新方向。"
    - "空间复杂度是 O(L)，主要是递归栈的深度。"
