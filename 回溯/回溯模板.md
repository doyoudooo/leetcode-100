# 回溯算法的固定套路

回溯算法是解决组合、排列、子集等问题的强大工具，以下是一个通用的回溯问题解决框架：

## 1. 回溯算法模板

```java
void backtrack(参数) {
    // 1. 终止条件
    if (达到终止条件) {
        保存结果;
        return;
    }
    
    // 2. 遍历选择列表
    for (选择 in 选择列表) {
        // 3. 做选择
        添加选择;
        
        // 4. 递归
        backtrack(新的参数);
        
        // 5. 撤销选择（回溯）
        撤销选择;
    }
}
```

## 2. 常见回溯问题类型及模式

### 组合问题 (Combination)
- 特点：不考虑元素顺序，通常需要 `start` 参数避免重复
- 例题：[39. 组合总和]、[40. 组合总和 II]、[77. 组合]
```java
void backtrack(int[] nums, int start, ...) {
    // ...
    for (int i = start; i < nums.length; i++) {
        // 做选择
        backtrack(nums, i+1, ...); // 注意：i+1 表示下一轮从下一个元素开始
        // 撤销选择
    }
}
```

### 排列问题 (Permutation)
- 特点：考虑元素顺序，需要 `used` 数组标记已使用元素
- 例题：[46. 全排列]、[47. 全排列 II]
```java
void backtrack(int[] nums, boolean[] used, ...) {
    // ...
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        // 做选择
        used[i] = true;
        backtrack(nums, used, ...);
        used[i] = false; // 撤销选择
    }
}
```

### 子集问题 (Subset)
- 特点：每个路径都是一个解，需要在每次递归时收集结果
- 例题：[78. 子集]、[90. 子集 II]
```java
void backtrack(int[] nums, int start, ...) {
    // 每次都收集当前路径作为一个结果
    result.add(new ArrayList<>(path));
    
    for (int i = start; i < nums.length; i++) {
        // 做选择
        backtrack(nums, i+1, ...);
        // 撤销选择
    }
}
```

### 搜索问题 (Search)
- 特点：找到满足条件的路径，可能需要剪枝优化
- 例题：[17. 电话号码的字母组合]、[39. 组合总和]
```java
void backtrack(参数, 当前状态) {
    if (满足条件) {
        保存结果;
        return;
    }
    if (不满足条件) return; // 剪枝
    
    for (选择 in 选择列表) {
        // 做选择，更新状态
        backtrack(参数, 新状态);
        // 撤销选择
    }
}
```

## 3. 优化技巧

1. **剪枝优化**
   - 提前判断无效路径，减少搜索空间
   - 例如在 [39. 组合总和] 中，如果 `target < 0`，可以直接返回

2. **排序预处理**
   - 对输入数组排序，有助于剪枝和处理重复元素
   - 例如在 [40. 组合总和 II] 中，`if(i > start && nums[i] == nums[i-1]) continue;`

3. **状态管理**
   - 使用 `StringBuilder` 代替 `String` 拼接
   - 利用参数传递状态，减少创建新对象

4. **去重处理**
   - 排列问题：使用 `used` 数组记录使用情况
   - 组合问题：使用 `start` 参数控制搜索起点

## 4. 判断回溯还是动态规划

- 如果问题要求**列出所有可能的解**，通常用回溯
- 如果问题只需要**解的个数**或**最优解**，通常考虑动态规划
- 如果状态空间很大，但需要找到可行解，考虑回溯+剪枝

回溯算法虽然看起来简单，但掌握好剪枝技巧和问题建模是解决复杂问题的关键。
