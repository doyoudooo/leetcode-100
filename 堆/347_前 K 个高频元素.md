给你一个整数数组 `nums` 和一个整数 `k` ，请你返回其中出现频率前 `k` 高的元素。你可以按 **任意顺序** 返回答案。

**示例 1:**

```
输入: nums = [1,1,1,2,2,3], k = 2
输出: [1,2]
```

**示例 2:**

```
输入: nums = [1], k = 1
输出: [1]
```

**提示：**

*   `1 <= nums.length <= 10^5`
*   `k` 的取值范围是 `[1, 数组中不相同的元素的个数]`
*   题目数据保证答案唯一，换句话说，数组中前 `k` 个高频元素的集合是唯一的
*   **进阶：**你所设计算法的时间复杂度 **必须** 优于 `O(n log n)` ，其中 `n` 是数组的大小。

## 解决方法

### 1. 问题理解

**目标：** 找到一个整数数组 `nums` 中出现频率最高的 `k` 个元素。
**输出：** 返回这 `k` 个元素的列表，顺序任意。
**约束：** 时间复杂度要求优于 O(n log n)。

### 2. 思路分析

#### 方法一：哈希表 + 排序 (O(N log N))

1.  **统计频率：** 使用哈希表（字典）统计每个元素出现的频率。
2.  **排序：** 将哈希表中的 `(元素, 频率)` 对按照频率进行降序排序。
3.  **提取结果：** 取排序后的前 `k` 个对中的元素。

**代码实现 (Python):**

```python
from typing import List
import collections

class Solution:
    def topKFrequent_sort(self, nums: List[int], k: int) -> List[int]:
        # 1. 统计频率 O(N)
        counts = collections.Counter(nums)
        
        # 2. 按频率排序 O(M log M)，M 是不同元素的数量 (M <= N)
        sorted_items = sorted(counts.items(), key=lambda item: item[1], reverse=True)
        
        # 3. 提取前 k 个元素的 key O(K)
        result = [item[0] for item in sorted_items[:k]]
        return result
```

**复杂度分析:**
- **时间复杂度：** O(N + M log M)，其中 N 是数组长度，M 是不同元素的数量。在最坏情况下 M 接近 N，复杂度为 O(N log N)。不满足进阶要求。
- **空间复杂度：** O(M)，哈希表和排序可能需要的空间。

#### 方法二：哈希表 + 最小堆 (O(N log K))

这是解决 Top K 问题的经典方法。

1.  **统计频率：** 使用哈希表统计每个元素出现的频率。O(N)。
2.  **维护最小堆：** 维护一个大小为 `k` 的最小堆，堆中存储 `(频率, 元素)` 对。遍历频率哈希表：
    - 将 `(频率, 元素)` 对推入堆中。
    - 如果堆的大小超过 `k`，则弹出堆顶元素（频率最小的那个）。
3.  **提取结果：** 遍历结束后，堆中剩下的 `k` 个元素就是频率最高的 `k` 个元素。提取它们的元素部分。

**代码实现 (Python):**

```python
from typing import List
import collections
import heapq

class Solution:
    def topKFrequent_heap(self, nums: List[int], k: int) -> List[int]:
        """
        使用哈希表 + 最小堆查找前 K 个高频元素。
        """
        # 1. 统计频率 O(N)
        counts = collections.Counter(nums)
        
        # 2. 维护大小为 k 的最小堆 O(M log K)，M 是不同元素数量
        min_heap = [] # 存储 (frequency, element)
        for element, frequency in counts.items():
            heapq.heappush(min_heap, (frequency, element))
            if len(min_heap) > k:
                heapq.heappop(min_heap) # 弹出频率最小的
                
        # 3. 提取结果 O(K)
        result = [item[1] for item in min_heap]
        return result
```

**复杂度分析:**
- **时间复杂度：** O(N + M log K)，其中 N 是数组长度，M 是不同元素的数量 (M <= N)。这通常优于 O(N log N)，尤其当 K 远小于 N 时。
- **空间复杂度：** O(M + K)。哈希表 O(M)，堆 O(K)。

#### 方法三：哈希表 + 快速选择 (平均 O(N))

类似于 "数组中的第K个最大元素"，我们可以对频率进行快速选择。

1.  **统计频率：** 使用哈希表统计频率。O(N)。
2.  **转换数据结构：** 将 `(元素, 频率)` 对放入一个列表中。
3.  **快速选择：** 对这个列表应用快速选择算法，找到频率第 `k` 高的那个 `(元素, 频率)` 对。快速选择的目标是找到排序后（按频率降序）索引为 `k-1` 的元素，或者（按频率升序）索引为 `M-k` 的元素（M 为不同元素个数）。
4.  **提取结果：** 找到第 k 高的频率阈值后，再次遍历哈希表（或快速选择过程中划分好的列表），收集所有频率大于或等于该阈值的元素。

**实现细节：**
- 快速选择需要实现 `partition` 函数，作用于 `(元素, 频率)` 对列表，比较的是频率。
- 需要处理频率相同的情况（虽然题目保证答案唯一，但中间过程可能遇到）。
- 找到第 k 高的频率后，收集结果需要 O(M) 时间。

**代码实现 (Python):**

```python
from typing import List
import collections
import random

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        """
        使用哈希表 + 快速选择查找前 K 个高频元素 (平均 O(N))。
        """
        # 1. 统计频率 O(N)
        counts = collections.Counter(nums)
        
        # 2. 转换为 (频率, 元素) 列表 O(M)
        freq_list = list(counts.items()) # [(element, frequency)]
        m = len(freq_list)
        
        # 3. 快速选择找到第 k 大频率的索引 (按频率降序排，找索引 k-1)
        # 或者按频率升序排，找索引 m-k
        target_idx = m - k 

        def partition(left, right):
            pivot_idx = random.randint(left, right)
            # 按频率比较
            freq_list[right], freq_list[pivot_idx] = freq_list[pivot_idx], freq_list[right]
            pivot_freq = freq_list[right][1] 
            
            store_idx = left
            for i in range(left, right):
                if freq_list[i][1] < pivot_freq: # 按频率升序划分
                    freq_list[store_idx], freq_list[i] = freq_list[i], freq_list[store_idx]
                    store_idx += 1
            freq_list[store_idx], freq_list[right] = freq_list[right], freq_list[store_idx]
            return store_idx

        left, right = 0, m - 1
        while True:
            if left == right:
                pivot_index = left
                break
            pivot_index = partition(left, right)
            if pivot_index == target_idx:
                break
            elif pivot_index < target_idx:
                left = pivot_index + 1
            else:
                right = pivot_index - 1
                
        # 4. 提取结果 O(K) 或 O(M)
        # 此时 freq_list[target_idx] 到 freq_list[m-1] 都是前 k 高频的
        # （注意 partition 后只有 pivot_index 位置确定，其他不一定有序）
        # 更稳妥的方式是返回 pivot_index 及其右侧的所有元素
        return [item[0] for item in freq_list[target_idx:]]

```
*修正快速选择实现和结果提取逻辑：*
快速选择找到的是第 `m-k` 小的频率对应的元素在 `partition` 后的位置。我们需要的是所有频率大于等于这个阈值的元素。

```python
from typing import List
import collections
import random

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        counts = collections.Counter(nums)
        freq_list = list(counts.items()) # [(element, frequency)]
        m = len(freq_list)
        target_idx = m - k # 第 k 大频率 = 第 m-k 小频率 (升序)

        def partition(left, right, pivot_idx):
            pivot_freq = freq_list[pivot_idx][1]
            # 1. Move pivot to end
            freq_list[pivot_idx], freq_list[right] = freq_list[right], freq_list[pivot_idx]
            store_idx = left
            # 2. Move all smaller elements to the left
            for i in range(left, right):
                if freq_list[i][1] < pivot_freq:
                    freq_list[store_idx], freq_list[i] = freq_list[i], freq_list[store_idx]
                    store_idx += 1
            # 3. Move pivot to its final place
            freq_list[store_idx], freq_list[right] = freq_list[right], freq_list[store_idx]
            return store_idx

        def quick_select(left, right, k_smallest_idx):
            if left == right:
                return

            pivot_idx = random.randint(left, right)
            pivot_final_idx = partition(left, right, pivot_idx)

            if k_smallest_idx == pivot_final_idx:
                return
            elif k_smallest_idx < pivot_final_idx:
                quick_select(left, pivot_final_idx - 1, k_smallest_idx)
            else:
                quick_select(pivot_final_idx + 1, right, k_smallest_idx)

        # 执行快速选择，使得索引 target_idx 左边的频率都小于等于它，右边的都大于等于它
        quick_select(0, m - 1, target_idx)

        # 此时 freq_list[target_idx:] 包含了频率至少是第 k 高的所有元素
        return [item[0] for item in freq_list[target_idx:]]

```

**复杂度分析:**
- **时间复杂度：** 平均 O(N)。统计频率 O(N)，快速选择平均 O(M)，提取结果 O(K) 或 O(M)。因为 M <= N，所以总体平均 O(N)。最坏情况 O(N^2)。
- **空间复杂度：** O(M)。哈希表和频率列表。

#### 方法四：桶排序 (O(N))

如果我们可以利用频率的范围。

1.  **统计频率：** 使用哈希表统计频率。O(N)。
2.  **创建桶：** 创建一个桶数组（列表的列表），索引代表频率，值是具有该频率的元素列表。桶的大小是 `n+1`（因为最高频率可能是 n）。
3.  **元素入桶：** 遍历频率哈希表，将元素放入对应频率的桶中。O(M)。
4.  **倒序提取：** 从后往前（从最高频率）遍历桶数组，收集元素，直到收集到 `k` 个元素为止。O(N) 或 O(M)。

**代码实现 (Python):**

```python
from typing import List
import collections

class Solution:
    def topKFrequent_bucket(self, nums: List[int], k: int) -> List[int]:
        """
        使用桶排序的思想查找前 K 个高频元素 (O(N))。
        """
        # 1. 统计频率 O(N)
        counts = collections.Counter(nums)
        
        # 2. 创建桶 O(N) - 桶的数量取决于最大频率，最大为 N
        n = len(nums)
        buckets = [[] for _ in range(n + 1)] 
        
        # 3. 元素入桶 O(M) - M 为不同元素数量
        for element, frequency in counts.items():
            buckets[frequency].append(element)
            
        # 4. 倒序提取 O(N) 或 O(M)
        result = []
        for i in range(n, 0, -1): # 从最高频率 n 开始
            if buckets[i]:
                result.extend(buckets[i])
            if len(result) >= k:
                break
                
        # 如果需要精确 k 个，可以截断
        return result[:k] 
```

**复杂度分析:**
- **时间复杂度：** O(N)。统计频率 O(N)，入桶 O(M)，提取结果最坏 O(N)（如果所有元素频率都一样）。总体 O(N)。
- **空间复杂度：** O(N + M)。哈希表 O(M)，桶数组 O(N)。

### 3. 如何在面试中讲解

1.  **问题理解**：
    - "目标是找到数组中出现频率最高的 k 个元素。要求时间复杂度优于 O(N log N)。"
2.  **方法一：哈希表 + 排序 (Baseline)**：
    - "先用哈希表统计频率 (O(N))，然后按频率排序 (O(M log M))，取前 k 个。总复杂度 O(N log N)，不满足进阶要求。"
3.  **方法二：哈希表 + 最小堆 (常用解法)**：
    - "**思路:** 统计频率 (O(N))。维护一个大小为 k 的最小堆，存储 `(频率, 元素)`。遍历频率项，入堆，如果堆大小超 k 则弹出最小频率项。最后堆内即为所求。"
    - "**复杂度:** 时间 O(N + M log K)，空间 O(M + K)。满足优于 O(N log N) 的要求。"
4.  **方法三：哈希表 + 快速选择 (最优平均时间)**：
    - "**思路:** 统计频率 (O(N))。将 `(元素, 频率)` 对放入列表。使用快速选择找到频率第 k 高（或第 M-k 低）的分割点。"
    - "**复杂度:** 平均时间 O(N)，最坏 O(N^2)。空间 O(M)。这是理论上平均最优的方法。"
    - "实现相对复杂，需要写 `partition` 和处理边界。"
5.  **方法四：桶排序 (线性时间)**：
    - "**思路:** 统计频率 (O(N))。创建一个大小为 N+1 的桶数组，索引代表频率。将元素按频率放入桶中 (O(M))。从后往前遍历桶，收集元素直到 k 个 (O(N))。"
    - "**复杂度:** 时间 O(N)，空间 O(N + M)。当频率范围可控时，这是非常高效的方法。"
6.  **总结与选择**：
    - "堆方法是 Top K 问题的通用且较易实现的解法，复杂度 O(N log K)。"
    - "快速选择平均时间最优 O(N)，但实现复杂且有最坏情况。"
    - "桶排序在时间和空间允许的情况下是 O(N) 的确定性解法。"
    - "面试中通常期望至少能写出堆方法，能想到并解释快速选择或桶排序更佳。"
