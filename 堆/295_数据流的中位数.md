**中位数** 是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

*   例如 `[2,3,4]` 的中位数是 `3` 。
*   例如 `[2,3]` 的中位数是 `(2 + 3) / 2 = 2.5` 。

实现 MedianFinder 类:

*   `MedianFinder()` 初始化 `MedianFinder` 对象。
*   `void addNum(int num)` 将数据流中的整数 `num` 添加到数据结构中。
*   `double findMedian()` 返回到目前为止所有元素的中位数。与实际答案相差 `10^-5` 以内的答案将被接受。

**示例 1：**

```
输入
["MedianFinder", "addNum", "addNum", "findMedian", "addNum", "findMedian"]
[[], [1], [2], [], [3], []]
输出
[null, null, null, 1.5, null, 2.0]

解释
MedianFinder medianFinder = new MedianFinder();
medianFinder.addNum(1);    // arr = [1]
medianFinder.addNum(2);    // arr = [1, 2]
medianFinder.findMedian(); // 返回 1.5 ((1 + 2) / 2)
medianFinder.addNum(3);    // arr = [1, 2, 3]
medianFinder.findMedian(); // 返回 2.0
```

**提示:**

*   `-10^5 <= num <= 10^5`
*   在调用 `findMedian` 前，数据结构中至少有一个元素
*   最多 `5 * 10^4` 次调用 `addNum` 和 `findMedian`

## 解决方法

### 1. 问题理解

**目标：** 设计一个数据结构，支持高效地添加数字 (`addNum`) 和查找当前所有数字的中位数 (`findMedian`)。
**中位数定义：**
- 奇数个元素：中间那个数。
- 偶数个元素：中间两个数的平均值。

**挑战：** 数据是流式输入的，数据结构需要动态维护中位数。

### 2. 思路分析

#### 朴素方法（低效）

- **维护排序列表：**
    - `addNum`: 将数字插入到已排序列表中，保持有序。使用 `bisect.insort` 时间复杂度 O(N)。
    - `findMedian`: 直接根据列表长度计算中位数索引并返回值。O(1)。
    - 缺点：`addNum` 效率太低，为 O(N)。
- **每次查找时排序：**
    - `addNum`: 直接将数字添加到列表末尾。O(1)。
    - `findMedian`: 对整个列表排序，然后找中位数。O(N log N)。
    - 缺点：`findMedian` 效率太低。

#### 高效方法：双堆 (最大堆 + 最小堆)

这是解决此问题的经典方法。核心思想是将数据流分为两部分：

1.  **较小的一半 (lo)：** 使用 **最大堆 (Max-Heap)** 存储。堆顶是这部分的最大值。
2.  **较大的一半 (hi)：** 使用 **最小堆 (Min-Heap)** 存储。堆顶是这部分的最小值。

**维护策略：**
- 始终保持两个堆的大小平衡：`len(lo)` 要么等于 `len(hi)`，要么比 `len(hi)` 多 1 (`len(lo) == len(hi) + 1`)。
- `lo` 中的所有元素都小于或等于 `hi` 中的所有元素。

**`addNum(num)` 流程：**
1.  **默认添加到 `lo` (最大堆)：** 为了方便后续比较和移动，我们先将新数字 `num` 加入 `lo`。由于 Python 的 `heapq` 是最小堆，我们将 `-num` 加入 `lo` 来模拟最大堆。
2.  **维护堆顶关系：** 将 `lo` 的堆顶（即 `-lo[0]`，是 `lo` 中的最大值）移动到 `hi` (最小堆) 中。这样可以保证 `lo` 中的元素总是小于等于 `hi` 中的元素。
    - `heapq.heappush(hi, -heapq.heappop(lo))`
3.  **维护大小平衡：** 检查两个堆的大小。如果 `len(lo) < len(hi)`，说明 `hi` 比 `lo` 多了一个元素，需要将 `hi` 的堆顶（`hi` 中的最小值）移动回 `lo`。
    - `heapq.heappush(lo, -heapq.heappop(hi))`

经过这三步，可以保证：
- `lo` 的堆顶是较小一半中的最大值。
- `hi` 的堆顶是较大一半中的最小值。
- `len(lo)` 要么等于 `len(hi)`，要么等于 `len(hi) + 1`。

**`findMedian()` 流程：**
1.  **如果 `len(lo) > len(hi)`：** 说明总元素个数是奇数，中位数就是 `lo` 的堆顶元素（较小一半中的最大值）。返回 `-lo[0]`。
2.  **如果 `len(lo) == len(hi)`：** 说明总元素个数是偶数，中位数是 `lo` 的堆顶 (`-lo[0]`) 和 `hi` 的堆顶 (`hi[0]`) 的平均值。返回 `(-lo[0] + hi[0]) / 2.0`。

### 3. 代码实现 (Python)

```python
import heapq

class MedianFinder:

    def __init__(self):
        """
        初始化 MedianFinder 对象。
        使用两个堆：
        self.lo: 最大堆，存储数据流中较小的一半数字 (用负数模拟)
        self.hi: 最小堆，存储数据流中较大的一半数字
        """
        self.lo = []  # Max-heap (stores negative numbers)
        self.hi = []  # Min-heap

    def addNum(self, num: int) -> None:
        """
        将 num 添加到数据结构中。
        时间复杂度: O(log N)
        """
        # 1. 先将 num 加入 lo (最大堆)
        heapq.heappush(self.lo, -num)
        
        # 2. 将 lo 的最大值 (即 -lo[0]) 移动到 hi，维持 lo <= hi
        largest_in_lo = -heapq.heappop(self.lo)
        heapq.heappush(self.hi, largest_in_lo)
        
        # 3. 平衡两个堆的大小，保证 len(lo) >= len(hi)
        if len(self.lo) < len(self.hi):
            smallest_in_hi = heapq.heappop(self.hi)
            heapq.heappush(self.lo, -smallest_in_hi)

    def findMedian(self) -> float:
        """
        返回当前所有元素的中位数。
        时间复杂度: O(1)
        """
        # 如果 lo 比 hi 多一个元素 (总数为奇数)，中位数是 lo 的堆顶
        if len(self.lo) > len(self.hi):
            return -self.lo[0]
        # 如果 lo 和 hi 元素个数相等 (总数为偶数)，中位数是两者堆顶的平均值
        else:
            return (-self.lo[0] + self.hi[0]) / 2.0

# mf.addNum(2)
# print(mf.findMedian()) # 1.5
# mf.addNum(3)
# print(mf.findMedian()) # 2.0
```

### 4. 复杂度分析

- **`addNum(num)`:**
    - 时间复杂度：O(log N)。涉及最多三次堆操作（两次 `heappush`，一次 `heappop`），每次堆操作的时间复杂度是 O(log N)，其中 N 是当前数据流中的元素总数。
    - 空间复杂度：O(1) (除了存储元素本身)。
- **`findMedian()`:**
    - 时间复杂度：O(1)。只需要访问两个堆的堆顶元素。
    - 空间复杂度：O(1)。
- **整体空间复杂度：** O(N)。需要存储数据流中的所有 N 个元素在两个堆中。

### 5. 如何在面试中讲解

1.  **问题理解**：
    - "我们需要设计一个数据结构，能动态接收数据流，并随时可以 O(1) 时间复杂度返回当前所有数据的中位数。"
2.  **挑战与朴素方法**：
    - "挑战在于数据是动态增加的。如果每次 `addNum` 都维护一个完整排序列表，`addNum` 会是 O(N)。如果每次 `findMedian` 都排序，`findMedian` 会是 O(N log N)。都不够高效。"
3.  **核心思路：双堆**：
    - "我们可以用两个堆来解决：一个最大堆 `lo` 存储较小的一半数据，一个最小堆 `hi` 存储较大的一半数据。"
    - "目标是让 `lo` 的堆顶 <= `hi` 的堆顶，并且两个堆的大小尽可能平衡 (`len(lo)` 等于 `len(hi)` 或多 1)。"
4.  **`addNum` 逻辑**：
    - "新来的数 `num` 先加入 `lo` (最大堆)。"
    - "为了维持 `lo` <= `hi` 的性质，将 `lo` 的最大值弹出，加入 `hi` (最小堆)。"
    - "最后检查大小平衡。如果 `lo` 比 `hi` 少了，就从 `hi` 弹出最小值，加入 `lo`。"
    - "这样保证了 `lo` 和 `hi` 分别持有数据的下半部分和上半部分，且大小平衡。"
    - "由于 Python 只有最小堆，最大堆可以通过存入负数来模拟。"
5.  **`findMedian` 逻辑**：
    - "如果 `len(lo) > len(hi)` (总数奇数)，中位数就是 `lo` 的堆顶 (最大值)。"
    - "如果 `len(lo) == len(hi)` (总数偶数)，中位数就是 `lo` 堆顶和 `hi` 堆顶的平均值。"
6.  **复杂度分析**：
    - "`addNum` 是 O(log N) 因为有堆操作。"
    - "`findMedian` 是 O(1) 因为只访问堆顶。"
    - "空间复杂度是 O(N) 来存储所有元素。"
7.  **代码演示**：
    - "展示使用 `heapq` 实现双堆的代码。"
