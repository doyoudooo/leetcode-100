给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

你必须设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

**示例 1:**

```
输入: [3,2,1,5,6,4], k = 2
输出: 5
```

**示例 2:**

```
输入: [3,2,3,1,2,4,5,5,6], k = 4
输出: 4
```

**提示：**

*   `1 <= k <= nums.length <= 10^5`
*   `-10^4 <= nums[i] <= 10^4`

## 解决方法

### 1. 问题理解

**目标：** 找到一个未排序数组 `nums` 中第 `k` 大的元素。
**注意：** 是排序后的第 k 大，不是第 k 个不同的元素。
**约束：** 时间复杂度要求为 O(n) (平均情况)。

### 2. 思路分析

#### 方法一：排序 (O(N log N))

最直观的方法是对整个数组进行排序，然后返回排序后数组的倒数第 `k` 个元素（或者说索引为 `n - k` 的元素）。

**算法流程：**
1.  对 `nums` 数组进行降序排序。
2.  返回索引为 `k - 1` 的元素。
或者：
1.  对 `nums` 数组进行升序排序。
2.  返回索引为 `n - k` 的元素。

**代码实现 (Python):**

```python
from typing import List

class Solution:
    def findKthLargest_sort(self, nums: List[int], k: int) -> int:
        nums.sort(reverse=True) # O(N log N)
        return nums[k - 1]
        
        # 或者升序排序
        # nums.sort() # O(N log N)
        # return nums[len(nums) - k]
```

**复杂度分析:**
- **时间复杂度：** O(N log N)，主要由排序决定。不满足题目 O(n) 的要求。
- **空间复杂度：** O(log N) 或 O(N)，取决于排序算法使用的空间（例如快速排序的递归栈或归并排序的辅助数组）。

#### 方法二：基于堆 (优先队列) (O(N log K))

维护一个大小为 `k` 的最小堆 (Min-Heap)。遍历数组元素，将元素加入堆中。如果堆的大小超过 `k`，则弹出堆顶（最小）元素。遍历结束后，堆顶元素就是第 `k` 大的元素。

**算法流程：**
1.  初始化一个大小为 `k` 的最小堆。
2.  遍历 `nums` 数组中的每个元素 `num`：
    - 将 `num` 推入堆中。
    - 如果堆的大小大于 `k`，则从堆中弹出堆顶元素（当前堆中最小的元素）。
3.  遍历结束后，堆中恰好包含数组中最大的 `k` 个元素，而堆顶就是这 `k` 个元素中最小的那个，即数组的第 `k` 大元素。返回堆顶元素。

**代码实现 (Python):**

```python
import heapq
from typing import List

class Solution:
    def findKthLargest_heap(self, nums: List[int], k: int) -> int:
        """
        使用大小为 k 的最小堆查找第 k 大元素。
        """
        min_heap = [] # Python heapq 默认是最小堆
        for num in nums:
            heapq.heappush(min_heap, num) # O(log K)
            if len(min_heap) > k:
                heapq.heappop(min_heap) # O(log K)
        
        # 堆顶元素即为第 k 大的元素
        return min_heap[0] 
        # 或者 return heapq.heappop(min_heap) 如果只需要结果
```

**复杂度分析:**
- **时间复杂度：** O(N log K)。遍历数组 N 次，每次堆操作（插入或删除）的时间复杂度是 O(log K)。
- **空间复杂度：** O(K)。需要存储大小为 K 的堆。
- 当 K 远小于 N 时，此方法优于排序。但仍不满足严格的 O(N) 要求。

#### 方法三：基于快速选择 (QuickSelect) (平均 O(N)，最坏 O(N^2))

快速选择算法是快速排序算法的一个变种，专门用于查找第 k 小（或第 k 大）的元素。其核心思想是利用快速排序的 `partition` 操作。

**Partition 操作：** 选择一个基准元素 (pivot)，将数组划分为两部分：小于等于 pivot 的元素和大于 pivot 的元素。返回 pivot 最终所在的索引 `p`。

**算法流程：**
1.  目标是找到排序后索引为 `target_idx = n - k` 的元素（即第 k 大元素）。
2.  定义一个递归（或迭代）函数 `quick_select(left, right, target_idx)`：
    - 在 `[left, right]` 区间内执行 `partition` 操作，得到 pivot 的最终索引 `p`。
    - **比较 `p` 与 `target_idx`：**
        - 如果 `p == target_idx`：找到了第 k 大元素，返回 `nums[p]`。
        - 如果 `p < target_idx`：第 k 大元素在 pivot 的右侧，递归（或迭代）调用 `quick_select(p + 1, right, target_idx)`。
        - 如果 `p > target_idx`：第 k 大元素在 pivot 的左侧，递归（或迭代）调用 `quick_select(left, p - 1, target_idx)`。
3.  初始调用 `quick_select(0, n - 1, n - k)`。

**优化：随机化 Pivot**
为了避免最坏情况 O(N^2)（当每次选取的 pivot 都是当前区间的最大或最小值时），可以在 `partition` 操作前随机选择一个元素与区间的第一个（或最后一个）元素交换，然后用该元素作为 pivot。这样可以使得平均时间复杂度达到 O(N)。

**代码实现 (Python):**

```python
import random
from typing import List

class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        """
        使用快速选择算法查找第 k 大元素 (平均 O(N))。
        """
        n = len(nums)
        target_idx = n - k # 第 k 大元素的索引 (升序排列后)
        
        def partition(left, right):
            # 随机选择 pivot 并放到最左边
            pivot_idx = random.randint(left, right)
            nums[left], nums[pivot_idx] = nums[pivot_idx], nums[left]
            pivot = nums[left]
            
            # 双指针法进行 partition (类似 Hoare partition scheme 稍作修改)
            l, r = left + 1, right
            while True:
                while l <= r and nums[l] < pivot:
                    l += 1
                while l <= r and nums[r] > pivot:
                    r -= 1
                if l > r:
                    break
                nums[l], nums[r] = nums[r], nums[l]
                l += 1
                r -= 1
            # 将 pivot 放到正确的位置
            nums[left], nums[r] = nums[r], nums[left]
            return r # 返回 pivot 的最终索引

        left, right = 0, n - 1
        while True: # 使用迭代代替递归
            if left == right: # 区间只有一个元素
                return nums[left]
            
            pivot_index = partition(left, right)
            
            if pivot_index == target_idx:
                return nums[pivot_index]
            elif pivot_index < target_idx:
                left = pivot_index + 1
            else: # pivot_index > target_idx
                right = pivot_index - 1
```

**复杂度分析:**
- **时间复杂度：**
    - **平均情况：** O(N)。每次 `partition` 操作需要 O(区间长度) 时间。由于每次递归（或迭代）的区间大小期望减半，总时间复杂度为 N + N/2 + N/4 + ... = O(N)。
    - **最坏情况：** O(N^2)。如果每次 pivot 都选得不好（例如，在已排序数组中总是选第一个元素），导致区间只缩小 1，则退化为 O(N^2)。随机化 pivot 可以极大地降低发生最坏情况的概率。
- **空间复杂度：** O(log N) (递归栈平均深度) 或 O(1) (迭代实现)。

### 3. 如何在面试中讲解

1.  **问题理解**：
    - "目标是找到未排序数组中第 k 大的元素，注意不是第 k 个不同的元素。要求时间复杂度 O(N)。"
2.  **方法一：排序 (Baseline)**：
    - "最简单的方法是排序，然后取第 `n-k` 个元素。时间复杂度 O(N log N)，不满足要求，但可以作为基准。"
3.  **方法二：最小堆 (优先队列)**：
    - "**思路:** 维护一个大小为 k 的最小堆。遍历数组，将元素加入堆，如果堆大小超过 k，就弹出堆顶（最小值）。最后堆顶就是第 k 大的元素。"
    - "**实现:** 使用 `heapq` 库。"
    - "**复杂度:** 时间 O(N log K)，空间 O(K)。当 K 较小时比较好，但仍不是 O(N)。"
4.  **方法三：快速选择 (满足 O(N) 平均复杂度)**：
    - "**思路:** 这是基于快速排序 `partition` 操作的算法。目标是找到排序后索引为 `n-k` 的元素。"
    - "**Partition:** 每次 `partition` 将数组分为小于 pivot 和大于 pivot 的两部分，并返回 pivot 的最终位置 `p`。"
    - "**递归/迭代:** 比较 `p` 和 `target_idx = n - k`：
        - 如果 `p == target_idx`，找到。
        - 如果 `p < target_idx`，说明第 k 大元素在右边，在右半部分继续查找。
        - 如果 `p > target_idx`，说明第 k 大元素在左边，在左半部分继续查找。"
    - "**随机化:** 为了避免最坏 O(N^2) 情况，每次随机选择 pivot。"
    - "**复杂度:** 平均时间 O(N)，最坏时间 O(N^2)（但随机化后概率极低），空间 O(log N) (递归) 或 O(1) (迭代)。"
5.  **总结与选择**：
    - "快速选择是满足 O(N) 平均时间复杂度的标准解法。"
    - "堆方法虽然不是严格 O(N)，但在 K 较小或不允许修改原数组时也是常用方法。"
